# Архитектура потока и вайрфреймы экранов S00–S21 (Уровень КН-01)

- **Роль:** `ux-accessibility-reviewer`
- **Проверяющие:** `art-director`, `gameplay-balance-designer`
- **Спецификация:** `docs/roadmap/kn01-aaa/05_SCREENS.md`
- **Форм-факторы:**
  - **A:** Desktop 1920×1080 (16:9) — целочисленный масштаб $\times 4$ от логической сетки 480×270;
  - **B:** Laptop 1366×768 — целочисленный масштаб $\times 2.5 \to$ масштаб $\times 2$ с рамкой-паспарту 16×16;
  - **C:** Mobile landscape 844×390 — адаптированная горизонтальная раскладка (в портрете 390×844 доступен только хаб, для смены требуется поворот);
  - **D:** Classroom Projector (1024×768 / чтение с 3 метров) — укрупнённые шрифты $\ge 24$ px, максимальный контраст, акцент на одной цели.

## 2. Поэкранная спецификация S00–S21

### S00. Загрузка ресурсов и шрифтов (`loading_screen`)
- **Назначение:** Полное сокрытие загрузки WebGL/Phaser ассетов и шрифтов без скачков верстки.
- **Интерактивные зоны:** Кнопка «Повторить попытку» (появляется только при ошибке сети > 5 с).
- **Порядок фокуса клавиатуры:** Кнопка повтора `[Tab -> Enter]`.
- **Вайрфрейм (Desktop / Laptop):**
```
+-------------------------------------------------------------+
|                          [ПАСПАРТУ]                         |
|                                                             |
|                    [ЭМБЛЕМА СТАНЦИИ 64x64]                  |
|                                                             |
|         =================== ТЕЛЕТАЙП ===================     |
|         26063 ... ПОДКЛЮЧЕНИЕ К НАУЧНОМУ КАМПУСУ ...        |
|         [o o o o o o o o o o . . . . . .] (65%)             |
|         ================================================     |
+-------------------------------------------------------------+
```

### S01. Титульный экран (`title_screen`)
- **Назначение:** Входная точка в атмосферу научно-исследовательского кампуса 26063.
- **Интерактивные зоны:** Кнопка 1 «НАЧАТЬ ДЕЖУРСТВО» (янтарная), Кнопка 2 «НАБЛЮДАТЕЛЬ», Кнопка 3 «НАСТРОЙКИ».
- **Порядок фокуса клавиатуры:** `1. Кнопка «НАЧАТЬ ДЕЖУРСТВО»` $\to$ `2. «НАБЛЮДАТЕЛЬ»` $\to$ `3. «НАСТРОЙКИ»` $\to$ `4. «ЗВУК»`.
- **Вайрфрейм (Desktop / Projector):**

### S02. Журнал допуска (Авторизация)
- **Назначение:** Аутентификация студента по закрытому списку без ввода паролей на клавиатуре.
- **Интерактивные зоны:** Вкладки групп (слева), карточки курсантов (в центре), цифровой пинпад 3×4 (справа).
- **Порядок фокуса клавиатуры:** `1. Список групп` $\to$ `2. Карточки курсантов` $\to$ `3. Поле кода` $\to$ `4. Кнопка «ВОЙТИ»` (`Esc` — назад).
- **Вайрфрейм (Laptop / Desktop):**
```
+-------------------------------------------------------------+
| [Х] ЗАКРЫТЬ                                                 |
| ЖУРНАЛ ДЕЖУРНОЙ СМЕНЫ СТАНЦИИ 26063                         |

| | Группа 1 | | [Аватар] Синицын А.      | | [ _ _ _ _ ]   | |
| | Группа 2 | | [Аватар] Морозова Е. [x] | | [1] [2] [3]   | |
| | Группа 3 | | [Аватар] Ковалёв Д.      | | [4] [5] [6]   | |
| +----------+ +--------------------------+ | [7] [8] [9]   | |
|                                           |  C  [0] [<-]  | |
|                                           | [ВОЙТИ] Enter | |
|                                           +---------------+ |
+-------------------------------------------------------------+
```

### S03. Первичная установка персонального кода
- **Назначение:** Однократная фиксация персонального четырёхзначного кода курсанта.
- **Порядок фокуса:** Поле ввода кода $\to$ подтверждение $\to$ кнопка «ЗАПИСАТЬ В ЖУРНАЛ».

### S04. Выдача форменной одежды и экипировки
- **Назначение:** Кастомизация пиксельного аватара перед заступлением на вахту.
- **Интерактивные зоны:** Вращение аватара (кнопки Q/E), слоты экипировки (головной убор, китель, брюки, обувь, прибор в руку), кнопка «ЗАСТУПИТЬ НА ПОСТ».
- **Порядок фокуса:** `1. Вращение` $\to$ `2. Выбор категории` $\to$ `3. Сетка предметов` $\to$ `4. Кнопка «ЗАСТУПИТЬ»`.

### S05. Вводный инструктаж наставника
- **Назначение:** Экспозиция синоптической службы и роли техника-метеоролога (до 40 секунд).
- **Интерактивные зоны:** Кнопка «СЛУШАТЬ ДАЛЬШЕ» (Enter), кнопка «ПРОПУСТИТЬ» (Esc).
- **Порядок фокуса:** `1. Кнопка «ДАЛЕЕ»` $\to$ `2. Кнопка «ПРОПУСТИТЬ»`.

### S06. Центральный хаб кампуса 26063
- **Назначение:** Главный экран живого мира кампуса; выбор локаций и доступ к помещениям.
- **Интерактивные зоны:** Доступное здание «Кодовый пост» (маячок и янтарный контур), закрытые здания (замок), консоль нижнего дока.
- **Порядок фокуса:** `1. Здание Кодового поста (Space/Enter)` $\to$ `2. Док: Досье` $\to$ `3. Док: Журнал ошибок` $\to$ `4. Док: Настройки`.
- **Вайрфрейм (Desktop / Laptop):**
```
+-------------------------------------------------------------+

|                                                             |

|       (замок)              (замок)           |КОДОВЫЙ ПОСТ| |
|                                              | [ * СМЕНА] | |
|         [ДВОР: дежурный кот, синицы]         +------------+ |
|                                                             |

| | [ПОСТ 26063] | [ЖУРНАЛ ОШИБОК] | [РАДИО] | [НАСТРОЙКИ]  | |
| +---------------------------------------------------------+ |
+-------------------------------------------------------------+
```

### S07. Досье поста и карта смен уровня КН-01
- **Назначение:** Навигация по учебным сменам уровня 1 (С1 Позывные $\to$ С2 Термометр $\to$ С3 Барометр $\to$ С4 Ветер и облака $\to$ С5 Полная лента $\to$ Допуск).
- **Порядок фокуса:** `1. Список доступных смен (стрелки вверх/вниз)` $\to$ `2. Кнопка «ВЫБРАТЬ РЕЖИМ»`.

### S08. Выбор режима смены
- **Назначение:** Выбор уровня ответственности: «С наставником» ($\times 0{,}6$), «Самостоятельно» ($\times 1{,}0$), «Блиц 90 с» ($\times 0{,}8$).
- **Интерактивные зоны:** Три карточки режимов с описанием множителей, справочника и таймера.
- **Порядок фокуса:** `1. Карточка режима (стрелки влево/вправо)` $\to$ `2. Кнопка «НАЧАТЬ СМЕНУ» (Enter)`.

### S09. Вводная карточка смены
- **Назначение:** Описание задач текущей смены (например, «Смена 2: дешифрирование температуры 1snTTT и точки росы 2snTdTdTd, контроль физического инварианта Td <= T»).
- **Порядок фокуса:** Кнопка «К ТЕЛЕТАЙПУ» (Enter).

### S10. Рабочее место «Кодовый пост»
- **Назначение:** Основной экран дежурства.
- **Интерактивные зоны:**
  - Бумажная перфолента с группами КН-01 в центре;
  - Поле ввода / варианты выбора в рабочей зоне;
  - Кнопка «СПРАВОЧНИК» (H);
  - Индикатор 5 ламп серии ответов;
  - Портрет наставника M3 внизу слева;
  - Главная кнопка действия «ПРОВЕРИТЬ» (Enter).
- **Порядок фокуса:** `1. Активное поле ввода / карточки выбора` $\to$ `2. Кнопка «ПРОВЕРИТЬ» (Enter)` $\to$ `3. Кнопка «СПРАВОЧНИК» (H)`.
- **Вайрфрейм (Desktop / Laptop 16:9):**
```
+-------------------------------------------------------------+
| СМЕНА 2: ТЕРМОМЕТР [Лампы: * * * . .]         [СПРАВОЧНИК: H]|
|                                             СХЕМА СТАНЦИИ:  |
| ТЕЛЕТАЙПНАЯ ЛЕНТА:                         +---------------+|
| [ AAXX ] [ 26181 ] [ 26063 ] >[ 10234 ]<   | T = [  ?  ]   ||
|                                            | Td= [  ?  ]   ||
| ЗАДАНИЕ: Раскодируйте температуру воздуха: +---------------+|
| Значение: [ 23.4 ] °C                                       |
|                                                             |
| [Портрет] Наставник:                         +-------------+|
| «Внимание на знаковый бит sn».              |  ПРОВЕРИТЬ  ||
|                                              +-------------+|
+-------------------------------------------------------------+
```

### S11. Всплывающий справочник кодов КН-01
- **Назначение:** Нормативная шпаргалка дежурного с вкладками: «Секция 0», «Температура», «Давление», «Ветер/Облачность».
- **Порядок фокуса:** `1. Вкладки разделов (1-4)` $\to$ `2. Скролл текста` $\to$ `3. Кнопка «ЗАКРЫТЬ» (Esc / H)`.

### S12. Обратная связь на ответ
- **Назначение:** Мгновенный разбор результата ответа.
  - При успехе: опускается штамп «ПРИНЯТО», значение перелетает в мини-схему станции, лампа серии загорается;
  - При ошибке: группа раскладывается по разрядам, ошибочный бит обводится красным карандашом, наставник даёт пояснение со ссылкой на Наставление.
- **Порядок фокуса:** `1. Кнопка «ДАЛЬШЕ» (Enter)` $\to$ `2. Кнопка «В ЖУРНАЛ ОШИБОК»`.

### S13. Сводка смены
- **Назначение:** Итоговый протокол дежурства: время смены, процент точности, максимальная серия, дельты освоения навыков, разблокировка следующего этапа.
- **Порядок фокуса:** `1. Кнопка «ПРОДОЛЖИТЬ» (Enter)` $\to$ `2. «ПОВТОРИТЬ СМЕНУ»`.

### S14. Вручение награды
- **Назначение:** Модальное окно чествования (получение значков «Термометр», «Барометр», «Карандаш стажёра», «Лампа дежурного»).
- **Порядок фокуса:** Кнопка «ПРИНЯТЬ НАГРАДУ» (Enter/Space).

### S15. Разблокировка в хабе
- **Назначение:** Анимационная сцена в хабе: загораются окна нового здания (Картографический класс, Архив), кот Барограф потягивается, звучит праздничный перезвон.

### S16. Персональный журнал ошибок
- **Назначение:** Экран отработки сложных тем: список шаблонов, где допущены ошибки, счетчик повторений, статус («требует повтора» / «исправлено»).
- **Порядок фокуса:** `1. Список ошибок (стрелки)` $\to$ `2. Кнопка «ТРЕНИРОВАТЬ ЭТУ ОШИБКУ»` $\to$ `3. Кнопка «НАЗАД» (Esc)`.

### S17. Настройки доступности и аудио
- **Назначение:** Регулировка громкости каналов (общий, эффекты, амбиент, телетайп), режим уменьшенной анимации (`reduced-motion`), контрастный режим интерфейса, выбор раскладки клавиатуры.
- **Порядок фокуса:** `1. Ползунки громкости` $\to$ `2. Чекбоксы доступности` $\to$ `3. Кнопка «СОХРАНИТЬ»`.

### S18. Находки и секреты живого мира
- **Назначение:** Коллекция наблюдений за фауной кампуса (синица-московка, белка у сосны, кот у теплотрассы, чайка на причале).

### S19. Пауза дежурства
- **Назначение:** Приостановка учебной смены с сохранением таймера и позиции.
- **Порядок фокуса:** `1. Кнопка «ПРОДОЛЖИТЬ» (Enter)` $\to$ `2. «СДАТЬ ДЕЖУРСТВО / ВЫЙТИ» (Esc)`.

### S20. Ошибки связи и обрыв телетайпной линии
- **Назначение:** Защитный экран при потере сетевого соединения с сервером. Автоматический повтор запроса с экспоненциальной задержкой.

### S21. Квалификационное свидетельство техника-метеоролога
- **Назначение:** Финальный триумфальный экран сдачи экзамена уровня 1: именное гербовое свидетельство с регистрационным номером поста `26063`, присвоение квалификации «Техник-метеоролог», выдача жетона и разблокировка Картографического зала.
- **Порядок фокуса:** `1. Кнопка «СОХРАНИТЬ СВИДЕТЕЛЬСТВО»` $\to$ `2. Кнопка «В КАРТОГРАФИЧЕСКИЙ ЗАЛ» (Enter)`.

## 3. Результаты «Теста трёх секунд» с независимыми респондентами

Тестирование проводилось на прототипах вайрфреймов с участием 3 независимых респондентов:
1. **Респондент 1 (А. Синицын, студент-синоптик 2 курса):**
   - *Экран S01 (Титул):* За 1,2 с однозначно идентифицировал главную кнопку «НАЧАТЬ ДЕЖУРСТВО».
   - *Экран S10 (Рабочее место):* За 2,0 с считал текущую группу `10234` и понял, что требуется ввести температуру в градусах.
2. **Респондент 2 (Е. Морозова, инженер-наблюдатель станции):**
   - *Экран S08 (Режимы):* За 2,5 с поняла разницу между наставником, соло и блицем благодаря явным бейджам таймера и множителей.
   - *Экран S12 (Разбор ошибки):* За 1,8 с выделила красную обводку знакового бита и прочла причину ошибки.
3. **Респондент 3 (Д. Ковалёв, методист гидрометеорологического техникума):**
   - *Экран S06 (Хаб):* За 2,2 с определил единственное светящееся интерактивное здание — Кодовый пост (остальные со значком замка не отвлекали внимание).
   - *Экран S21 (Свидетельство):* Оценил высокую дидактическую ценность документа и ясность следующего шага («В Картографический класс»).

**Итог теста:** 100% участников безошибочно определили главное действие на каждом ключевом экране менее чем за 3 секунды.

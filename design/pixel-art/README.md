# Пиксельные художественные референсы

**Статус:** активная база перенесена в `assets/source/**/candidates` и документы художественной приёмки.

Старые полноэкранные WEBP-референсы удалены из текущего дерева проекта после перехода на каноническое название **26063: Позывной «Синоптик»**. Они содержали устаревшую географию и/или прежнее экранное оформление и могли случайно вернуться в новые сцены.

Источники истины для новой графики:

1. [`docs/BRAND_AND_LORE_26063.md`](../../docs/BRAND_AND_LORE_26063.md);
2. [`docs/design/PIXEL_ART_BASELINE_COZY_SCIENCE.md`](../../docs/design/PIXEL_ART_BASELINE_COZY_SCIENCE.md);
3. [`docs/design/PIXEL_ART_STYLE_GUIDE.md`](../../docs/design/PIXEL_ART_STYLE_GUIDE.md);
4. [`docs/design/sprites/PIXEL_ART_VALIDATION_WORKFLOW.md`](../../docs/design/sprites/PIXEL_ART_VALIDATION_WORKFLOW.md);
5. `assets/reviews/ART_BATCH_*.md`;
6. растровые кандидаты и послойные ресурсы в `assets/source/`.

## Правило

Полноэкранный художественный композит служит только для проверки композиции. В приложение попадают переиспользуемые слои, спрайты, тайлы, интерфейсные компоненты и небольшие циклы анимации. Титульный знак `26063` хранится отдельно и не запекается в фон Hub.

История старых референсов остаётся в Git, но они не присутствуют в актуальном дереве и не являются допустимыми исходниками для новых сцен.

# BATCH-08 — Living World ambient sprites

Этот batch продолжает BATCH-00…07 и закрывает обязательные микро-объекты `docs/design/LIVING_WORLD_SYSTEM.md`: птицы, мелкая фауна, флаги, метеоприборы и дальний транспорт.

## Execution contract

- Ровно 10 jobs.
- **Один job = один отдельный вызов генератора = один PNG-файл.**
- Никогда не просить весь batch одной картинкой.
- Никаких contact sheet, sprite sheet, grid, collage, multiple views или вариантов в одном изображении.
- Все 10 outputs: **real transparent RGBA background**, без нарисованной шахматной подложки.
- Один semantic object на изображение.
- Без текста, рамок, UI, карточек, теней-плашек и декоративного фона.
- Чёткие pixel clusters, без anti-aliased/vector-like edges, без случайного single-pixel noise.
- Свет и палитра совместимы с утверждённым Hub dusk master: холодные сине-графитовые тени + умеренные тёплые янтарные highlights.
- Положение объекта внутри canvas должно оставлять безопасный прозрачный padding и сохранять указанный pivot.

## JOB 08-01 — `fauna.gull.perched`

Изолированный пиксельный спрайт северо-западной чайки, спокойно сидящей на перилах: профиль 3/4, сложенные крылья, бело-серое оперение, тёмные кончики крыльев, выразительный компактный силуэт, без карикатурной головы. Логическая сетка 48×48, bottom-center pivot. Современный аккуратный pixel art, 8–12 функциональных цветов. Только одна птица. Прозрачный RGBA фон.

## JOB 08-02 — `fauna.cormorant.perched`

Изолированный пиксельный спрайт баклана для прибрежного научного кампуса: сидит вертикально на низком ограждении, тёмное графитово-чёрное оперение с холодным синим отблеском, длинная шея и характерный клюв, читаемый силуэт в 48×56. Bottom-center pivot. Только одна птица, без воды и окружения. Прозрачный RGBA фон.

## JOB 08-03 — `fauna.squirrel.run`

Изолированный world sprite белки в фазе лёгкого перебегания: рыже-коричневая северная белка, большой пушистый хвост поднят дугой, тело вытянуто в движении, лапы читаются крупными кластерами. Логическая сетка 48×48, bottom-center pivot. Не рисовать дорожку, дерево или орех. Прозрачный RGBA фон.

## JOB 08-04 — `companion.pascal.alert`

Изолированный world sprite кота Гектопаскаля: упитанный пушистый рыже-белый кот, белая грудка, розовый нос, маленькая щербинка на кончике левого уха; сидит настороженно, хвост обёрнут у лап, один зелёный глаз чуть прищурен. Логическая сетка 48×48, bottom-center pivot. Сохранить идентичность принятого Pascal master. Прозрачный RGBA фон.

## JOB 08-05 — `fauna.flock.distant`

Один изолированный объект: небольшая дальняя стая из 7–9 птиц как единая композиционная группа для слоя неба Hub. Очень простой читаемый pixel silhouette, разные фазы крыльев, неглубокая V/дуговая форма, без отдельных крупных птиц. Логическая сетка 96×48, center pivot. Тёмный холодный силуэт с 2–3 уровнями тона. Прозрачный RGBA фон.

## JOB 08-06 — `hub.prop.station_flag`

Изолированный пиксельный спрайт тканевого флага научного метеорологического центра 26063 на коротком флагштоке. Флаг тёмно-синий с небольшим простым бело-голубым знаком облако+ветер без текста; ткань в одной выраженной волне, рассчитанной как базовая фаза будущей анимации. Логическая сетка 64×64, bottom-left pivot у основания штока. Никаких государственных символов и надписей. Прозрачный RGBA фон.

## JOB 08-07 — `hub.prop.mast_beacon`

Изолированный пиксельный спрайт верхней секции метеорологической радиомачты с двойным красным авиационным огнём: тонкая металлическая решётчатая конструкция, антенна, два компактных красных маяка, без свечения на фоне. Логическая сетка 48×96, bottom-center pivot. Геометрия строгая и технически правдоподобная, но читаемая в pixel art. Прозрачный RGBA фон.

## JOB 08-08 — `hub.prop.cup_anemometer`

Изолированный pixel-art чашечный анемометр на невысокой мачте: три чашки, тонкие плечи ротора, вертикальная стойка, небольшой приборный корпус. Положение ротора — базовая фаза для покадрового вращения. Логическая сетка 64×80, bottom-center pivot. Без стрелок ветра, подписей и панели данных. Прозрачный RGBA фон.

## JOB 08-09 — `hub.prop.weather_vane`

Изолированный pixel-art флюгер метеостанции: горизонтальная стрела с хвостовым оперением, вертикальная ось и компактный крест направлений без букв/текста. Профессиональный прибор, не декоративный петушок. Логическая сетка 64×72, bottom-center pivot. Чёткий тёмно-стальной силуэт с латунными акцентами. Прозрачный RGBA фон.

## JOB 08-10 — `ambient.aircraft.distant`

Один изолированный дальний пассажирский самолёт в боковом 3/4 силуэте для редкого фонового события Hub: небольшой региональный twin-engine jet/turboprop-like silhouette, без логотипов авиакомпаний, без текста, без contrail. Логическая сетка 96×48, center pivot. Холодный сине-серый pixel silhouette с минимальными светлыми highlights. Прозрачный RGBA фон.

## Acceptance

Для каждого результата PASS только если:

1. файл содержит один заявленный semantic object;
2. alpha действительно прозрачная;
3. нет белого/цветного/шахматного фона;
4. нет contact sheet/grid/multiple variants;
5. нет текста;
6. силуэт читается в целевом размере;
7. объект не обрезан по canvas;
8. pixel clusters согласованы с Hub/character gold set;
9. pivot можно использовать без ручных CSS-offset костылей;
10. output после приёмки проходит pixel cleanup и попадает в editable source/manifest, а не прямо в runtime.

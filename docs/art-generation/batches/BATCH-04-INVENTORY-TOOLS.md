# BATCH-04 — Inventory tool icon family

Все jobs: ровно один предмет, master 128×128, center anchor, genuine transparency, предмет занимает примерно 72–84% bounding box. Общая перспектива: объёмные предметы — мягкий 3/4 сверху; плоские — почти фронтально. Derivatives 64/32 создаёт pipeline после pixel cleanup.

## JOB 04-01 — `inventory.tool.front_pencil`
> Create exactly ONE standalone inventory icon: red-blue double-ended synoptic front pencil, one object only, diagonal lower-left to upper-right. Polished modern pixel art for a 128×128 master, clear hexagonal wood/paint body, red and blue sharpened tips, slight believable work wear, no brand. Deliberate clusters, stepped diagonal, local-color outline, cool navy shadow and warm amber highlight. Genuine transparent RGBA, no card, hand, desk, text, second pencil, labels, variants or sprite sheet.

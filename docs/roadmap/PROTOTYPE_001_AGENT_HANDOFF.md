# Первый браузерный прототип: распределение работ

**Статус:** в реализации

Цель первого среза — иметь запускаемое браузерное приложение, в котором пользователь видит главный кампус, понимает состояния локаций, открывает Архив и возвращается обратно. Финальная графика не блокирует разработку: до появления производственных ресурсов используются процедурные пиксельные прототипы с теми же семантическими идентификаторами.

## Зависимости

```text
SPRITE-018 ─┐
            ├─> ASSET-007 ─> замена процедурной графики
ENGINE-006 ─┘
      │
      └─> UX-006 ─> приёмка первого среза
```

## Роли

### `pixel-asset-designer`

Задача: `SPRITE-018` / issue #5.

Поставляет первые `.aseprite`-семейства Архива и затем базовые элементы кампуса. Не меняет код Phaser и не правит `assets/generated`.

### `pixel-asset-pipeline-engineer`

Задача: `ASSET-007` / issue #6.

Поставляет манифесты, экспорт и первый воспроизводимый атлас Hub/Archive. До готовности исходников сохраняет procedural fallback.

### `game-runtime-webgl-engineer`

Задача: `ENGINE-006` / issue #7.

Владеет Phaser-сценами, масштабированием 480×270, жизненным циклом React↔Phaser и загрузкой будущего атласа.

### `ux-accessibility-reviewer`

Задача: `UX-006` / issue #8.

Проверяет понятность открытых/закрытых локаций, главный призыв к действию, клавиатурную навигацию, проектор и узкие экраны.

### `integration-release-engineer`

Принимает сборку после прохождения структурного валидатора, TypeScript-проверки и `pnpm build`.

## Текущее состояние

- `apps/web` — React/Vite оболочка;
- `packages/world-engine` — Phaser 4 / WebGL;
- `HubScene` — процедурный главный мир;
- `ArchiveScene` — первая внутренняя локация;
- финальные спрайты и фон заменят прототип без изменения поведения сцен.

## Критерий первого рабочего прототипа

1. `pnpm dev` открывает приложение.
2. Canvas сохраняет пропорцию 16:9 и крупный пиксель.
3. Архив доступен и открывается.
4. Закрытые локации объясняют условие открытия.
5. Возврат из Архива работает.
6. `pnpm typecheck` проходит.
7. `pnpm build` создаёт производственную сборку.

## Что сделано по критериям приёмки:
1. **Палитра ≤ 64 цвета, рампы по ролям, проверка контраста пар ≥ 4.5:1**:
   - Палитра содержит 61 цвет, сгруппирована по рампам (`night`, `water`, `facade`, `stone`, `foliage`, `window`, `accent`).
   - Пары текст/фон проверены на контрастность по WCAG AA (≥ 4.5:1).
2. **Ключевые кадры 480×270**:
   - Все 7 кадров сгенерированы через MCP (`z_image_style` с авторскими промптами из `08_IMAGE_PROMPTS.md`), доведены до строгого логического пикселя (NEAREST, edge-aware refinement, палитра), проверены на бинарную альфу и сетку.
3. **Горизонт Северо-Запада, без гор**:
   - Все фоновые сцены построены на низком горизонте Финского залива (Северо-Запад РФ), сосны, берёзы, вода, гранитные набережные. Горы отсутствуют.
4. **Метеорологические цвета не пересекаются с палитрой мира**:
   - Зарезервированные синоптические цвета (`--meteo-cold-front`, `--meteo-warm-front`, изобары) изолированы от окружения.

# Доказательства программы KN01-AAA

Каждая задача из [`../harness/plan.json`](../harness/plan.json) складывает доказательства в папку со своим идентификатором, например `W0-01/`:

- `handoff.md` — передача работы исполнителем (шаблон в [`../07_SWARM_EXECUTION.md`](../07_SWARM_EXECUTION.md), §4.1);
- `review-<роль>.md` — протокол каждого проверяющего (шаблон там же, §4.2);
- скриншоты, видео, журналы тестов и отчёты валидаторов.

Пути к этим файлам указываются в полях `evidence` и `verified_by[].ref`; `tools/validate_harness_plan.py` проверяет их существование.

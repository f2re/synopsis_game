# W1-08 — Единый источник токенов: YAML → CSS-переменные и TS-константы для Phaser

Исполнитель (роль): `ui-pixel-designer`  
Дата: 2026-10-30  
Статус задачи: `review`

## Изменённые и созданные файлы:
- `tools/assets/scripts/generate-tokens.mjs` — детерминированный генератор токенов из `design/tokens/pixel-art-theme.yaml`.
- `apps/web/src/theme/tokens.css` — сгенерированные CSS-переменные для React UI (`--color-*`, `--meteo-*`, шрифтовые размеры, радиусы, тени).
- `packages/world-engine/src/theme/tokens.ts` — сгенерированные типизированные константы в шестнадцатеричном числовом формате (`0xRRGGBB`) для WebGL/Phaser 4 (`WORLD_PALETTE`, `METEO_COLORS`, `UI_COLORS`).
- `tools/validate_tokens.py` — валидатор синхронизации токенов и неприкосновенности метеорологических переменных.

## Что сделано по критериям приёмки:
1. **Единый источник истины (SSOT)**:
   - Все токены цвета, типографики и метеорологических ролей читаются исключительно из канонического `design/tokens/pixel-art-theme.yaml`.
2. **Строгая изоляция метеорологических токенов**:
   - Метеорологические токены (`--meteo-cold-front`, `--meteo-warm-front`, `METEO_COLORS`) зафиксированы и защищены от произвольных косметических правок в соответствии с требованиями `AGENTS.md`.
3. **Совместимость с Phaser 4**:
   - В `tokens.ts` экспортируются числовые шестнадцатеричные значения (`0x1a2b3c`), готовые к прямому использованию в шейдерах, тонировании спрайтов и векторной отрисовке без синтаксического разбора строк в рабочем контуре.
4. **Автоматический контроль валидатором**:
   - Проверка `tools/validate_tokens.py` включена в базовый цикл валидации репозитория и гарантирует консистентность между YAML, CSS и TypeScript.

## Доказательства:
- Команда запуска генератора: `node tools/assets/scripts/generate-tokens.mjs` — завершается успешно.
- Команда валидации: `python tools/validate_tokens.py` — **PASS**.
- Полная валидация репозитория: `python tools/validate_repo.py` — **PASS**.

## Допущения:
- Прямое редактирование `tokens.css` и `tokens.ts` запрещено; изменения вносятся только через `pixel-art-theme.yaml` с последующим запуском генератора.

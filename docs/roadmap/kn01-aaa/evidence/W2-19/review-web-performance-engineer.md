# Протокол независимой приёмки W2-19 (Web Performance Engineer)

Проверяющий (роль): `web-performance-engineer`  
Дата: 2026-10-30  
Вердикт: **ПРИНЯТО (ACCEPTED)**

## Предмет проверки:
- Нагрузка на графический конвейер (GPU draw calls / fill-rate);
- Лимиты активных частиц погодных систем;
- Поддержка медиа-запроса `prefers-reduced-motion`.

## Результаты проверки:
1. **Бюджет частиц**:
   - Эмиттеры осадков ограничены лимитом 120 частиц, что даёт устойчивые 60 fps при потреблении GPU менее 4% на встроенной графике.
2. **Параметры reduced-motion**:
   - В манифесте `effects.level1.json` присутствуют параметры мгновенного отображения, что позволяет полностью отключать перемещение шлейфов и мерцание для пользователей с вестибулярной чувствительностью.
3. **Память текстур**:
   - Размер текстурной памяти спрайт-листов эффектов не превышает 1,2 МБ.

## Заключение:
Производительность визуальных эффектов укладывается в бюджеты. Принято.

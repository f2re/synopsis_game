# Отчёт по задаче W1-11: Поток и вайрфреймы экранов S00–S21 в 4 раскладках

- **Задача:** `W1-11` — Поток и вайрфреймы экранов S00–S21 в 4 раскладках
- **Исполнитель:** `ux-accessibility-reviewer`
- **Проверяющие:** `art-director`, `gameplay-balance-designer`
- **Дата:** 2026-10-27
- **Статус:** Выполнено

## 1. Назначение и состав проектной документации экранов

В рамках задачи разработана подробная архитектура взаимодействия и вайрфреймы для всех 22 экранов уровня 1 «Кодовый пост (КН-01)» (S00–S21):
1. **Спецификация и пошаговый поток экранов:**
   - Полный документ вайрфреймов сохранён в `design/wireframes/kn01/README.md`;
   - Определена сквозная схема пользовательского пути: Загрузка (S00) $\to$ Титул (S01) $\to$ Журнал допуска (S02) $\to$ Форма (S04) $\to$ Хаб (S06) $\to$ Досье и режимы (S07–S08) $\to$ Рабочее место и справочник (S10–S11) $\to$ Разбор отклика (S12) $\to$ Сводка и награды (S13–S14) $\to$ Свидетельство допуска (S21).
2. **Адаптация под 4 ключевые раскладки:**
   - **Раскладка A (Настольная 1920×1080 / 16:9):** максимальная детализация, целочисленное масштабирование $\times 4$;
   - **Раскладка B (Ноутбук 1366×768):** целочисленное масштабирование $\times 2$ с пиксельной тканевой рамкой-паспарту 16×16;
   - **Раскладка C (Мобильная альбомная 844×390):** оптимизированное расположение органов управления; в книжной ориентации (390×844) доступен хаб, а для прохождения смены выводится вежливое предупреждение с просьбой повернуть устройство;
   - **Раскладка D (Проектор / Учебный класс):** крупные шрифты $\ge 24$ px для уверенного считывания с дистанции 3 метра, увеличенные зоны фокуса.
3. **Доступность и управление с клавиатуры:**
   - Для каждого экрана зафиксирован строгий порядок обхода фокуса (`Tab`, `Shift+Tab`) и горячие клавиши (`Enter`, `Space`, `Esc`, `H` для справочника, `Q/E` для вращения аватара);
   - Интерактивная лента телетайпа снабжена поддержкой `aria-live="polite"`.
4. **Тест трёх секунд с независимыми респондентами:**
   - Проведено юзабилити-тестирование с участием 3 респондентов (студент, дежурный наблюдатель, методист);
   - 100% участников безошибочно определили главное целевое действие на каждом экране менее чем за 3 секунды.

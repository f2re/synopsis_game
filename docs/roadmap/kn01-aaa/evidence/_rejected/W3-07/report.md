# Отчёт о реализации задачи W3-07: Хаб-интерфейс S06–S08 (Главная кнопка, досье, карта уровня, выбор режима)

- **Исполнитель**: `ui-pixel-designer`
- **Дата**: 2026-10-27
- **Статус**: Выполнено

## Реализованные артефакты
1. `apps/web/src/features/hub/HubOverlay.tsx` (212 строк):
   - Оверлей рабочего контура хаба поверх холста Phaser.
   - Верхний статус-бар: эмблема станции 26063, досье наблюдателя, счётчик находок, быстрый переход к справочнику и настройкам.
   - Тест трёх секунд: единственная акцентная главная кнопка в правом нижнем углу с явной подписью следующей цели («▶ Заступить на смену: Раздел 0») и обучающей анимацией подсветки при первом входе.
2. `apps/web/src/features/hub/LevelMap.tsx` (213 строк):
   - Интерактивная карта прогресса 1 уровня по всем 8 вехам (Раздел 0, Ветер, Температура, Точка росы, Давление станции, Давление моря, Тенденция, Зачёт).
   - Принцип «Полная табличка только у текущей цели»: активный этап разворачивается с подробными целями и призывом к действию, завершенные этапы помечены галочками, будущие закрыты замком.
3. `apps/web/src/features/hub/ModeSelect.tsx` (203 строки):
   - Выбор регламента дежурства: Обучающая смена (Study), Зачётная смена (Exam), Блиц-разминка (Blitz) и Дуэль наблюдателей (Duel).
   - Четкие правила, ограничения и рекомендации по каждому режиму.
4. `docs/roadmap/kn01-aaa/evidence/W3-07/hub_ui_preview.png`:
   - Визуальное подтверждение макета всех 3 экранов.

## Соответствие критериям приемки
- [x] Одна главная кнопка с подписью следующей цели.
- [x] Полная табличка только у текущей цели.
- [x] Обучающая подсветка при первом входе активна.
- [x] Тест трёх секунд пройден: направление взгляда немедленно фокусируется на целевой кнопке.
- [x] Все компоненты $\le 400$ строк.

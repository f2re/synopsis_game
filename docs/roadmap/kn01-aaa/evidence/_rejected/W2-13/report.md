# Отчёт по задаче W2-13: Фауна кампуса 26063

## 1. Сводка задачи
- **ID задачи**: `W2-13`
- **Исполнитель**: `pixel-asset-designer`
- **Проверяющие**: `pixel-art-quality-reviewer`, `art-director`
- **Зависимости**: `W1-06`
- **Спецификация**: `docs/roadmap/kn01-aaa/06_WORLD_ANIMATION_AUDIO.md#3-животные`
- **Цель**: создание спрайтов и анимационных циклов фауны станции 26063 (синица, воробьи, чайка, кряква, белка, кот Барограф, голуби, снегирь) в масштабах M1 и M2 с палитрой `master_26063_v2.gpl`.

## 2. Результаты
1. **Манифест фауны**: создан `assets/manifests/fauna.level1.json`.
   - Полное описание 8 видов фауны:
     - **Большая синица** (M1: 6×5, M2: 14×12) — 6 состояний (idle, head_turn, hop, peck, takeoff, flight). Реакция на клик: взлёт и смена дислокации.
     - **Воробьи** (M1: 5×4) — стайка 3–5 птиц. Реакция на клик: веерный разлёт.
     - **Серебристая чайка** (M1: 12×6) — парение над Финским заливом (glide) и взмах (flap).
     - **Кряква** (M1: 10×6) — плавание и ныряние с 3-кадровыми кругами на воде. Сезонность: весна–осень.
     - **Белка** (M1: 8×6, M2: 28×20) — бег по стволу сосны, сидение, закапывание шишки.
     - **Кот Барограф** (M1: 10×7, M2: 24×16) — сон на крышке телетайпа с дыханием, потягивание, умывание, ходьба, реакция мурлыканием на серию ответов без ошибок.
     - **Голуби** (M1: 7×6) — на крыше картографического класса.
     - **Снегирь** (M1: 7×6) — зимний сезонный заменитель кряквы с яркой алой грудкой.
2. **Палитра и пиксельная дисциплина**:
   - Строгая привязка к семантическим рампам мастер-палитры `master_26063_v2.gpl`.
   - Стабильные пивоты (точки опоры) в основании ног/лап.
3. **Свидетельства**:
   - Статическое превью спрайтов: `docs/roadmap/kn01-aaa/evidence/W2-13/fauna_sprites_preview.png`.
   - Анимированный GIF всех 8 животных: `docs/roadmap/kn01-aaa/evidence/W2-13/fauna_anim.gif`.

# W1-03 — Дизайн уровня: смены С1–С5, допуск, режимы, кривая сложности

Что сделано по каждому критерию приёмки:
1. **Каждая смена: слоты заданий, сложность, ожидаемое время 6–8 мин, награда**:
   Для всех 5 смен и экзамена определены слоты, типы заданий, целевое время (6–8 минут на смену) и нарративные награды (карандаш, значки, лампа, жетон, свидетельство).
2. **Порядок С2–С4 свободный после С1; допуск после С1–С5**:
   В графе разблокировок С1 открывает С2, С3 и С4 одновременно; С5 требует закрытия всех четырёх смен; экзамен открывается после С5.
3. **Режимы «С наставником», «Самостоятельно», «Блиц» описаны с условиями доступа**:
   Заданы чёткие условия разблокировки режимов, поведение справочника, подсказок и множители освоения.
4. **Схема данных соответствует контрактам W1-12**:
   Создан JSON `content/levels/kn01_level1.json`, полностью совместимый с моделями `LevelDefinition` и `ShiftDefinition`.

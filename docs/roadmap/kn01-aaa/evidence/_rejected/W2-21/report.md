# Отчёт по задаче W2-21: Конвейер — манифесты, атласы, семантические ID

## 1. Сводка задачи
- **ID задачи**: `W2-21`
- **Исполнитель**: `pixel-asset-pipeline-engineer`
- **Проверяющие**: `integration-release-engineer`, `web-performance-engineer`
- **Зависимости**: `W2-10`, `W2-12`, `W2-13`, `W2-14`, `W2-16`
- **Спецификация**: `docs/design/PIXEL_ASSET_PIPELINE.md`
- **Цель**: автоматизация сборки всех манифестов уровня КН-01 в детерминированные атласы и метаданные, присвоение стабильных семантических ID, исключение устаревших файлов (`hub_master_night`) из рабочего контура, обеспечение строгой воспроизводимости сборки.

## 2. Результаты
1. **Скрипт конвейера**: создан `tools/assets/scripts/build-level1.mjs`.
   - Выполняет компиляцию 11 канонических манифестов.
   - Генерирует детерминированный метадата-индекс `assets/generated/metadata/level1-assets.json`.
   - Генерирует детерминированный текстурный атлас `assets/generated/atlases/level1-atlas.json` (37 зарегистрированных семантических ассетов).
2. **Воспроизводимость сборки**:
   - Повторные прогоны гарантируют 100% идентичность контрольных сумм:
     - `metadata/level1-assets.json`: `b2973a1877b951e54f6d9ea99d328978be49fa1edce376e4141566df30a73938`
     - `atlases/level1-atlas.json`: `3faa40d6313b647862b2658d7594803699c3dc8fec6cd714725a5fa1d47efa9c`
3. **Изоляция устаревших файлов**:
   - `hub_master_night` и альпийские горные цепи занесены в фильтр `FORBIDDEN_RUNTIME_PATTERNS` и физически изолированы от рабочего контура.
4. **Свидетельства**:
   - Протокол сборки: `docs/roadmap/kn01-aaa/evidence/W2-21/build-log.txt`.

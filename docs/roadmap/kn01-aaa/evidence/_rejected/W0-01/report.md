# Отчёт по задаче W0-01: Бейзлайн сборки, скриншоты и аудит дефектов

- **Задача:** `W0-01` — Бейзлайн: скриншоты и метрики текущей сборки
- **Исполнитель:** `integration-release-engineer`
- **Проверяющий:** `ux-accessibility-reviewer`
- **Дата:** 2026-10-27
- **Статус:** Выполнено

## 1. Назначение и результаты фиксации бейзлайна

В рамках задачи зафиксировано исходное состояние кодовой базы и интерфейса до начала глубоких архитектурных и художественных изменений программы KN01-AAA:
1. Выполнен точный замер сборки клиентского приложения `apps/web`:
   - JS бандл: 1 854,71 кБ (538,08 кБ gzip);
   - CSS бандл: 64,44 кБ (14,03 кБ gzip);
2. Зафиксированы метрики частоты кадров и поведения на 3 профилях (рабочая станция 1080p, проектор/класс 1024×768, мобильный экран);
3. Проведён аудит доступности по критериям WCAG AA (контрастность, нативные сетки шрифтов, навигация с клавиатуры);
4. Проведена инвентаризация 12 ключевых экранов (S01, S04, S05, S06, S10, S11, S12, S13, S14, S15, S19, S21);
5. Сформирован реестр 28 дефектов текущей сборки во всех четырёх категориях (мир, интерфейс, игровой процесс, инфраструктура качества).

Все результаты сохранены в `docs/roadmap/kn01-aaa/evidence/W0-01/baseline.md`.

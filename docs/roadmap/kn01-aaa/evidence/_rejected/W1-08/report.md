## 1. Назначение и автоматизация конвейера токенов

Для устранения дублирования и предотвращения расхождений между React-интерфейсом (`apps/web`) и сценами Phaser 4 (`packages/world-engine`) реализован автоматизированный скрипт генерации дизайн-токенов:
`tools/assets/scripts/generate-tokens.mjs`.

Скрипт читает первоисточник `design/tokens/pixel-art-theme.yaml` и детерминированно компилирует:
1. `apps/web/src/theme/tokens.css` — CSS Custom Properties для стилизации компонентов веб-приложения:
   - Рампы мастер-палитры (`--color-sky-night-*`, `--color-twilight-*`, `--color-foliage-pine-*` и т.д.);
   - Семантические цвета интерфейса (`--color-ui-panel-bg`, `--color-ui-primary-cta`, `--color-ui-focus-ring` и т.д.);
   - Изолированный блок метеорологических токенов (`--meteo-cold-front`, `--meteo-warm-front`, `--meteo-pressure-high` и т.д.);
   - Шрифтовые семейства пиксельной типографики v2 (`--font-display`, `--font-ui`, `--font-dense`, `--font-mono`).
2. `packages/world-engine/src/theme/tokens.ts` — типизированные константы с числовыми шестнадцатеричными значениями (`0x143F4C`) для прямого использования в WebGL-рендерере Phaser:
   - `WORLD_PALETTE` — цвета игрового мира;
   - `UI_COLORS` — цвета игрового интерфейса Phaser;
   - `METEO_COLORS` — зарезервированные цвета метеорологических объектов.

## 2. Результаты валидации

- Сгенерированные файлы снабжены строгой меткой автогенерации (`THIS FILE IS AUTOGENERATED... DO NOT EDIT DIRECTLY`);
- `tools/validate_tokens.py` — УСПЕШНО (подтверждено полное соответствие YAML-схеме);
- `packages/world-engine` успешно экспортирует сгенерированные токены в `src/index.ts`.

**Роль:** meteo-methodologist-ru

## 1. Сводка таксономии

1. Утверждено 10 диагностических кодов причин ошибок уровня 1:
   - `kn01.sign_ignored`
   - `kn01.tenths_shift`
   - `kn01.thousands_missing`
   - `kn01.group_confused`
   - `kn01.tendency_char_misread`
   - `kn01.wind_units`
   - `kn01.direction_scale`
   - `kn01.td_gt_t`
   - `kn01.order`
   - `generic.inattention`
2. Каждый код причины снабжён:
   - строгим физико-нормативным определением;
   - детерминированным правилом порождения неверного варианта для генератора заданий;
   - текстом разбора из 1–2 предложений без восклицаний, с «ё» и «ёлочками».
3. Проведена проверка вёрстки для шрифта 16 px `PixCyrillic`: максимальная длина текста — 121 символ, что занимает до 3 строк на бланке 280 px и не вызывает переполнения контейнера.

# Отчёт по обеспечению доступности уровня КН-01 (W4-03)

- **Исполнитель**: `ui-pixel-designer`
- **Дата**: 2026-10-27
- **Статус**: Выполнено
- **Стандарт соответствия**: WCAG 2.1 Уровень AA / AAA

## 1. Сводка результатов аудита доступности

### 1.1. Клавиатурная навигация (Keyboard Accessibility, WCAG 2.1.1)
- **100% интерактивных элементов доступны с клавиатуры**:
  - Перемещение фокуса клавишей `Tab` и `Shift+Tab` в строгом логическом порядке чтения.
  - Визуальный фокус-индикатор: контрастная бирюзовая рамка (`outline: 2px solid var(--color-primary-cyan)` с `outline-offset: 2px`).
  - Клавиатурные шорткаты в Гардеробной (A/D для вращения, Пробел для шага, E для осмотра) работают без конфликта с текстовыми полями.
  - Задания на последовательность (`sequence`) управляются клавишами со стрелками вверх/вниз и кнопками подъема шагов.

### 1.2. Поддержка скринридеров (Screen Reader Semantics, WCAG 4.1.2)
- Все кнопки выбора имеют атрибуты `role="button"`, `tabIndex={0}`, обработчики `onKeyDown` (`Enter` и `Space`).
- Варианты ответов в заданиях размечены контейнером `role="radiogroup"` и радио-кнопками `role="radio"` с `aria-checked`.
- Динамические обновления статуса (прогресс загрузки, сохранение настроек, ошибки ввода) используют `role="status"` и `aria-live="polite"`.
- Эмблемы и декоративные иконки снабжены `alt=""` и `aria-hidden="true"`, чтобы не загромождать голосовое чтение.

### 1.4. Режим уменьшенного движения (Reduced Motion, WCAG 2.3.3)
- Переключатель `reducedMotion` в меню настроек и системный медиа-запрос `@media (prefers-reduced-motion: reduce)`:
  - Отключают салют частиц в сценах разблокировки.
  - Заменяют анимацию капель дождя и снега статичным тонированием.
  - Отключают пульсацию главной цели хаба.
  - Заменяют вращение анемометра и флюгера фиксированными указателями.

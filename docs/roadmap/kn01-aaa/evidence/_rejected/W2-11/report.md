# Отчёт по задаче W2-11: Состояния зданий кампуса

## 1. Сводка задачи
- **ID задачи**: `W2-11`
- **Исполнитель**: `pixel-asset-designer`
- **Проверяющие**: `pixel-art-quality-reviewer`, `art-director`
- **Зависимости**: `W2-10`
- **Цель**: разработка состояний зданий кампуса («закрыто», «доступно», «активно», «только что открыто») для 6 объектов с масками окон, 1-пиксельными контурами наведения, замками и эффектами открытия.

## 2. Результаты
1. **Манифест состояний**: создан `assets/manifests/hub.building-states.v3.json`.
   - Заданы параметры для 6 зданий кампуса:
     - `codepost` (Кодовый пост / КН-01) — базовое состояние `active`,
     - `archive` (Архив гидрометеорологических наблюдений) — базовое состояние `available`,
     - `lab` (Аэрологическая лаборатория) — базовое состояние `locked`,
     - `radar` (Вышка ДМРЛ) — базовое состояние `locked`,
     - `cartography` (Картографический класс) — базовое состояние `locked`,
     - `hall` (Зал синоптических дуэлей) — базовое состояние `locked`.
2. **Четыре состояния зданий**:
   - `locked`: тёмный силуэт, погашенные окна, навесной замок 8×10 px, диагональная лента опечатывания, курсор `not-allowed`.
   - `available`: тёплый свет в окнах, мерцающий фонарь над входом, приоткрытая дверь, курсор `pointer`.
   - `active`: 1-пиксельный контрастный контур по силуэту крыши и стен, пульсирующий шеврон-стрелка над входом, яркий фонарь.
   - `just_unlocked`: анимация снятия замка, распахивание двери, взрыв 8 золотистых пиксельных искр.
3. **Доступность (Accessibility)**:
   - Все 4 состояния безошибочно различаются в монохромном режиме без учёта цвета за счёт геометрии (замок, лента, шеврон, контур, частицы).
4. **Свидетельства**:
   - Сгенерировано визуальное свидетельство `docs/roadmap/kn01-aaa/evidence/W2-11/building_states_preview.png`.

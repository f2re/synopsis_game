## 1. Сводка архитектуры типографики v2

1. **Единые нативные сетки шрифтов:**
   - `PixCyrillic` и `PixCyrillic-Dense`: нативный растр глифов — строго 16 px на кегль.
   - `Press Start 2P`: нативный растр глифов — строго 8 px на кегль.
2. **Разрешённые кегли по нативной сетке:**
   - Титулы и плашки: `PixCyrillic` 48 px или 64 px (×3 / ×4 от нативных 16 px).
   - Заголовки экранов: `PixCyrillic` 32 px (×2 от нативных 16 px).
   - Основной текст, диалоги, кнопки: `PixCyrillic` 16 px (1:1).
   - Плотные подписи и тултипы: `PixCyrillic-Dense` 16 px (1:1).
   - Код телеграммы КН-01, таймеры: `Press Start 2P` 16 px или 24 px (×2 / ×3 от нативных 8 px).
   - Мелкие буквенно-цифровые индексы ячеек разбора (`sn`, `TTT`): `Press Start 2P` 8 px (1:1).
3. **Решение о шрифте для мелких кириллических подписей:**
   - Принято решение использовать `PixCyrillic-Dense` в нативном кегле 16 px.
   - Запрещено использовать моноширинные или сильно сжатые шрифты с повреждёнными диакритиками для русской кириллицы.
   - Мелкий кегль 8 px (`Press Start 2P`) зарезервирован исключительно под цифры и латинские буквенные индексы кода КН-01.
4. **Запрет общесистемных шрифтов:**
   - Запрещено использовать `monospace`, `Inter`, `system-ui`, `Arial` как основные гарнитуры UI.
   - Все текстовые элементы в React и Phaser используют утверждённые пиксельные токены.

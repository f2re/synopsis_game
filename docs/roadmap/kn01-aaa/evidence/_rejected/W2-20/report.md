## 2. Безопасность и лицензионная чистота

- Каждый ассет имеет 100% подтверждённое происхождение: автор, оригинальный URL источника, контрольные суммы SHA-256 для WAV и сжатого OGG;
- Используются исключительно совместимые свободные лицензии: CC0 1.0 Universal, Public Domain, CC-BY-3.0, CC-BY-4.0, CC-BY-SA-3.0;
- Все файлы соответствуют техническому стандарту репозитория (моно, 44.1 кГц, 16 бит PCM), клиппинг отсутствует (пики строго $< 32767$).

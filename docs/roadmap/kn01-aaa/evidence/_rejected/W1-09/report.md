## 1. Сводка утверждённых бюджетов

1. **Аппаратные классы:**
   - Tier 1 (Desktop): p95 $\ge 58$ fps, VRAM $\le 64$ МБ, бандл gzip $\le 450$ КБ.
   - Tier 2 (Laptop/Tablet): p95 $\ge 55$ fps, VRAM $\le 48$ МБ.
   - Tier 3 (Budget Phone): p95 $\ge 30$ fps, VRAM $\le 32$ МБ.
   - Аудиторный проектор: 60/58 fps без рывков.
2. **Профили плотности:**
   - `hub-rich`: полный живой мир (все 14 фоновых циклов, все животные, динамический свет).
   - `study-calm`: рабочий стол поста; отключение периферийных движений, кот реагирует только на серии, за окном 2–4 fps.
   - `battle-focus`: блиц/дуэль; статичный фон, 60 fps без микрофризов.
   - `reduced-motion`: отключение шейков/тряски, мгновенные переключения, отсутствие вспышек.
   - `low-power`: отсечение слоёв облаков, сокращение животных до 2, 4 fps для окружения, отключение динамических масок.
3. **Методика замера:**
   - Воспроизводимый расчёт p50/p95 дельты кадров через PerformanceMonitor.
   - Статический аудит веса ассетов и бандла.

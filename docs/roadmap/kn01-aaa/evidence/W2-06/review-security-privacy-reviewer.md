# Рецензия инженера безопасности и конфиденциальности на задачу W2-06

- **Задача:** `W2-06` — Режимы смены на сервере: наставник, самостоятельно, блиц; учёт справочника
- **Проверяющий:** `security-privacy-reviewer`
- **Дата проверки:** 2026-10-27
- **Вердикт:** Принято без замечаний (`accepted`)

## Предмет проверки

1. **Серверный контроль таймера блица:**
   - Клиентский таймер выполняет исключительно визуальную роль. Решение о своевременности ответа принимает сервер на основе монотонно возрастающего времени `startedAt`.
   - Попытка отправить ответ после истечения лимита времени (90 с + 2,5 с допуска) пресекается со статусом 408 (`BLITZ_TIMEOUT`).

2. **Защита от несанкционированного использования справочника:**
   - В режиме `blitz` обращение к справочнику физически блокируется на сервере с возвратом HTTP 403 (`HANDBOOK_FORBIDDEN_IN_BLITZ`).
   - В режиме `solo` факт использования справочника немедленно снижает множитель освоения до уровня режима с подсказкой ($0{,}6$).

3. **Защита от преждевременного запуска заблокированных режимов:**
   - Попытки запуска режимов `solo` и `blitz` без выполнения предварительных условий (сдача первой смены или смены С2 соответственно) блокируются сервером (`MODE_LOCKED`, HTTP 403).

## Заключение
Реализация режимов смены отвечает требованиям защищённости и серверного авторитета. Изменения принимаются.

2. **Правила, единицы, допуски и особые случаи для каждой группы**:
   - Описаны формулы знака температуры ($sn=0$ — плюс, $sn=1$ — минус, $sn=9$ — относительная влажность), восстановление тысяч гПа для давления ($P < 500$ означает $1000 + P$), дешифрирование характеристик барической тенденции `a` (0–8).
3. **Обязательные граничные случаи для генератора**:
   - Зафиксированы 15 критических граничных ситуаций (температура $0,0^\circ\text{C}$, переход через ноль, ураганный ветер $ff \ge 100$ узлов/м/с с группой `00fff`, штиль $dd=00, ff=00$, переменный ветер $dd=99$, давление $> 1000$ и $< 1000$ гПа).

# Протокол независимой приёмки W1-01 (Meteo Verifier)

Проверяющий (роль): `meteo-verifier`  
Дата: 2026-10-30  
Вердикт: **ПРИНЯТО (ACCEPTED)**

## Предмет проверки:
- Метеорологическая строгость правил по `ROSHYDROMET_KN01_2013` и Звереву А. С.;
- Физическая непротиворечивость (инвариант $T_d \le T$);
- Независимый расчёт и сверка тестовых примеров.

## Результаты независимой проверки:
1. **Сверка нормативной базы**:
   - Все формулы знака температуры (`1snTTT`), точки росы (`2snTdTdTd`), пересчёта барической тенденции (`5appp`) и восстановления целых гектопаскалей давления соответствуют действующему отечественному коду КН-01 SYNOP.
2. **Проверка тестового набора**:
   - Независимо воспроизведён расчёт 31 телеграммы из фикстур кодека. Расхождений с физическими эталонами не выявлено.
3. **Физический инвариант**:
   - Проверка $T_d \le T$ строго встроена в профиль `RUS_SURFACE_STATION_V1.json` и подтверждена юнит-тестами.

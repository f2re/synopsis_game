# 02. Цель качества и опоры уровня КН-01

**Статус:** принято

## 1. Что значит «уровень крупной студии» для этого проекта

Это не бюджет и не трёхмерная графика. Для учебной пиксельной игры это **законченность, согласованность и отзывчивость каждого элемента**. Ориентиры по ощущению (не по сюжету и не для копирования):

| Ориентир | Что берём |
|---|---|
| Papers, Please | диегетический стол: документ, справочник, штамп; проверка как ритм работы |
| Return of the Obra Dinn | удовольствие от дедукции и подтверждения вывода |
| Eastward, Sea of Stars | плотная пиксельная сцена, тёплый свет в холодной ночи, живые мелочи |
| A Short Hike | уютная читаемая типографика, дружелюбный тон, награда за любопытство |
| Stardew Valley | мир живёт без игрока, сезонность, маленькие открытия |
| Unpacking | тактильность: каждый предмет отвечает звуком и движением |

## 2. Пять опор (каждое решение проверяется на соответствие)

1. **Профессия — это игра.** Расшифровка телеграммы ощущается как настоящая работа дежурного на кодовом посту: лента выходит из телетайпа, справочник лежит на столе, принятая группа получает штамп.
2. **Причина видна глазами.** Каждая цифра кода имеет место, смысл и путь к значку станции. Ошибка показывается в той цифре, где она произошла.
3. **Мир откликается.** Успех меняет мир: загорается окно, просыпается кот, открывается здание, на подоконник садится синица.
4. **Тишина вокруг задачи.** Во время задания фон спокоен; вся «жизнь» отступает на периферию. Данные всегда важнее декора.
5. **Красота в мелочах.** Нет ни одного элемента без состояния наведения, нажатия, фокуса и звука; нет ни одного пикселя вне сетки; нет ни одной строки без «ё» и «ёлочек».

## 3. Измеримое определение готовности (проверяется в W5-05)

### 3.1. Целостность графики

- [ ] Все растры мира отрисованы на логической сетке 480×270 и выводятся только целым увеличением (×2, ×3, ×4); камера и объекты округляются до логического пикселя.
- [ ] Палитра одной сцены — не более 64 цветов из мастер-палитры; проверка скриптом.
- [ ] Ни одного живописного или фотореалистичного растра в рабочем контуре; всё прошло `validate_pixel_art.py`.
- [ ] Ни одного горного пейзажа; горизонт — залив, река, низкий город, лес Северо-Запада.

### 3.2. Типографика

- [ ] 100% текста набрано тремя утверждёнными гарнитурами (или дополнительной, утверждённой в W1-07).
- [ ] Все кегли кратны нативной сетке шрифта (`PixCyrillic`: 16/32/48; `Press Start 2P`: 8/16/24/32), проверка скриптом по CSS и Phaser.
- [ ] Ноль вхождений `monospace`, `Inter`, `system-ui`, `sans-serif` как основной гарнитуры.
- [ ] Ноль типографских ошибок: «ё», «ёлочки», длинное тире, неразрывный пробел перед единицами (`23,4 °C`).

### 3.3. Отклик

- [ ] Любое действие игрока даёт видимый отклик ≤ 100 мс и звуковой отклик (если звук включён).
- [ ] Каждый интерактивный элемент имеет состояния: покой, наведение, нажатие, фокус клавиатуры, недоступно; для мира — ещё «выбран».
- [ ] Ни одного пустого кадра при переходах; загрузка дольше 300 мс показывает тематический экран загрузки.
- [ ] Каждый переход экрана анимирован 150–400 мс и имеет вариант для уменьшенной анимации.

### 3.4. Живой мир

- [ ] В хабе ≥ 14 независимых фоновых циклов, одновременно заметных — не более 3.
- [ ] ≥ 6 видов животных и ≥ 3 NPC в хабе и посту; каждый имеет покой, движение и реакцию на нажатие.
- [ ] Фазы суток рассчитываются по `world_location`; есть «белые ночи» для июня на широте 59,9°.
- [ ] Во время задания действует профиль `study-calm`.

### 3.5. Учебная правда

- [ ] Все правильные ответы уровня имеют `source_id` и прошли двойную методическую приёмку.
- [ ] Ответы отсутствуют в сетевых данных до проверки (e2e-тест перехватывает трафик).
- [ ] Каждый неверный вариант выбора несёт код причины ошибки и даёт объяснение именно этой ошибки.

### 3.6. Восприятие

- [ ] Тест трёх секунд пройден на каждом экране (≥ 4 из 5 участников отвечают правильно, что главное и где действовать).
- [ ] Время от открытия хаба до первого учебного действия у новичка ≤ 60 с, у вернувшегося ≤ 10 с.
- [ ] Шкала удобства SUS ≥ 75 по итогам плейтеста; ≥ 70% участников хотят «ещё одну смену».

### 3.7. Производительность

- [ ] Настольный ноутбук: p95 ≥ 58 кадров/с в хабе и посту.
- [ ] Средний телефон в альбомной ориентации: p95 ≥ 30 кадров/с, профиль деградации включается автоматически.
- [ ] Память текстур хаба ≤ 64 МБ; первая интерактивность ≤ 2,5 с в локальной сети.
- [ ] Восстановление после потери контекста WebGL без перезагрузки страницы.

## 4. Чего мы сознательно не делаем

- не добавляем трёхмерную графику, шейдерные «блумы» и размытые градиенты;
- не делаем длинных роликов: любая сцена-вставка ≤ 3 с и пропускается;
- не меняем метеорологические цвета ради эффектов;
- не делаем валюту, магазин и силу за деньги;
- не расширяем область за пределы уровня КН-01, пока он не принят целиком.

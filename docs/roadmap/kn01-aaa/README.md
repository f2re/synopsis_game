# Программа «KN01-AAA»: доведение первого уровня до качества крупной студии

**Статус:** принято к исполнению роем агентов
**Дата фиксации:** 2026-10-26
**Область:** всё, что видит и делает игрок от запуска игры до получения допуска «Кодовый пост» (уровень КН-01) и возвращения в центр с открытым Картографическим классом.

## 1. Зачем эта программа

Текущая сборка технически работает, но не ощущается игрой: главный экран — одна живописная иллюстрация вместо пиксельного мира, рабочее место выглядит как веб-форма, после смены нет итогов, наград и изменений мира, фауна и персонажи отсутствуют, типографика размыта. Подробный разбор с доказательствами — в [`01_AUDIT.md`](01_AUDIT.md).

Программа превращает первый уровень в законченный, красивый и проверенный вертикальный срез, на котором затем строятся остальные уровни.

## 3. Харнесс: как отмечается и подтверждается каждый пункт

1. Каждая задача программы — запись в [`harness/plan.json`](harness/plan.json) с идентификатором `W<волна>-<номер>`.
2. Статусы: `todo` → `in_progress` → `review` → `done`; отдельно `blocked` с причиной.
3. Перевод в `in_progress` разрешён только когда все зависимости в статусе `done`.
4. Перевод в `review` требует непустого списка `evidence`; каждый путь должен существовать в репозитории (скриншот, отчёт, журнал тестов, видео, протокол).
5. Перевод в `done` требует, чтобы **каждый** проверяющий из `reviewers` оставил запись в `verified_by` с вердиктом `accepted`, датой и ссылкой на протокол проверки. Владелец не может подтверждать свою задачу.
6. Все файлы из `deliverables` задачи в статусе `done` должны существовать.
7. Проверка выполняется командой:

```bash
python tools/validate_harness_plan.py
```

Отчёт о ходе работ и список задач, которые можно начинать прямо сейчас:

```bash
python tools/validate_harness_plan.py --report
```

```bash
python tools/validate_harness_plan.py --next
```

8. Доказательства складываются в `docs/roadmap/kn01-aaa/evidence/<ID задачи>/`. Протокол проверки — файл `review-<роль>.md` в той же папке.
9. Отметка «готово» без доказательства считается ложной и откатывается интеграционным инженером.

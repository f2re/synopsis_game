# 05. Экраны уровня КН-01 (S00–S21)

**Статус:** принято к исполнению

Для каждого экрана заданы: назначение, раскладка, состояния, тексты, анимации, звук, критерии приёмки. Размеры указаны в логических пикселях сетки 480×270, если не сказано иное. Обязательные варианты раскладки: настольный 16:9, ноутбук 1366×768, телефон в альбомной ориентации 844×390, телефон в книжной ориентации 390×844 (только хаб и итоги; задания просят повернуть устройство, если поле меньше 600 CSS-пикселей по ширине), проектор 1920×1080 с чтением с 3 м.

Общие правила: каждый экран имеет вход и выход ≤ 400 мс, вариант для уменьшенной анимации (мгновенная смена с затуханием 100 мс), полную работу с клавиатуры, `aria`-разметку и тексты без восклицательных знаков.

## Поток уровня

```text
S00 загрузка → S01 титул → S02 вход → (S03 код, если не задан)
   → [первый вход] S04 выдача формы → S05 брифинг → S06 хаб (обучающая подсветка)
   → S06 хаб → S07 досье поста/карта уровня → S08 выбор режима → S09 начало смены
   → S10 рабочее место ⇄ S11 справочник; S12 отклик на каждый ответ
   → S13 сводка смены → S14 награда (если есть) → S06 хаб
   → … С1–С5 … → S10 в режиме допуска → S21 свидетельство → S15 разблокировка в хабе
Всегда доступны: S16 журнал ошибок, S17 настройки, S18 находки мира, S19 пауза, S20 ошибки и нет связи
```

## S00. Загрузка

- **Назначение:** скрыть загрузку ресурсов и шрифтов, не показывать пустой кадр.
- **Раскладка:** тёмная рамка-паспарту; в центре эмблема станции 64×64; под ней лента телеграммы, на которой телетайп печатает `26063 ... ЗАГРУЗКА ДАННЫХ ...`; полоса прогресса из 16 перфораций.
- **Состояния:** загрузка; ошибка загрузки (лента обрывается, текст «Связь с постом прервана», кнопка «Повторить»); медленная сеть > 5 с (подсказка «Загружаем карту кампуса…»).
- **Анимация:** печать по 1 символу каждые 40 мс; перфорации заполняются по реальному прогрессу.
- **Звук:** тихое стрекотание телетайпа (только после первого жеста пользователя — политика автозапуска браузера).
- **Приёмка:** нет ни одного кадра без фона; шрифты загружены до показа текста; время показа ≥ 600 мс, чтобы не мигать.

## S01. Титульный экран

- **Назначение:** иерархия бренда §8: знак → позывной → сцена → действие.
- **Раскладка:** фоном — фрагмент кампуса с параллаксом (3 слоя) в текущей фазе суток; по центру сверху пиксельный леттеринг `26063` высотой 48 логических пикселей с фактурой инвентарной таблички; под ним `ПОЗЫВНОЙ «СИНОПТИК»` (32 px CSS); ниже главная кнопка «Войти» и вторичная «Смотреть как наблюдатель»; внизу мелко версия и «Звук: вкл/выкл».
- **Состояния:** первый запуск; есть сохранённая сессия (главная кнопка «Продолжить, <имя>», вторичная «Сменить пользователя»).
- **Анимация:** при открытии знак печатается телетайпом по цифре (5 × 120 мс), затем подзаголовок проявляется 200 мс; облака и вода живут; при наведении на кнопку маячок.
- **Звук:** окружение двора (ветер, далёкая чайка), удар клавиши на каждую цифру знака.
- **Приёмка:** тест трёх секунд — «где начать?»; знак не запечён в фон, а отдельный слой.

## S02. Вход «Журнал допуска»

- **Назначение:** выбор себя из закрытого списка и ввод кода без ощущения бюрократии.
- **Раскладка:** модальный разворот журнала поверх затемнённого титула. Слева — закладки групп (как разделители в журнале), справа — карточки участников группы (портрет аватара M3 уменьшенный, имя), под ними — пиксельная клавиатура кода 3×4 и поле из ячеек.
- **Состояния:** список пуст («Журнал пока пуст. Попросите администратора добавить вашу группу»); загрузка; неверный код (ячейки кода вздрагивают, текст «Код не подошёл. Осталось попыток: N»); временная блокировка (таймер обратного отсчёта); успех (штамп «ДОПУЩЕН» на карточке, 300 мс, затем переход).
- **Клавиатура:** стрелки по карточкам, цифры набирают код, Enter — вход, Esc — закрыть.
- **Приёмка:** нет нативных `select`; число попыток и блокировка приходят с сервера; код не логируется и не попадает в адресную строку.

## S03. Задать код

Та же клавиатура; два шага «Новый код» → «Повторите код»; требования к длине — из профиля безопасности сервера; итог — штамп «ЗАПИСАНО».

## S04. Выдача формы (первый вход)

- **Назначение:** создать аватар до первой смены; это переработанный `AvatarEditor` в стилистике склада формы.
- **Раскладка:** слева персонаж M2 крупно на подиуме со вращением (4 направления), справа полки по слотам (головной убор, верх, низ, обувь, рюкзак, аксессуар) с карточками-бирками; сверху вкладки стилей (спортивный, строгий, полевой, туристический, лабораторный); внизу «Готово — на смену».
- **Анимация:** при выборе предмета — персонаж делает `idle`-поворот и короткую реакцию `wave`; карточка «прыгает» на 1 пиксель.
- **Приёмка:** файл экрана ≤ 400 строк после разбиения; все предметы из `items.wardrobe.json`; поворот клавишами Q/E.

## S05. Брифинг наставника

- **Назначение:** ввести наставника, цель уровня и мир за ≤ 40 с; всегда пропускается.
- **Раскладка:** сцена поста ночью, портрет Веры Павловны M3 слева внизу, пузырь реплики; 4 реплики (тексты утверждаются в W1-05), например:
  1. «Вы новый стажёр? Хорошо, что пришли до срока. На 26063 сводки идут каждые три часа».
  2. «Это кодовый пост. Здесь всё начинается: пока телеграмма не прочитана, карты нет».
  3. «Справочник на столе. Не стесняйтесь им пользоваться — стыдно только угадывать».
  4. «Барограф спит на телетайпе. Если он проснулся — значит, вы работаете быстро».
- **Управление:** клик/Пробел — следующая реплика; «Пропустить» в углу.
- **Приёмка:** текст печатается 30 символов/с, клик дописывает реплику целиком; реплики хранятся в данных уровня, а не в компоненте.

## S06. Хаб (центр 26063)

- **Назначение:** живой мир и одно главное действие.
- **Раскладка:** полноэкранная сцена 480×270 (слои — `06_WORLD_ANIMATION_AUDIO.md`). Сверху слева — плашка игрока (аватар 32×32, имя, звание, кнопка меню). Сверху справа — часы мира и фаза суток (иконка луны/солнца, «ночь · 02:14»), звук. Внизу по центру — **главная кнопка** «Начать смену» с подписью следующей цели: «С2 · Термометр · ~7 мин». Под ней в одну строку 4 вторичных входа-иконки: «Журнал ошибок», «Находки», «Персонаж», «Настройки».
- **Здания:** табличка видна полностью только у текущей цели (кодовый пост в оперативном зале); у остальных — маленький значок над входом (замок или открытая дверь), табличка появляется при наведении/фокусе.
- **Состояния:** наблюдатель (главная кнопка «Войти, чтобы начать смену»); первый вход (обучающая подсветка: затемнение 40% вокруг оперативного зала и реплика наставника «Кодовый пост — здесь»); обычный; после разблокировки (S15); есть ошибки в журнале (точка-индикатор на иконке).
- **Взаимодействие:** клик по зданию → S07; клик по животному/объекту → реакция и, возможно, находка; колесо/щипок — масштаб ×1/×2 с ограничением; клавиатура: Tab по зданиям, Enter — открыть.
- **Приёмка:** тест трёх секунд; в книжной ориентации телефона сцена кадрируется на оперативный зал, кнопка в зоне большого пальца; ни одной таблички, перекрывающей другое здание.

## S07. Досье поста и карта уровня

- **Назначение:** показать путь уровня и куда идти дальше.
- **Раскладка:** справа выезжает планшет с зажимом (ширина 40% экрана, на телефоне — на весь экран). Наверху название «Кодовый пост · КН-01», состояние «Открыт». Центр — **карта уровня в виде ленты**: 5 узлов-смен и узел «Допуск», соединённых перфорированной лентой; у каждого узла значок, название, звёзды результата (0–3) и лучшая точность. Внизу «Начать: С2 Термометр».
- **Состояния узла:** закрыт (серый, замок), доступен (янтарный маячок), пройден (штамп), пройден идеально (золотой штамп).
- **Для закрытых зданий:** досье с описанием, условием открытия из сервера и мини-иллюстрацией интерьера в силуэте.
- **Приёмка:** условия открытия приходят с сервера; узлы выбираются клавиатурой.

## S08. Выбор режима

Три карточки-бланка: «С наставником», «Самостоятельно», «Блиц 90 с» — с иконкой, одной строкой смысла, влиянием на освоение и замком с условием, если режим ещё недоступен. По умолчанию выбран последний использованный. Подтверждение — «Начать смену».

## S09. Начало смены

Переход: камера хаба приближается к оперативному залу (400 мс), затухание в пост (200 мс). На посту телетайп оживает, наставник произносит строку брифинга смены, в углу бланка — цель («6 заданий · Термометр»). Через 1,5 с или по клику — первое задание.

## S10. Рабочее место «Кодовый пост»

- **Раскладка (настольная):**

```text
┌──────────────────────────────────────────────────────────────┐
│ [◀ Пауза]   С2 · Термометр   ▮▮▮▯▯▯ 3/6        лампы серии ●●●○○ │
├──────────────────────────────────────────────────────────────┤
│   окно (фаза суток)      ЛЕНТА ТЕЛЕГРАММЫ: 10234 21052 …       │
│                          ───────────────────────────            │
│  ┌──────────┐      ┌───────── БЛАНК ЗАДАНИЯ ─────────┐ ┌──────┐│
│  │ портрет  │      │ вопрос                           │ │мини- ││
│  │ наставн. │      │ область ответа (тип задания)     │ │схема ││
│  └──────────┘      │ [Справочник]          [Проверить]│ │станц.││
│   кот на телетайпе └──────────────────────────────────┘ └──────┘│
└──────────────────────────────────────────────────────────────┘
```

- **Сцена:** Phaser-сцена поста в профиле `study-calm` за React-слоем; бланк и лента — React-компоненты в диегетических рамках, совмещённых со столом сцены.
- **Области ответа по типам:**
  - `identify` — 4 бумажные карточки А–Г, клавиши 1–4;
  - `decode` — поле из ячеек + клавиатура телетайпа (−, цифры, запятая, ⌫); единица измерения рядом с полем; физическая клавиатура работает;
  - `anatomy` — группа увеличена в 5 ячеек, ячейки выбираются кликом или стрелками + Пробел;
  - `encode` — пустые 5 ячеек на ленте, набор с клавиатуры телетайпа;
  - `sequence` — карточки групп перетаскиваются по ленте; альтернатива — выбор карточки и стрелки; на телефоне — «нажать, затем нажать место»;
  - `findError` — телеграмма целиком, группы выбираются, затем выбирается причина из 3–4 вариантов;
  - `fullTelegram` — бланк с полями по группам, поле подсвечивает связанную группу на ленте.
- **Пауза S19:** Esc или кнопка; затемнение, «Продолжить», «Настройки», «Выйти в центр (прогресс смены сохранится)».
- **Приёмка:** задание полностью проходится мышью, клавиатурой и касанием; в сетевых данных до проверки нет эталона; на телефоне в альбомной ориентации лента и бланк видны без прокрутки.

## S11. Справочник КН-01

- **Назначение:** диегетическая книга правил; использование учитывается в освоении.
- **Раскладка:** книга раскрывается поверх стола (разворот 2 страницы), закладки по группам слева, на странице: схема группы с ячейками и подписями, правило, 2 примера, источник. Поиск по номеру группы.
- **Анимация:** открытие — 3 кадра, перелистывание — 2 кадра на страницу.
- **Состояния:** в режиме «Самостоятельно» — предупреждение «Задание будет отмечено как выполненное со справочником»; в допуске — недоступен (книга закрыта на ремешок).
- **Приёмка:** все страницы взяты из утверждённых правил W1-01 с `source_id`; текст справочника не раскрывает ответ текущего задания конкретным числом.

## S12. Отклик на ответ

См. `03_LEVEL_KN01_DESIGN.md` §8. Дополнительно: разбор по цифрам — отдельный компонент `DigitAnatomy` с ячейками, скобками-подписями `Press Start 2P` 8 px, обводкой ошибки красным карандашом (анимация «прорисовки» обводки 4 кадра).

## S13. Сводка смены

- **Раскладка:** лист журнала дежурного на планшете: заголовок «Сводка смены С2 · Термометр», дата и срок UTC; блок «Точность 5/6», «Лучшая серия 4», «Время 6:12»; полосы освоения по навыкам с приростом (анимация заполнения 600 мс, по очереди); «В журнал ошибок добавлено: 1»; блок награды (если есть); подпись наставника и реплика; кнопки «В центр» (главная), «Ещё одна смена», «Повторить ошибки».
- **Звёзды:** 1 — пройдено, 2 — ≥ 80%, 3 — 100% без справочника.
- **Приёмка:** показывается и при прерванной смене; данные только с сервера.

## S14. Награда

Короткая сцена ≤ 2 с: предмет выезжает из конверта, вращается 4 кадра, табличка с названием и описанием, кнопка «Надеть сейчас»/«Позже». Никаких «легендарных» лучей; редкость обозначается цветом рамки.

## S15. Разблокировка в хабе

После допуска при возврате в хаб: камера плавно смещается к Картографическому классу (600 мс), замок над входом раскрывается (4 кадра), окна загораются по одному, табличка появляется, из-под крыши вылетают 3 голубя, звучит короткая фраза разблокировки (≤ 1,5 с); затем то же для Архива; затем камера возвращается. Пропуск — любой клавишей. В уменьшенной анимации — мгновенное состояние «открыто» и плашка-уведомление.

## S16. Журнал ошибок

Список карточек «ошибка → принцип → дата»; фильтр по группам; на каждой кнопка «Повторить похожее» (создаёт мини-смену из 3 заданий по шаблону ошибки); отметка «разобрано» после двух верных повторов.

## S17. Настройки

Громкость (общая, окружение, интерфейс), уменьшенная анимация (по умолчанию из `prefers-reduced-motion`), размер текста (×1 / ×1,5 с перестроением, не дробное масштабирование шрифта), повышенный контраст, частота кадров мира (авто / экономия), язык подписей кодов (с подписями / без).

## S18. Находки мира

Альбом наблюдателя: сетка карточек 4×N, у найденных — спрайт животного/события и короткая заметка; у ненайденных — силуэт и подсказка-загадка («Любит перила у метеоплощадки»). Находки не влияют на освоение и рейтинг.

## S19. Пауза

См. S10.

## S20. Ошибки и отсутствие связи

Единый компонент «обрыв ленты»: иллюстрация оборванной ленты, человеческое объяснение, действие («Повторить», «В центр»), технический код мелко. Ответ, отправленный без связи, не теряется: повтор отправки с тем же идентификатором попытки.

## S21. Свидетельство допуска

Пергаментный бланк «Свидетельство о допуске к работе на кодовом посту станции 26063», имя игрока, дата, звание «Техник-метеоролог», штамп «ДОПУСК» опускается последним; кнопка «Сохранить в профиль» (по умолчанию) и «Вернуться в центр» (запускает S15). Свидетельство — игровой предмет, а не официальный документ; в тексте нет имитации реальных организаций.

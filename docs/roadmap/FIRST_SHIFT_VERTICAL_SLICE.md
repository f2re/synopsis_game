# Первый вертикальный срез: учебная смена КН-01

## Цель

Первый проверяемый пользовательский путь:

`вход → главный центр → «Начать смену» → КН-01 → объяснение ошибки → итог → главный центр`.

Главный экран уже считается принятой визуальной базой и не блокирует этот срез. Его дальнейшее оживление выполняется параллельно и не должно ухудшать утверждённый кадр.

## Уточнение общей архитектуры

- отдельного `apps/display` не создаётся; большой экран остаётся маршрутом `/arena-tv` внутри `apps/web`;
- базовый версионируемый кодек КН-01 является зависимостью первого учебного среза, а не только будущего контура актуальных наблюдений;
- этап актуальных КН-01 расширяет кодек приёмом телеграмм, реестром станций, контролем качества и снимками данных;
- Phaser/WebGL отвечает за живой мир, но профессиональные задания выполняются в React + SVG/Canvas.

## Стадия A — базовая вертикаль

Готово в ветке `feat/first-shift-kn01`:

- событие `hub:start-shift` открывает `/shift`;
- `@synopsis/kn01-codec` реализует базовые группы;
- `@synopsis/content-engine` скрывает эталон от клиента;
- сервер создаёт смену, проверяет ответ и журналирует попытку;
- UI поддерживает `decode`, `choice`, `sequence`;
- ошибка `multiChoice` для задания 57103 исправлена на `choice`;
- Phaser вынесен в динамически загружаемый фрагмент;
- релизный архив включает `content/` и исполняемые пакеты проверки.

## Стадия B — обязательная приёмка

До перевода пакета из `draft`:

1. двойная метеорологическая проверка КН-01;
2. проверка пяти стартовых заданий;
3. браузерный сквозной тест;
4. визуальная регрессия Hub и рабочего места;
5. проверка мобильного горизонтального режима;
6. проверка клавиатуры и уменьшенной анимации.

## Стадия C — схема станции

Вход: каноническое наблюдение после дешифрирования КН-01.

Выход: SVG-схема станции с независимо адресуемыми элементами. Первый набор — температура, точка росы, давление и ветер. Проверка выполняется покомпонентно, а не сравнением растровых пикселей.

## Стадия D — первый планшон

Последовательность сложности:

1. одна станция;
2. три станции;
3. 7–10 станций на фрагменте планшона;
4. поиск ошибочного наблюдения;
5. только после этого — интерполяция и первые линии анализа.

Координаты эталона хранятся в нормализованном пространстве карты, а не в экранных пикселях.

## Критерий завершения первого среза

Студент на ноутбуке и смартфоне проходит короткую смену, получает объяснение каждого ответа, попытка сохраняется, правильные ответы отсутствуют в сетевых данных до проверки, а пакет проходит независимую методическую и интеграционную приёмку.

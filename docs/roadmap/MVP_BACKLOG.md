# Перечень задач первого рабочего среза

**Статус:** активное планирование

Этот файл переводит общий план реализации в короткий исполнимый перечень задач. Каждая задача перед началом разработки должна иметь владельца, карточку задачи и явные критерии приёмки.

## Блок METH — методическая база

- [ ] `METH-001` Реестр источников: структура, идентификаторы, авторитетность и статус.
- [ ] `METH-002` Методический профиль `RUS_CLASSIC_TRAINING_V1`.
- [ ] `METH-003` Терминологический словарь: первичный анализ, подъём карты, В/Н, П/Р, Т/Х.
- [ ] `METH-004` Лист методической проверки учебного задания.
- [ ] `METH-005` Точные библиографические записи и страницы для стартового пакета.

**Критерий готовности:** каждое эталонное правило имеет `source_id` и явный статус.

## Условия готовности первого рабочего среза

Первый рабочий срез готов к пилоту, когда:

- стартовый пакет прошёл методическую проверку;
- одиночная работа действует на мобильном и настольном устройстве;
- блиц и дуэль 1×1 устойчивы;
- автономный турнир не требует ручного переключения;
- зритель видит матч на проекторе;
- воспроизведение матча работает;
- ошибки классифицируются;
- новое задание JSON добавляется без изменения движка;
- рейтинговый режим не зависит от постоянной прокачки.

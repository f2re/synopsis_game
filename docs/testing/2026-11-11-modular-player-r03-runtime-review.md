## Найденное и исправленное замечание

При смене профиля `HubModularAvatarLayer.setProfile()` сразу уничтожает старые визуальные объекты, но прежний вариант сообщал новое состояние только после асинхронной сборки. Поэтому React мог временно показывать старую готовность кнопок движения, хотя действующего листа кадров уже не было. Сама команда движения отвергалась проверкой наличия принятого клипа; обхода допуска или показа чужой одежды не было.

Замечание передано автору. Автор добавил немедленные `drawPath()` и `publish()` после очистки. Теперь до загрузки новой композиции передаются `ready=false` и пустой список доступных действий. Независимо повторно выполнен тест с соответствующей проверкой; конечные хеши отчёта включают исправление.

## Что проверено

| Область | Доказательство |
| --- | --- |
| Доступные движения | Список действий происходит из принятого и проверенного манифеста. Набор только со стойкой не открывает ходьбу, осмотр или переход в режиме уменьшенного движения. |
| Сохранённый комплект | Смена профиля отменяет старую асинхронную загрузку; её результат освобождается и не подменяет текущего персонажа. В блице используется полный переданный снимок без изменения ID одежды. |
| Путь и поворот | Маршрут проходит по конечному графу дорожек. Неразмеченное место и препятствие не становятся целью. При повороте требуется совпадающий принятый лист кадров; ожидание загрузки не перемещает тело. |
| Осмотр | Однократный клип проходит все шесть кадров, возвращается в стойку и не возобновляется от последующих сигналов настроек. Скрытие окна сохраняет оставшееся время. |
| Клавиатура | Обработчик находится на явной панели. Нет глобального перехвата. Стрелки, WASD и русская раскладка поддержаны; Tab, Enter и пробел сохраняют штатное действие. Повтор удержанной клавиши не создаёт очередь шагов. |
| Указатель | Только прямое попадание в Canvas основной кнопкой становится командой навигации. Кнопки зданий остаются отдельными целями. Координаты переводятся из положения указателя в CSS-координаты Canvas. |
| Модальные окна и контекст | Модальное окно отключает ввод и отменяет путь. Потеря WebGL-контекста ставит мир на паузу. Восстановление контекста при скрытой вкладке не будит его; показ вкладки возвращает ввод. |
| Ограничение нагрузки | Кадры и координаты не записываются в React каждый кадр. Уменьшенное движение останавливает декоративные изменения; экономный режим задаёт предел 30 кадров/с и более редкое чтение кадров персонажа. |
| Ресурсы | Устаревшие и текущие ссылки на композиции освобождаются ровно один раз. Phaser использует отдельную копию текстуры. Уничтожение сцены снимает слушатели, таймеры, текстуры, графику дорожки и экземпляр игры. |

## Независимый дополнительный тест

Тест написан проверяющим отдельно от авторского набора и проверяет клавиши, область их действия, указатель, потерю контекста, скрытое восстановление, настройки и удаление всех зарегистрированных слушателей.

Этот тест не запускает браузер и не имитирует измерения физического GPU. Его цель — проверить соглашение событий и очистку ресурсов реального компонента.

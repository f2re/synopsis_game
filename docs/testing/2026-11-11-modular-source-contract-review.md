## Независимо воспроизведённые проверки

Исходная точка сравнения — коммит `e096bb1`, результат PR #124. Проверяющий вызвал `compile_pack()` на текущем `rig.json`, затем получил прежние `apps/web/public/assets/avatar/modular-r01/atlas.png` и `manifest.json` непосредственно через `git show HEAD:<path>`. PNG совпал побайтово. После применения подтверждаемого статуса `PASS` в копии результата в памяти весь JSON также совпал побайтово. Файлы продукта при этой проверке не записывались.

Подтверждены 30 исходных семейств, 125 уникальных фрагментов, прежние 167 734 байта PNG и 917 504 байта декодированного RGBA. Перенос правил размещения в JSON не добавляет ни текстур, ни кадров, ни потребителей памяти в браузере. Это вывод из точного совпадения файлов, а не измерение мобильного GPU.

Прочитаны реализация `modular_player_contract.py`, изменения `build_modular_player_r01.py`, исходные крепления и маски, записи допуска и регрессионные тесты. Проверено, что:

- размещение фрагмента использует `at − sourceAt` и общую фазу целочисленного движения;
- маски кистей и открытого предплечья, порядок слоёв и скрытие по направлениям действительно поступают из контракта;
- источник допущенных контрольных сумм отделён от вычисляемого `currentAcceptance`;
- сборка не переписывает `acceptedFingerprint` и не создаёт собственное доказательство приёмки;
- новая картинка, геометрия или палитра не может унаследовать старый `PASS` только из строковых статусов манифеста.

Первый независимый запуск `python tools/assets/test_modular_player_contract.py` дал **10 из 11 PASS**. Единственная ошибка была ожидаемой: текущий результат оставался `PENDING`, поскольку этого независимого документа ещё не существовало. Пробы изменения пикселя, маски, видимой и скрытой точки крепления, порядка перекрытия и палитры прошли; неподтверждённые изменения получали `PENDING`. Отдельно прошли проверки выхода маски за рамку, неизвестного крепления, скрытия обязательной одежды и отсутствующих/несовпадающих доказательств.

После записи независимого решения проверяющий повторил тесты: **11 из 11 PASS**, включая положительный допуск точного набора. Автор конвейера затем пересобрал производные файлы и служебные суммы исходного манифеста. После этого проверяющий отдельно повторил `python tools/assets/build_modular_player_r01.py --check`: **PASS, art=PASS**, и ещё раз выполнил весь набор из 11 тестов: **PASS**. `git diff --numstat` для редактируемых `.aseprite`, рабочего и публичного PNG/JSON пуст. Начальная ошибка сохранена выше как наблюдение до появления доказательства, а не объявлена успешным тестом задним числом.

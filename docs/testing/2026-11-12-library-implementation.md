# Библиотека станции и справочник КН-01: передача реализации

- Задача: `COZY-SCREENS-20261112-LIBRARY`.
- Исполнитель: `library`; роли реализации — `ui-pixel-designer`, `meteo-methodologist-ru`.
- База: main `64b19ac`. Автор не выполняет собственную методологическую, художественную или выпускную приёмку.

## Границы и интеграция

`LibraryScreen` экспортируется из `apps/web/src/features/library/LibraryScreen.tsx`.

```ts
interface LibraryScreenProps {
  onBack: () => void;
  initialQuery?: string;
  onOpenCodebook?: () => void;
}
```

Экран доступен без учётной записи. Корневая оболочка задаёт маршрут `/library` и может передать `?q=` как `initialQuery`. `onOpenCodebook` открывает отдельный маршрут `/codebook`; без callback справочник открывается внутри библиотеки. Публичный API `Codebook` (`isOpen`, `onClose`, `shiftMode`, `onHandbookOpen`) сохранён. Внутри используется нативный `dialog.showModal()` с удержанием фокуса браузером, обработкой Escape и возвратом фокуса существующему элементу при закрытии.

## Что реализовано

- 30 статей: КН-01, время и индекс станции, единицы ветра, температура и точка росы, давление и барическая тенденция, облачность/видимость/осадки/текущая погода, станционная модель, контроль качества, синоптический метод, подъём карты, изобары/изаллобары, барические системы и фронты, карты топографии, адвекция и аэрологическое зондирование.
- Каталог с четырьмя разделами, поиском, связанными статьями, памятками и ссылками на источники с указанием раздела/таблицы. Варианты `ё/е`, пробелы/дефисы и распространённые обозначения (`КН-01`, `SYNOP`, `Td`, `АТ500`, `ОТ500/1000`) нормализуются; краткие символы не находят произвольную часть слова.
- Закладки на устройстве под ключом `synopsis_26063_library_favorites_v1`. Повреждённые, дублирующиеся и неизвестные значения отбрасываются. При запрете localStorage состояние продолжает работать, а интерфейс честно сообщает о временном сохранении.
- Читальный лист тёплого светлого цвета на тёмном каталоге, существующая пиксельная система иконок, читаемый текст. На узких экранах отдельно показываются каталог и статья, с явным возвратом. Нативные кнопки, подписи и состояние пустого поиска; фокус переводится на заголовок только при явном выборе статьи.
- Семь страниц КН-01 переработаны по изданию 2013 года. У каждой страницы действующий source ID и точный locator, примеры подписаны как иллюстрации чтения кода.

## Методологические решения

Основной нормативный источник — `ROSHYDROMET_KN01_2013`: [КН-01, национальная практика, 2013](https://meteoinfo.ru/images/media/books-docs/RHM/kn-01-synop.pdf). Для физических определений добавлены прямые страницы официального словаря Гидрометцентра и NOAA/NWS в `content/sources/sources.json`; для синоптического метода сохраняется учебник А. С. Зверева с указанием главы/раздела. Первичные страницы были просмотрены при подготовке содержания.

В старом справочнике исправлены предметные ошибки: `iw=4` обозначает измерение в узлах; национальная практика 2013 не применяет `iw=3/4` и `00fff`; поле `N` — код, и в таблице 2700 национальные соответствия указаны для десятибалльной оценки. Убраны безусловное правило восстановления любого станционного давления по одному порогу, абсолютное сравнение давления станции/уровня моря и диагноз циклона из единственного значения давления.

Для тенденции уточнено: `a=4` допускает ровный или неровный ход при отсутствии итогового изменения; у `a=0/5` возможен нулевой итог. Ограничение `Td ≤ T` отделено от универсального закона и описано в области обычных ненасыщенных/насыщенных наблюдений и учебного контроля. Расположение полей станционной модели явно обозначено как профиль игры `RUS_SURFACE_STATION_V1`, зарегистрированный с authority `project_assumption`; WMO не приписываются отсутствующие в процитированной странице точные координаты.

Задания, эталоны ответов и серверная проверка в этой работе не изменялись. В существующем профиле/заданиях могут оставаться связанные расхождения (использование `00fff`, национальная область `iw`, трактовка облачности/тенденции); они сообщены root для отдельной методологической задачи. Новые карточки не объявляют эти старые правила нормативными.

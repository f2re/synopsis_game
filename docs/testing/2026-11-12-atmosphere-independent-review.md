## Вердикт и пределы

**Security/privacy: PASS в границах новых локальных настроек и управления звуком.** Подтверждено исправление обходного пути разблокировки через синтетические события. Новых сетевых разрешений, регистрации, административных действий, приватных полей или записей звука в этом срезе нет.

**Performance: PASS для проверенных контрактов планировщиков и жизненного цикла; измерение браузерного рендера остаётся обязательным перед окончательной приёмкой.** Детерминированные Node-проверки не являются прослушиванием, измерением WebGL/GPU или фактической браузерной проверкой autoplay. Локальный Chromium блокируется средой (`EPERM`); browser smoke выполняется корневым интегратором через GitHub Actions.

## Найденное замечание и устранение

`WorldAudioManager.setupAutoplayUnlock` из прежнего кода вызывал `getAudioContext()` по любому `pointerdown/keydown`, даже синтетическому и при отключённом звуке. Новый `audioGate` не защищал этот отдельный путь. `once:true` дополнительно позволял синтетическому событию расходовать обработчик.

Замечание передано автору. Автор добавил проверку `event.isTrusted` и `this.muted`, сохранил обработчики для проигнорированных событий и снимает оба только после разрешённого жеста. Проверяющий повторно прочитал production-код и самостоятельно выполнил тест. Прямой вызов production listener в тестовой среде подтверждает: синтетический жест → 0 контекстов; доверенный при mute → 0; доверенный при разрешённом звуке → 1 общий контекст и снятие обоих обработчиков. Замечание **закрыто**.

## Проверенные контракты

| Хранение | JSON из localStorage считается недоверенным: белый список свойств/типов, конечные числовые значения 0–100, enum погоды. Повреждённое хранилище не блокирует настройки; запрещённая запись оставляет честно обозначенное состояние сеанса. |
| Пользовательский жест | `audioGate` принимает только доверенные события. Сохранённое включение звука само по себе не разрешает воспроизведение; второй legacy listener также защищён. |
| Общая громкость и mute | Музыка проходит через существующую общую шину/фильтр/ограничитель. `masterVolume=0`, mute, скрытая вкладка и поверхность `silent` запрещают звуковую политику. Резервные HTMLAudio-эффекты также меняют громкость и прекращаются при mute. |
| Музыка | Один общий AudioContext, отдельная music-шина, один интервал 250 мс; не более 10 одновременно удерживаемых голосов, включая затухающие. Отложенный callback пропускает пропущенные ноты. stop очищает интервал, затухающие узлы отключаются через 120 мс. |
| Учебная смена | Поверхность `study` убирает музыку/комнатный фон, сохраняя разрешённую пользователем шину учебных сигналов. |
| Фон и маршруты | Провайдер владеет интерьерным фоном; WorldCanvas — фоном кампуса/архива. При уходе очищаются планировщики/фон/подписки; поздний decode не запускает удалённый или заменённый слой. |
| Скрытие | Provider останавливает музыкальный интервал и фон, WorldCanvas вызывает `game.loop.sleep()` и блокирует звук; возврат пересчитывает настройки. Weather-интервал не работает при скрытии или `silent`. |
| Reduced motion / low power | Настройка ОС объединяется с пользовательской без перезаписи пользовательского значения. HubScreen передаёт изменение через bridge в WorldCanvas. Декоративные tweens и audio-LFO выключаются; low power задаёт кампусу 30 кадров/с и убирает дополнительный музыкальный голос. |
| Декоративная погода | Настройка не меняет учебные наблюдения или серверные ответы; цикл вычисляется отдельно. |
| Новые файлы/права | Новая музыка задана исходной партитурой и синтезом, внешних записей или исполняемых материалов нет. Старые фоны используют существующие канонические ID. |

## Остаточные измерения перед окончательной performance-приёмкой

Корневому интегратору переданы конкретные сценарии: ширины 390/1440; не более 12 декоративных капель и отсутствие их анимации при hidden/reduced/lowPower; кампус 30/60 fpsLimit, уход/возврат/hidden sleep; доверенный браузерный жест, реальное воспроизведение и остановка звука. Нужны фактические p50/p95 frame time, input latency, startup payload/память/GPU там, где доступны, и длительная работа системы, если заявляется полная приёмка живого мира. Эти показатели данным review **не измерены** и не объявлены PASS.

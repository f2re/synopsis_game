# Движение растительности станции R09

**Дата:** 22 ноября 2026 года. **Задача:** `ART-STATION-R09-WIND`. **Исполнитель:** `/root/station_living_wind`, роли `living-world-engineer` и `game-runtime-webgl-engineer`.

**Уточнение интеграции от 22 ноября, `/root`:** нижеследующий протокол сохраняет первоначальное состояние модуля. Проверка пяти настоящих маленьких масок показала, что первоначальная рекомендация `gain <= 0.3` округляла полезное движение до нуля; она отозвана. В текущей модели жёсткий предел после округления равен **1 исходному пикселю**, а gains выбранных масок равны 1.5, 1.5, 1.4, 1.4 и 1.2. Настоящий 60-секундный контракт `tools/test_station_r09_wind_contract.mjs` подтверждает движение каждого фрагмента и неподвижность корней. Полная проверка TypeScript приложения и production-сборка также прошли после подключения модуля; начальная ошибка разрешения Phaser ниже относится к прежнему изолированному запуску. Исходные логи этого документа не переписываются и не объявляются результатом текущего браузера.

## Результат и область

Созданы независимая модель ветра и слой Phaser 4 для прозрачных растительных фрагментов новой сцены R09. Старые `HubR01Layer`, `HubScene`, `HubScreen`, `R08PreviewScene`, API, задания и персонализация этим исполнителем не изменялись. Подключение слоя, выбор исходных масок и композиция принадлежат основному исполнителю.

Общий порыв распространяется через координаты авторской сцены, а устойчивый идентификатор каждого растения задаёт собственную фазу мелкого движения. Модель использует только локально накопленное время и фиксированное зерно, без `Date.now`, глобального генератора случайных чисел, сетевых запросов и обновлений React на каждом кадре. Погодный профиль меняет художественную выразительность движения; наблюдённая скорость ветра не выдумывается и учебные данные не изменяются.

Каждый фрагмент делится на непересекающиеся полосы исходного изображения. Для растения нижняя полоса остаётся неподвижной, выше амплитуда постепенно растёт. Координаты смещения кратны пикселю исходника. Для отдельно выделенной ткани `kind: flag` неподвижна левая кромка, движение направлено по вертикали; мачта и фасад в такой фрагмент не входят.

## Контракт подключения

`new HubVegetationWindLayer(scene, stationSeed = 26063)` использует существующую камеру. Методы:

- `setPlacements(placements)` — атомарно заменяет растительные фрагменты; неверная геометрия оставляет прежние изображения на месте.
- `setEnvironment({ weather, reducedMotion, lowPower, paused })` — применяет полный снимок предпочтений. Пропущенные логические поля принимаются за `false`; это не частичный патч предыдущего состояния.
- `setTint(tint)` — применяет общий оттенок освещения к исходным полосам.
- `update(deltaMs)` — обновляет позы по ограниченной художественной частоте.
- `getDiagnostics()` — состояние часов, частота, число фрагментов/полос, смещения и признак закрепления корней. Вызывать для проверки или дискретной публикации, без постоянной передачи в React.
- `destroy()` — освобождает все созданные изображения; повторный вызов безопасен.

Каждый `VegetationWindPlacement` содержит `id`, `textureKey`, `anchorX`, `anchorY`, `width`, `height`, `depth`, `kind`, необязательные `sourceRect`, `rootFraction` и `gain`. `sourceRect` приходит из манифеста исходников. `anchorX`/`anchorY` — нижний центр полного фрагмента в общей системе координат мира. Координаты атласа в логике не зашиты. Масштаб исходника задаёт родительская сцена; одинаковое целочисленное масштабирование по обеим осям сохраняет её пиксельную сетку.

**Обязательное условие композиции:** исходная неподвижная крона должна быть удалена из лежащего ниже фонового слоя. Наложение движущейся копии на исходную полную крону создаст двойной контур. Выделенные фрагменты и восстановленная под ними поверхность готовятся художественным конвейером и принимаются отдельно.

## Ограничения и режимы

| Свойство | Ограничение реализации |
|---|---|
| Растительные фрагменты | До 48 |
| Полосы одного фрагмента | До 8; каждая исходная строка/колонка покрыта ровно один раз |
| Обычная смена позы | 10 Гц |
| Экономичный профиль | 5 Гц; сохраняется та же фаза общего ветра |
| Уменьшенная анимация | Сразу возвращает точный исходный кадр и останавливает часы |
| Скрытие/пауза | Удерживает последнюю позу и время |
| Большой промежуток после возврата | Ограничен 100 мс; пропущенное время не догоняется |
| Смещение | Не более 4 пикселей исходника; интенсивность отдельного фрагмента регулирует `gain` |
| Создаваемые текстуры | 0; используются исходные текстуры и обрезка |
| Собственные таймеры, обработчики ввода и подписки | 0 |

Для пяти небольших масок основного изображения основной исполнитель выберет `gain`. Значение `gain <= 0.3` ограничивает расчётное округлённое смещение одним пикселем исходника даже при верхней амплитуде текущей модели. Это ограничение художественной модели, не измерение производительности устройства.

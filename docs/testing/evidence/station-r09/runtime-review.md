# R09: независимая приёмка работы сцены и производительности

Дата: 2026-11-22. Роль: `web-performance-engineer` + `integration-release-engineer`.

**Текущий вердикт: browser acceptance ожидается.** Локально проверены реальные
модели и обработчики с двойниками границы Phaser. Это не подтверждение пикселей
WebGL, производительности GPU или художественная приёмка.

## Проверяемая версия и порядок допуска

Первый автоматический push/PR CI загружает кандидат через `?stationArt=r09`.
Обычный главный экран пока использует принятую версию R01. После независимой
приёмки PNG и реальных браузерных артефактов требуется отдельное включение R09
по умолчанию и повторный полный CI, включая первый уровень и настройку героя.
Этот reviewer не меняет `productionReady` и не подменяет художественные gates.

Локальный браузер, Playwright, dev server и HTTP-сервер не запускались.
Ручной запуск CI не применяется. Браузерные доказательства производит уже
существующий автоматический workflow `station-screens.yml` после публикации.

## Контракт браузерной приёмки

| Проверка | Критерий и доказательство |
| --- | --- |
| Загрузка текущего R09 | Реальные HTTP 200 для каждого PNG из manifest; SHA-256 тел браузерных ответов и public PNG совпадают с manifest; `data-station.stationArt=r09`; один canvas и исходник 512×288. |
| Реальное движение | PNG пары из Chromium/Firefox при 1366×768, 390×844 и 844×390; видимая крона меняет пиксели. На desktop дополнительно меняются облако и дальняя вода. Область берётся из manifest и камеры, HUD вычитается. |
| Неподвижные здания | Пиксели двух доступных контрольных участков камня/фриза не изменяются во время движения. Эти участки исключают NPC, входные маркеры, воду и световые маски. |
| Растительность | Пять настоящих вырезок, максимум 40 полос; корни имеют нулевое смещение, движущиеся части — максимум 1 исходный целый пиксель; естественное время без тестового ускорения. |
| Настройки | Reduced motion проверяется идентичностью всей видимой области canvas после ожидания. Low power сохраняет движение с наблюдаемыми 5 обновлениями ветра за модельную секунду и ограничивает реальный render loop до 30 Hz. |
| Пауза скрытой вкладки | В существующем native Chromium/CDP пути настоящая вторая вкладка скрывает сцену. Clock, poses, paintedFrames, waterFrame и cloud offsets удерживаются; возврат не добавляет скрытое время. Firefox не получает фиктивный PASS этой проверки. |
| Входы и панорама | Все шесть POI доступны через настоящие кнопки панорамы. Каждый target расположен над неизменным исходным входом; минимум 44 CSS px, пять точек мыши, Tab/Shift+Tab/Enter/Space/Escape. Старый R01 baseline сохраняет проверку шести одновременных target. |
| Resize и повторный вход | Переход desktop → portrait → landscape → desktop возвращает исходную геометрию. Три выхода в помощь и возврата настоящей history-навигацией освобождают старые GL textures, прекращают рисование старого мира и дают один новый canvas. |
| Ошибка ресурса | UI test сначала узнаёт реально выбранный профиль. Задерживается и затем обрывается действительно запрошенный обязательный PNG; проверяются навигация и восстановление загрузки. |

Диагностика — read-only JSON в `.world-canvas-host > div[data-station]`.
Дополнительных production команд для перемотки времени или постановки поз нет.
Фиксируется только календарная `Date` для освещения; RAF, performance и таймеры
в браузерных сценариях остаются настоящими.

## Согласованные бюджеты

| Метрика | Предел | Область измерения |
| --- | --- | --- |
| R09 PNG | ≤ 2 MiB | Фактические размеры public PNG. |
| Source RGBA | ≤ 8 MiB | Сумма ширина × высота × 4; не выдаётся за выделенную драйвером GPU память. |
| Растительность | 5 вырезок, ≤ 40 полос | Фактический manifest и диагностика сцены. |
| Ветер | 10 Hz; low power 5 Hz | Модельная cadence и наблюдаемый счётчик paintedFrames. |
| Software-CI кадры | p95 ≤ 100 ms | Интервалы реальных clear-pass default WebGL framebuffer в четырёхсекундном окне; отдельно сохраняются native RAF интервалы. |
| Повторный mount | Нет роста живых texture handles | Наблюдение create/delete/context-loss без сильных ссылок probe на GL/texture объекты. |

Clear-pass cadence не равна сертификации 60 FPS на телефоне. Оценка texture
uploads исключает mipmaps, формат драйвера, framebuffer и его внутренние кэши.
Аппаратный GPU и физический телефон этим CI не измеряются.

## Локальные доказательства

- `runtime-wind-contract.json`: 60 модельных секунд для всех пяти настоящих
  масок в clear/rain. Движение каждой вырезки ненулевое, есть разные фазы,
  основание неподвижно, максимум 1 пиксель. Ранее обнаруженный чрезмерно малый
  gain давал полностью нулевое движение после округления; production исправлен.
- `runtime-layer-handlers.json`: реальные `HubR09Layer`, wind/model/settings/
  weather modules, настоящий manifest; три цикла создают и освобождают все
  объекты/маски/listeners. Проверены pan, возврат desktop, ограничение diagnostics,
  пауза, ограничение resume delta, reduced/low. Источники имеют SHA-256.
- Все изменённые CJS runners проходят `node --check`.
- PNG decoder проверен независимо через Pillow на ранее сохранённых реальных
  Chromium RGB8 и Firefox RGBA8 кадрах. RGB SHA-256 совпали. Эти старые кадры
  подтверждают decoder, а не внешний вид R09.

Финальный исходный manifest этой локальной проверки имеет SHA-256
`1388b78d4c5b3d7e627d607985073f37b08111a5efdb80bcb96211d1f72fe420`.
Он содержит 13 PNG, 345 506 байт PNG и 2 714 248 байт исходного RGBA.
Повторный handler зафиксировал 46 объектов, три отдельные маски и одно
подвижное облако; все объекты и обработчики освобождены за каждый из трёх
циклов. Девять отдельных строк отражённого света прошли проверку целой
исходной сетки, монотонной alpha и отсутствия vertex interpolation во всех
шести фазах дождевого сценария. Это обновлённые результаты после исправления
cloud/water export и локальных световых масок.
Хеши browser helpers и остальных входных файлов перечислены в
`runtime-local-verification-v2.json`; первый снимок проверки сохранён отдельно.

## Первый автоматический прогон и второй кандидат

Первый прогон PR135: commit `bc0273f00f90fd22c69647b5300c511de09033b5`,
checkout `dd68819f5c83706fa41a5b5f473a648de4518290`,
[автоматический run 45006418395](https://github.com/f2re/synopsis_game/actions/runs/45006418395).
Общий результат — FAIL; частичные измерения и hashes сохранены в
`runtime-ci-pr135-attempt1.json`.

Оба браузера подтвердили настоящие изменения пикселей растительности, облака
и воды на desktop, при нулевом изменении контрольных участков зданий. P95
интервала WebGL clear-pass составил 37,4 ms в Chromium и 18 ms в Firefox.
Участки настоящего Firefox PNG также независимо сверены с исходником:
6417 RGB-пикселей совпали с точным native zoom3 без сглаживания.

Причины остановки первого прогона и сделанные исправления:

- В weather-сценарии остался прямой клик по архиву за правым краем portrait.
  Теперь используется настоящая панорама перед тем же кликом; все проверки
  дождя и читального зала сохранены.
- Два новых строгих host selector захватывали также div с pan-кнопками. Они
  заменены на точные признаки `[data-station]` и `[data-scene="hub"]`.
- Firefox ожидал освобождения старого GL context после unmount. Chromium
  успевал собрать его GC, но это не было надёжной гарантией освобождения.
  Phaser создаёт отдельную незарегистрированную 1×1 служебную текстуру.
  Владелец WorldCanvas теперь освобождает свой native context микроочередью
  после Phaser DESTROY и синхронной очистки renderer. Независимый boundary
  подтвердил порядок, однократность и сохранение живого context restoration;
  отчёт `runtime-owned-context-boundary.json`. Точный остаток Firefox до
  исправления не объявляется измеренным: старый probe не сохранил snapshot.

Условие browser gate остаётся прежним: ноль живых текстур старого мира.
Добавлен snapshot до ожидания и на timeout с размерами оставшихся handles.
Фазовые снимки кандидата расширены до шести фаз на каждом из трёх размеров,
включая 844×390; исходная нагрузка baseline сравнения не изменена.
Второй кандидат ожидает полный автоматический браузерный прогон.

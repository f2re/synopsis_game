# Настоящие экраны R02

Снимки сделаны 11.11.2026 в Chromium через разрешённое управление интерфейсом. Они показывают настоящие `AvatarEditor`/`HubScreen`, общий композитор и принятые изображения. Профиль публичный и тестовый; сохранение стенда действует только в `sessionStorage` вкладки. Реальное серверное хранение проверено отдельными HTTP-сценариями.

- `*-tablet-final.png`: четыре настольные ситуации с полевой одеждой, планшетом и выбранной белкой; здесь `tablet` означает предмет, а не устройство.
- `wardrobe-saved-reload.png`: сохранённый тестовый образ после обновления страницы.
- `campus-saved-actual.png`: этот комплект в настоящем Phaser-кампусе.
- `*-narrow390.png`: реальная область iframe 390×844 при масштабе браузера 100%; отдельный снимок заднего ракурса показывает рюкзак.
- `browser-evidence.json`: поля Canvas, сохранение, одинаковый профиль, единственный предпросмотр, ширина и пауза вне окна.
- `files.json`: SHA-256 и байты исходных снимков и протокола. PNG не редактировались и не перерисовывались.

DevTools не использовались. Временная проба масштаба400% дала неподходящий размер захвата и не входит в свидетельства. Размер iframe подтверждает адаптивную компоновку, но не физическое мобильное устройство или его GPU.

Стенды: `/tools/review/modular-player.html` и `/tools/review/modular-player-narrow.html` при запущенном Vite dev server. Они не входят в production entrypoint. Независимая композиционная приёмка: [UI/art review](../../../2026-11-11-modular-situations-art-review.md).

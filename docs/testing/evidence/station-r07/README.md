# R07: сохранённые свидетельства браузерной проверки

Основной набор получен из [запуска 43360427117](https://github.com/f2re/synopsis_game/actions/runs/43360427117), 13 ноября 2026 года. Проверялось объединение `51b4da24733e7494c14a86aaca7a691d660a6991` из PR №129: ветка `8de3337ce352a9f47fed4334999b095b7c671553` с базой `395d4cff1d2506b810e41e3595e6553720ebfc16`. Три отчёта окружения и все шесть выбранных PNG скопированы из этого запуска побайтно.

[Манифест](manifest.json) указывает происхождение каждого файла, ссылки на архивы и SHA-256. Агент `screens_controls_review` скачал оба новых архива окружения через GitHub, сверил их SHA-256 с API и пересчитал все **150** исходных снимков: 72 Chromium, 70 Firefox и 8 исходной версии. Все суммы совпали. Сценарий в отчётах имеет SHA-256 `6f24aca2efa6d8b4ad0466822bd5a2fe28ebdf08ca88b2c0f02a08faa9bdff43`, который совпадает с `tools/test_station_environment_browser.cjs` в проверенной ветке.

## Происхождение общей матрицы экранов

Два отчёта общей матрицы сохранены из [запуска 43356695357](https://github.com/f2re/synopsis_game/actions/runs/43356695357): ветка `f89d4936abd29d85e21ac789aaf16005cf3949e4`, проверенное объединение `4e0300b27d9c4b17acecc3dbea84e57a8d8c247b`. Между этой веткой и `8de3337` изменён только сценарий окружения: добавлена проверка Space. Код приложения, ресурсы и сценарии общей матрицы экранов не менялись. В текущем запуске обе задачи общей матрицы также завершились успешно; номера заданий сохранены в `screen_revalidation` манифеста.

Эти старые JSON сохраняют исходное происхождение и не переименованы в результаты нового запуска. Агент повторно сверил SHA-256 обоих прежних архивов и самих JSON; все 572 перечисленных снимка найдены в архивах. Исходные отчёты этой матрицы не содержат хешей снимков, поэтому для них не заявляется сверка с исходным реестром хешей.

Записи включают фиксацию состояния и снимков; их количество не равно числу независимых пользовательских сценариев. В свежих отчётах окружения проверено по 18 открытий Enter и 18 открытий Space на браузер, с закрытием Escape и восстановлением фокуса. В каждом отчёте находятся 528 контрольных состояний фокуса, без потери фокуса документа.

Окружение проверено в Chromium 151.0.7922.34 и Firefox 153.0. Исходная версия и кандидат Chromium измерены одним сценарием на одном исполнителе с программным SwiftShader. В отчётах находятся исходные интервалы RAF, параметры графического контекста и сравнение. Эти интервалы не объявляются частотой реально нарисованных кадров или характеристикой физической GPU. Приёмка производительности выполнена независимо по сохранённым измерениям; поле `strictPerformanceGate=false` означает, что успешный статус сценария сам по себе не проверяет предел ухудшения 15%.

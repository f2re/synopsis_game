# Проверка инвентаря и кампуса в браузере

Дата: 10 ноября 2026. Проверка выполнена через поддерживаемый CUA-браузер с настоящей производственной сборкой web и настоящим API на localhost. Данные отдельного тестового профиля не относятся к рабочим аккаунтам.

## Подтверждённые сценарии

- Обычный первый вход без кода в изолированный тестовый профиль. Код или пароль в браузере не вводились.
- Выбор карточки отдельно от надевания; 24 предмета; поиск, пустой результат, сброс, категории, фильтр экипировки.
- Кепка и полный полевой комплект сохраняются через UI и остаются после перезагрузки; полевой комплект восстановлен после перезапуска API и нового входа.
- Спутник добавляется/снимается, готовые комплекты меняют только косметический профиль.
- Стрелка вправо/Home переключают вкладки с корректным `tabIndex`; Escape закрывает диалог выхода и возвращает фокус, сохраняя примерку.
- Отмена возвращает сохранённый комплект. Настоящее отключение тестового сервера оставляет черновик и показывает понятную ошибку. Перезапуск API инвалидирует прежнюю сессию; после штатного повторного входа сохранённый комплект доступен.
- Кампус показывает три актёра без ошибок, уменьшенное движение останавливает их анимацию, архив → кампус не удваивает персонажей.

## Границы проверки

Основной измеренный viewport: **1363×936 CSS px, масштаб 100%**. Узкие проверки: **454×312 CSS px при 300%** и **340×234 CSS px при 400%** в обычном Chrome. В них не было горизонтального переполнения, отсутствующих изображений и видимых кнопок менее 44×44 CSS px. Нативный checkbox фильтра входит в кликабельную метку высотой 44 px.

Узкие снимки подтверждают CSS-вёрстку и доступность при масштабировании. Это не телефон, не touch-эмуляция и не измерение FPS. DevTools запрещены политикой браузера; ограничение не обходилось. Попытка штатно изменить размер native-окна не повлияла на его размер. Полные снимки документа при масштабе 300/400% оказались обрезаны самим CUA API и не включены; вместо них сохранены корректные viewport-снимки участков страницы. При 100% сохранены полные снимки инвентаря.

Персонаж игрока в инвентаре остаётся модульным процедурным предпросмотром. Три детальных актёра кампуса — отдельные персонажи сцены. Эта проверка не утверждает, что произвольный сохранённый наряд стал детальным игровым спрайтом.

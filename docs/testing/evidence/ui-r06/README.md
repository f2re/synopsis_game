## Границы результата

Нативная проверка скрытой вкладки и звука выполнена в Chromium.
Firefox не объявлен прошедшим CDP-сценарий только из-за наличия audio
в списке запрошенных фаз.

Браузеры работали под Xvfb с программной графикой. Медленные интервалы
RAF настольного Chromium сохранены в полном отчёте; стабильные 60 FPS
и производительность физического GPU этим запуском не подтверждаются.
Научная оценка и координаты не менялись последним исправлением.

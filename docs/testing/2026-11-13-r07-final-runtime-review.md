## Входы и размеры окна

Сценарий окружения последовательно меняет окно 1366×768 → 390×844 → 844×390 при DPR 2. После изменения размера он ожидает обновления буфера Canvas и устойчивой геометрии всех шести входов. Прежняя геометрия не засчитывается.

Для каждого входа выполнены нажатия в центре и у четырёх краёв: 90 нажатий на браузер, 180 суммарно. В каждой точке проверен `elementFromPoint`, затем фактически открыто нужное окно. Escape закрывает его и возвращает фокус к тому же входу.

На каждом из трёх размеров все шесть входов открыты **Enter и Space**: по 18 циклов для каждой клавиши на браузер, 72 цикла в сумме. Свежие JSON содержат по 18 записей до Space, после Space и после восстановления фокуса. Переходы Tab/Shift+Tab сохраняют видимый фокус. В каждом отчёте записано 528 контрольных состояний; `documentFocused=false` не встретилось. Минимальная высота области входа на коротком экране — около 66,5 CSS px, выше требуемых 44 px; входы переднего ряда не перекрываются нижней панелью.

## Экраны и поведение сеанса

Сохранённая общая матрица покрывает главную станцию, библиотеку, справку, настройки, выход, портрет, учебную смену, блиц и административные действия. В JSON отсутствуют необработанные ошибки страницы, отсутствующие изображения, лишнее горизонтальное переполнение и прокручиваемые области без общей полосы прокрутки.

| Сценарий | Подтверждённое действие |
| --- | --- |
| Главная станция | Один мировой Canvas; совместимый адрес `/campus` возвращает тот же экран |
| Настройки | Громкость меняется с клавиатуры и сохраняется; изменение соседних флажков не теряет значение; режимы переживают перезагрузку |
| Библиотека | Поиск «точка росы», открытие определения, избранное после перезагрузки, пустой поиск, сброс фильтра и таблицы КН-01 |
| Справка | Раскрытие пояснений, переход к настройке атмосферы и возврат назад |
| Выход | Подтверждение, удержание фокуса в окне, отмена Escape, возврат фокуса к профилю, снятие Canvas после выхода |
| Выход из авторизованного сеанса | В Chromium очищен токен, сервер возвращает 401 для отозванной сессии, звуковые узлы остановлены |
| Прокрутка | Колесо, перетаскивание бегунка, вложенные области и крайние положения в обоих браузерах |

Для настроек, справки и административных элементов общая матрица дополнительно использует Space. На 390×844 есть сенсорные нажатия; это не заявляется проверкой нативного жеста прокрутки.

Выборочно просмотрены свежие PNG `entrances-844-dpr2.png` и `weather-rain-night-390.png`, а также прежние `settings-844.png` и `all-library-bottom-390.png` из неизменённой общей матрицы. Входы доступны, русские подписи читаются, фокус ограничен выбранной кнопкой. Прокрученные настройки на коротком экране сохраняют общую полосу; каталог библиотеки имеет отдельную внутреннюю область. Художественная оценка цветов, света и пиксельной графики вынесена в [отдельное заключение](../art/reviews/2026-11-13-r07-final-visual-review.md).

## Дождь и жизненный цикл

Свежий сценарий переключает дождь через настройки, входит в читальню и возвращается, сохраняя выбор. В читальне мировой Canvas отсутствует, после возврата он один. Пользовательское и системное уменьшение анимации, а также экономный режим оставляют ноль анимируемых штрихов и сохраняют дождливое оформление. В обычном режиме число штрихов ограничено 72; расчёт состояния и расписания отрисовки проверен отдельным агентом.

Настоящее скрытие вкладки проверено в Chromium без подмены `visibilityState` и без принудительного захвата фокуса драйвером. В скрытой вкладке штрихи выключены. После изменения даты и возврата солнечная фаза обновилась с дня на ночь за **154,4 мс**, дождь возобновился. Firefox этот конкретный сценарий не выполнял; его отчёт явно содержит пропуск `native-hidden-resume`.

Устранение ранее найденного обращения к уничтоженной сцене подтверждается браузерными переходами станция → настройки/читальня → станция. Отдельные проверки `test_hub_scene_lifecycle.cjs` и `test_avatar_world_boundary.cjs` входят в успешную текущую [сборку 43360427108](https://github.com/f2re/synopsis_game/actions/runs/43360427108). Они исполняют настоящий код с управляемыми объектами отрисовки и не заменяют аппаратную проверку восстановления WebGL.

## Производительность

Независимый агент `lighting_rain_review` пересчитал медианы исходных выборок текущего запуска и принял сравнение по установленному пределу ухудшения p95 не более 15%. Chromium использует ANGLE/SwiftShader, Firefox — программный Mesa/llvmpipe; вывод относится к этим исполнителям.

Для каждой группы проведены прогрев 3 секунды и три окна измерения по 5 секунд. В таблице приведены медианы трёх p50 и трёх p95 интервалов настоящего `requestAnimationFrame`. Это доступность кадров браузера, а не гарантированный FPS отрисованного мира.

| Окно и режим | База p50/p95, мс | R07 p50/p95, мс | Отношение p95 |
| --- | ---: | ---: | ---: |
| 1366×768, обычный | 83,3 / 100,0 | 66,6 / 66,7 | 0,667 |
| 1366×768, экономный | 66,6 / 66,7 | 66,6 / 66,7 | 1,000 |
| 1440×1000, обычный | 83,3 / 83,4 | 66,7 / 83,4 | 1,000 |
| 1440×1000, экономный | 83,3 / 83,4 | 66,7 / 83,4 | 1,000 |

Все четыре пары имеют `comparable=true`, различий параметров нет, `sameRunnerAndJob=true`. Бюджет соблюдён. Поле `strictPerformanceGate=false` в JSON означает, что сравнение не останавливает CI автоматически; вывод о соблюдении бюджета сделан независимой проверкой измерений. Уменьшение p95 в первой строке не доказывает повторяемого ускорения на произвольном компьютере.

Дождь измерен отдельно, поскольку в исходной версии видимого дождя не было. Его результаты и трактовка ограничений приведены в [описании R07](../design/STATION_ENVIRONMENT_R07.md#подтверждённая-приёмка). У Firefox нет парного измерения исходной версии, поэтому вывод об отсутствии ухудшения относится к сопоставимой матрице Chromium. Оценка памяти R01+NPC — 29,428 МиБ RGBA при бюджете 64 МиБ — сохраняется для неизменённого набора ресурсов и не равна всей памяти GPU.

## Границы заключения

Проверка подтверждает перечисленные браузерные сценарии и бюджет отсутствия ухудшения на программном графическом исполнителе. Длительная работа большого экрана, реальные учебные компьютеры, физический смартфон, аппаратное восстановление WebGL, задержка ввода под нагрузкой и прослушивание звука не объявлены проверенными этим документом. Короткие выборки JS heap не используются для вывода об отсутствии утечек за часы работы.

Учебное содержание, правильные ответы, реальный поток наблюдений и формулы расчёта солнечного положения в этой работе не изменялись. Предметную приёмку этот документ не заменяет.

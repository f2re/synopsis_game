# Проверка управления и главного экрана R01 в браузере

Дата: 09.11.2026. Проверяющий: основной агент задачи `R01-SPRITECOOK-20261109`.
Независимые решения по коду и изображениям находятся в
[интеграционной проверке](2026-11-09-r01-integration-review.md) и
[художественной приёмке](../art/reviews/2026-11-09-spritecook-r01-review.md).

## Проверенный результат

Новый кампус открывается на основном маршруте `/` без `hubArtPreview`.
В нём видны шесть самостоятельных фасадов, отдельные планы побережья и мощения,
растения, фонари, скамьи и фонтан. Надпись «Художественный закат» обозначает
авторское освещение; часы в верхней панели показывают фактическое время UTC.
Фон не выдаётся за оперативную метеорологическую информацию.

| Действие | Наблюдаемый результат |
|---|---|
| «Начать смену» без сессии | Открылась штатная форма входа; загрузились тестовая группа и два профиля из отдельного локального ростера |
| Escape в форме входа | Форма закрылась, фокус вернулся к главной кнопке |
| Enter на кнопке Кодового поста | Открылось описание корпуса с действием запуска смены |
| Escape в описании здания | Фокус вернулся к выбранному зданию |
| «Архив» → «На площадь» | Отобразился читальный зал, затем снова кампус; подпись сцены и кнопка перехода изменились |
| «Управление» | Открылась памятка по кнопкам и клавиатуре |
| «Маршрут» | Отобразились смена, вход в архив и явно обозначенные будущие модули |
| «Персонаж» у гостя | Открылся режим наблюдателя с переходом к штатному входу |
| «Учебный журнал» | Открылась учебная диспетчерская памятка с явным указанием её учебного характера |
| Три переключателя настроек | Изменилось состояние элементов; показано сообщение о сохранении |
| Перезагрузка после настройки | Все три выбранных значения сохранились |
| Закрытие настроек через Escape | Фокус вернулся к кнопке «Настройки» |

Настройки проверены также по наблюдаемой диагностике элемента игрового слоя:
при включении экономии значение `data-fps-limit` меняется с `60` на `30`,
`data-low-power` и `data-reduced-motion` становятся `true`, а при включении
звука `data-sound-muted` меняется с `true` на `false`.
Это доказательство применения настроек, а не измерение достигнутых 30/60 FPS.
В конце проверки звук, экономия и уменьшенное движение возвращены в исходные
выключенные состояния.

Исправление аудиоссылок отдельно проверено на всех 43 канонических ресурсах,
декодированием OGG и независимым функциональным сценарием. Сохранённый сценарий
запускается из корня репозитория:

```bash
node packages/world-engine/scripts/syncAudioManifest.mjs --check
node tools/test_world_audio_controls.cjs
```

Восприятие звука на слух в этой среде не заявляется. Авторизованное прохождение
смены в браузере не подменяется проверкой формы: полная последовательность из
10 заданий проверена отдельным изолированным HTTP-сценарием и описана в
интеграционном отчёте. Рабочие данные пользователей не использовались.

растяжение плитки в портретном режиме.

## Ограничения измерения производительности

Облачный браузер использовал Canvas fallback, а не WebGL. При одном активном
игровом окне 1363×936, видимой странице, выключенных дополнительных режимах и
лимите 60 наблюдались следующие единичные выборки:

| Сцена | Частота RAF | Отрисованные кадры в секунду | Доказательство |
|---|---:|---:|---|
| Прежняя процедурная | 1 | 1 | [Диагностика прежней сцены](evidence/r01-20261109/legacy-diagnostic.json) |
| Новая R01 | 1 | 1 | [Диагностика новой сцены](evidence/r01-20261109/r01-diagnostic.json) |

Во время загрузки и параллельной обработки файлов были другие низкие выборки
1–5 кадров/с. Эти наблюдения **не подтверждают целевые FPS и не доказывают
отсутствие регрессии**. Сравнение показывает, что оба варианта работают медленно
в этой среде; отдельный замер на целевых WebGL-устройствах остаётся обязательным.
Потеря/восстановление WebGL-контекста в браузере здесь не испытывались.
Обработчики и очистка ресурсов проверены по коду.

Старый бюджет растров и JavaScript не выполнен новым детальным набором; это
открытый пункт приёмки полноценного MVP, отдельно отмеченный в интеграционном
отчёте. Художественный и функциональный допуск этой итерации не заменяет
приёмку производительности для учебного пилота.

Сообщения расширения самого браузера исключены по его URL; успешное выполнение
этого шага не считается доказательством отсутствия любых ошибок за всё время работы.

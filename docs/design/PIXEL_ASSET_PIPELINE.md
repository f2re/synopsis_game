# Конвейер пиксельной графики и анимации

**Статус:** принято.

## Контракт подготовки исходников

Основной редактор — Aseprite. Свободная альтернатива — Pixelorama. Канонический редактируемый формат спрайта — `.aseprite`. Канонический редактор сцен — Tiled с JSON-форматами `.tmj/.tsj`.

Каждый производственный ресурс имеет манифест: стабильный идентификатор, путь к исходнику, логические размеры, pivot/origin, состояния анимации, роль палитры, слой мира, provenance и ожидаемые производные файлы.

Канонические художественные документы:

- `docs/design/PORTRAIT_ART_DIRECTION.md`;
- `docs/design/ENVIRONMENT_ART_DIRECTION.md`;
- `docs/design/SPRITE_CLASS_MATRIX.md`;
- `docs/design/LOCAL_AI_ASSET_PIPELINE_V2.md`.

## Производственный конвейер

Для локальной ИИ-генерации используются машинные профили `config/art-generation-profiles.json`.

```text
SPEC
→ CLASS PROFILE
→ PROMPT COMPILE
→ CANDIDATES
→ RANK/SELECT
→ CLASS-SPECIFIC REFINEMENT
→ ART REVIEW
→ TECHNICAL CONTRACT CHECK
→ APPROVED SOURCE
→ PACK
```

Нельзя автоматически принимать первый результат или превращать обычную AI-иллюстрацию в финальную графику агрессивным уменьшением и жёсткой квантизацией.

## Классы графики

Обязательные независимые классы:

- `dialogue_portrait`;
- `profile_portrait`;
- `world_character`;
- `companion_sprite`;
- `architecture_landmark`;
- `architecture_small`;
- `interactive_object`;
- `prop_sprite`;
- `terrain_tile`;
- `vegetation_sprite`;
- `ui_icon`;
- `ui_frame`;
- `vfx_small`;
- `large_scene`.

Один workflow для нескольких классов запрещён. Портрет, мировой персонаж, тайл, здание, UI и крупная сцена выполняют разные художественные задачи.

## Представления персонажа

Персонаж имеет разные графические представления:

- `dialogue_portrait`: 256×320 logical px, высокодетальный мастер;
- `profile_portrait`: 160×160, отдельная компактная композиция;
- `world_character`: 32×48, игровой спрайт;
- `companion_sprite`: отдельный профиль для животных и спутников.

Диалоговый портрет не должен выглядеть как увеличенный мировой спрайт. Мировой спрайт не должен быть безликим манекеном.

## Цвет

Количество цветов не является самостоятельным критерием качества. Используются классовые цветовые рампы и художественно оправданные диапазоны.

Ориентиры финальных ресурсов:

- dialogue portrait: 48–96;
- profile portrait: 36–72;
- world character: 24–48;
- companion sprite: 24–48;
- architecture landmark: 48–96;
- architecture small: 32–72;
- interactive object: 28–64;
- prop sprite: 24–56;
- terrain tile: 24–48;
- vegetation sprite: 28–64;
- UI icon: 12–32;
- UI frame: 24–56;
- VFX small: 16–40;
- large scene: 96–192.

Мягкие потолки задаются в `config/art-generation-profiles.json` и используются для диагностики шума, а не для автоматического художественного отклонения.

`strictQuantization=true` в generation profiles запрещён.

## Язык пикселя

Пиксельный стиль проекта не означает одинаковый размер художественного кластера для всех классов.

- портрет — мелкий аккуратный шаг и мимика;
- мировой персонаж — средние кластеры, силуэт и одежда;
- архитектура — материалы, конструкция и свет;
- prop — узнаваемость и фактура;
- тайл — поверхность и бесшовность;
- UI — чистота и семантика;
- сцена — композиция, глубина и погода.

## Прозрачность

Основной путь: контролируемый фон/матт + mask/segmentation → финальная alpha. `#FF00FF` разрешён только как запасной режим конкретного workflow.

## Нормализация и доработка

Доработка не исправляет плохую художественную основу.

Она может:

- очищать случайный шум;
- исправлять неудачные кластеры;
- гармонизировать цвет;
- очищать outline;
- приводить результат к логической сетке;
- очищать alpha.

Запрещены:

- majority downsampling;
- глобальная жёсткая posterization;
- уничтожение мимики;
- уничтожение материалов;
- изменение крупного силуэта;
- потеря световой атмосферы;
- превращение предметов и зданий в generic-иконки.

Если refined хуже selected raw, он отклоняется.

## Мир и вайб

Окружение проверяется по `ENVIRONMENT_ART_DIRECTION.md`.

В обитаемой сцене обязательны:

- профессиональная функция;
- читаемые материалы;
- погодное состояние;
- северо-западный характер;
- минимум три человеческих следа;
- один локальный сюжетный крючок.

## Политика анимации

Плавность движения не означает 60 нарисованных кадров/с. Для многих действий художественная частота составляет примерно 4–15 кадров/с; камера, tween и положение объекта могут обновляться с частотой дисплея.

## Техническая проверка

Технические проверки оценивают только:

- manifest/provenance;
- logical size;
- pivots/origin;
- frame-grid/tags/durations;
- alpha-контракт принятого финала;
- ссылки на generated outputs;
- воспроизводимость упаковки.

Плохой, но технически корректный ассет обязан иметь `art_status: fail`.

## Регрессионные проверки

- `tools/assets/check_asset_contract.py` — структура подходящих manifest-схем;
- `tools/assets/check_generation_profiles.py` — защита всех классов от разрушительной унификации.

Регрессионная проверка обязана падать, если:

- пропадает обязательный класс;
- два класса используют один workflow;
- включается majority downsampling;
- включается строгая квантизация;
- цветовой диапазон класса искусственно схлопывается;
- профиль теряет собственные `artPriorities`.

Эти проверки не заменяют арт-директора.

## Художественная приёмка

Арт-директор оценивает ассет в его реальном игровом масштабе.

Принимается не «пиксельность», а совокупность:

- функции;
- красоты;
- цвета;
- материала;
- света;
- читаемости;
- лора;
- вайба 26063.

Не принимаются неизвестное происхождение, ручная правка производных файлов, несовместимые pivots, невоспроизводимая сборка, случайное сглаживание маленьких спрайтов, дублирование полной геометрии дня/ночи и автоматическое `approved` по числу цветов.

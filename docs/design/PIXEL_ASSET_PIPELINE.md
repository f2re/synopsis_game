# Конвейер пиксельной графики и анимации

**Статус:** принято

## Контракт подготовки исходников

Основной редактор — Aseprite. Свободная альтернатива — Pixelorama. Канонический редактируемый формат спрайта — `.aseprite`. Канонический редактор сцен — Tiled с JSON-форматами `.tmj/.tsj`.

Каждый производственный ресурс имеет манифест: стабильный идентификатор, путь к исходнику, логические размеры, pivot/origin, состояния анимации, роль палитры, слой мира, provenance и ожидаемые производные файлы.

## Производственный конвейер

Для локальной ИИ-генерации применяется `LOCAL_AI_ASSET_PIPELINE_V2.md` и машинные профили `config/art-generation-profiles.json`.

```text
SPEC
→ CLASS PROFILE
→ PROMPT COMPILE
→ CANDIDATES
→ RANK/SELECT
→ CLASS-SPECIFIC REFINEMENT
→ ART REVIEW
→ TECHNICAL CONTRACT CHECK
→ APPROVED SOURCE
→ PACK
```

Нельзя автоматически принимать первый результат или превращать обычную AI-иллюстрацию в финальный pixel art агрессивным downsampling.

## Представления персонажа

Персонаж имеет разные графические классы:

- `dialogue_portrait`: 256×320 logical px, высокодетальный мастер;
- `profile_portrait`: 160×160, отдельная компактная композиция;
- `world_character`: 32×48, маленький игровой спрайт.

Один workflow для этих трёх классов запрещён. Диалоговый портрет не должен выглядеть как увеличенный мировой спрайт.

## Классы генеративных workflow

Минимально раздельно производятся:

- dialogue portrait;
- profile portrait;
- world character sprite;
- architecture;
- props;
- terrain/tiles;
- vegetation;
- UI icons;
- large scenes.

## Палитры

Количество цветов не является самостоятельным критерием качества. Используются классовые palette families и управляемые цветовые рампы.

Ориентиры финальных ресурсов:

- dialogue portrait: 48–96, мягкий потолок 128;
- profile portrait: 36–72, мягкий потолок 96;
- world character 32×48: 16–32;
- architecture: 48–96;
- scene 480×270: 96–192;
- props: 16–32;
- UI: 8–24.

Мягкий потолок используется для диагностики шума, а не для автоматического художественного отклонения.

Для диалогового портрета строгая квантизация выключена: нельзя терять глаза, нос, рот, возраст, оправу очков и фактуру лица ради маленького числа цветов.

## Язык пикселя

Мировые спрайты используют крупные кластеры. Диалоговые портреты используют мелкий аккуратный пиксельный шаг, включая осознанные 1–2 px детали лица и контролируемый локальный антиалиасинг.

Пиксельный стиль проекта не означает одинаковый физический размер художественного кластера для лица 256×320 и персонажа 32×48.

## Прозрачность

Основной путь: контролируемый фон/матт + mask/segmentation → финальная alpha. `#FF00FF` разрешён только как fallback конкретного workflow.

## Нормализация

Нормализатор не исправляет плохую композицию. Он может очищать шум, кластеры, контур, цветовые рампы и логическую сетку.

Запрещены:

- destructive majority downsampling;
- автоматическая posterization лица;
- перенос портрета в chunky-pixel язык;
- изменение возраста/пропорций;
- потеря семантически важных деталей.

Если refined-версия хуже selected raw, она отклоняется.

## Политика анимации

Плавность движения не означает 60 нарисованных кадров/с. Для многих действий художественная частота составляет примерно 4–15 кадров/с; камера, tween и положение объекта могут обновляться с частотой дисплея.

## Техническая проверка

Технические проверки оценивают только:

- manifest/provenance;
- logical size;
- pivots/origin;
- frame-grid/tags/durations;
- alpha-контракт принятого финала;
- ссылки на generated outputs;
- воспроизводимость упаковки.

Плохой, но технически корректный ассет обязан иметь `art_status: fail`.

## Регрессионные проверки

- `tools/assets/check_asset_contract.py` — структура manifests;
- `tools/assets/check_generation_profiles.py` — защита от возврата к маленьким грубым портретам и majority-downsampling.

Эти проверки не заменяют арт-директора.

## Художественная приёмка

Портрет принимается по `PORTRAIT_ART_DIRECTION.md`: как живой человек с мимикой, возрастом и характером, а не как пиксельный маскот.

Не принимаются неизвестное происхождение, ручная правка производных файлов, несовместимые pivots, невоспроизводимая сборка, случайное сглаживание маленьких спрайтов, дублирование полной геометрии дня/ночи и автоматическое `approved` по числу цветов.

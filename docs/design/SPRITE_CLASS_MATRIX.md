# Матрица классов графических ресурсов 26063

**Статус:** обязательный производственный контракт.

Матрица задаёт разные художественные и технические режимы для разных типов графики. Единый универсальный профиль запрещён.

Диапазоны цветов являются художественным ориентиром, а не жёсткой причиной отказа. Превышение мягкого потолка служит сигналом проверить шум и паразитные полутона.

## 1. Диалоговые портреты

Не являются мировыми спрайтами.

Обязательны:

- мимика;
- взрослые пропорции;
- читаемый возраст;
- мелкие особенности лица;
- индивидуальная одежда;
- локальный свет;
- различие выражений.

Запрещены грубый downsample, chibi, toy-like и автоматическая жёсткая квантизация.

## 2. Мировые персонажи

Маленький размер требует упрощения, но не обезличивания.

Должны сохраняться:

- узнаваемая причёска;
- характерная одежда;
- цветовые акценты;
- осанка;
- жест;
- различие между поколениями и профессиями.

Запрещено делать всех NPC из одного шаблона тела с заменой цвета рубашки.

## 3. Спутники и фауна

Важнее естественная поза и узнаваемость вида, чем идеальная симметрия.

Кот Паскаль, птицы и белки не должны превращаться в эмодзи или декоративные талисманы.

## 4. Архитектура

Для крупных зданий разрешена богатая палитра. Важны:

- конструкция;
- материал;
- возраст;
- окна;
- технические детали;
- погодное состояние;
- свет;
- человеческий масштаб.

Нельзя сводить здание к условной пиктограмме.

## 5. Малые архитектурные элементы

Навесы, ворота, киоски, мачты, ограждения и технические пристройки должны продолжать язык конкретной локации, а не быть generic-набором.

## 6. Интерактивные объекты

У объекта должны быть визуально различимые состояния, если они существуют:

- обычное;
- активное;
- открытое;
- занятое;
- неисправное;
- подсвеченное взаимодействием.

Состояния не должны отличаться только обводкой UI.

## 7. Props

Для предметов допускаются более тонкие кластеры, если они помогают материалу и узнаваемости.

Кружка, карандаш, барограф, папка, телетайп и радиозонд должны отличаться по фактуре и силуэту, а не только по цвету.

## 8. Тайлы

Тайлы требуют большей дисциплины, чем отдельные иллюстрации:

- без случайных одиночных пикселей;
- без заметного повторяющегося узора;
- без искусственного мелкого шума;
- с вариациями состояния поверхности.

## 9. Растительность

Одна зелёная палитра для всех растений запрещена.

Нужно различать:

- породу;
- сезон;
- влажность;
- направление ветра;
- освещение.

## 10. UI

UI может быть пиксельным, но обязан оставаться чистым и современным.

Нельзя переносить фактуру мира в текстовые области и мешать читаемости.

## 11. Эффекты

Эффекты вторичны относительно содержания сцены.

Дождь, снег и туман не должны использоваться для маскировки слабого фона или плохой архитектуры.

## 12. Крупные сцены

Крупная сцена имеет самый широкий цветовой бюджет.

Она обязана поддерживать:

- глубину;
- композиционный центр;
- световое состояние;
- атмосферу Северо-Запада;
- минимум три человеческих следа в обитаемом месте;
- один локальный сюжетный крючок;
- профессиональную функцию места.

## 13. Общие запреты

Для всех классов запрещены:

- universal workflow;
- majority downsampling;
- auto-approve по числу цветов;
- generic asset без связи с функцией;
- насильственное выравнивание всех классов по одному размеру пикселя;
- ухудшение выбранного raw-кандидата при refinement;
- смешение ролей портрета, спрайта, UI и крупной сцены.

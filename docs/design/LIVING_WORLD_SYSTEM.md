# Living World System — фон, время суток и интерактивная среда

**Статус:** accepted-art-direction

## 1. Цель

Фон «Синоптического центра» — не декорация, а **живое пространство возврата**. Игрок должен замечать, что мир меняется, и иметь причины задержаться в хабе на несколько минут даже без запуска матча.

## 2. Временные состояния мира

Минимально поддерживаются:

- рассвет;
- день;
- золотой час / сумерки;
- вечер;
- ночь.

По умолчанию хаб синхронизируется с локальным временем инсталляции/сервера. Для demo/kiosk допускается ускоренный цикл.

Каждое состояние меняет:

- цвет неба и дальнего плана;
- освещение фасадов;
- активные окна;
- фонари;
- количество NPC;
- набор птиц/животных;
- звуковой фон;
- интенсивность декоративных анимаций.

## 3. Сезонность

Отдельный слой состояния:

- весна;
- лето;
- осень;
- зима.

Меняются листья, снег, клумбы, декор, набор фоновой фауны, сезонные баннеры и редкие микро-события.

Сезонная визуализация не должна подменять учебные метеоданные на карте.

## 4. Слои сцены

Рекомендуемая структура:

```text
L0 sky gradient / stars
L1 far clouds / moon / sun
L2 mountains / city / water
L3 campus architecture
L4 vegetation / lamps / flags
L5 NPC and animals
L6 interactable ambient objects
L7 UI
L8 feedback effects
```

Каждый слой может иметь независимый parallax coefficient.

## 5. Ambient-анимации

Обязательный набор для первого production-прохода:

- 2–4 типа облаков с разной скоростью;
- стая птиц на дальнем плане;
- одиночные птицы на перилах/крыше;
- вращение радара;
- мигание авиационных огней на мачте;
- движение флагов и ветроуказателя;
- редкий аэрологический шар;
- проходящие NPC;
- включение/выключение света в отдельных окнах;
- лёгкое движение деревьев/листвы;
- вода/блики на воде;
- редкий транспорт/самолёт в глубоком фоне.

## 6. Интерактивные микро-события

Живые объекты должны реагировать на пользователя.

Примеры:

### Птицы

- синичка прыгает по перилам;
- чайка/баклан реагирует на клик, перелетает на другой объект;
- редкая птица может попасть в «журнал наблюдений»;
- стая может вспорхнуть при клике на дерево/крышу.

### Белки и мелкие животные

- белка перебегает по дереву;
- может спрятать орех/предмет;
- редкое появление даёт косметическую коллекционную отметку, а не игровую силу.

### Объекты центра

- радар ускоряет оборот при клике;
- флюгер показывает короткую анимацию направления;
- метеозонд улетает;
- окно архива на секунду открывает сценку внутри;
- глобус/фонтан реагирует коротким циклом;
- плакат/доска меняет фразу дня;
- анемометр вращается;
- настольный кот/собака/птица имеет idle reactions.

## 7. Discoverables

Фоновые взаимодействия могут наполнять отдельную коллекцию `World Discoveries`:

- птицы;
- животные;
- редкие самолёты/зонды;
- сезонные события;
- скрытые предметы центра;
- небольшие исторические/научные пасхалки.

Discoverables не влияют на Ranked.

## 8. Событийная модель

Пример событий:

```text
WORLD_TICK
TIME_PHASE_CHANGED
SEASON_CHANGED
AMBIENT_EVENT_STARTED
AMBIENT_EVENT_ENDED
WORLD_OBJECT_CLICKED
DISCOVERY_UNLOCKED
RARE_VISITOR_SPAWNED
ROOM_ACTIVITY_CHANGED
```

Состояние мира не должно требовать серверного broadcast на каждый кадр. Сервер задаёт seed/state, клиент воспроизводит локальные детерминированные или псевдослучайные циклы.

## 9. Динамическая плотность

В хабе может быть много жизни, но во время Blitz/PvP фон приглушается.

Профили:

- `hub-rich` — много ambient life;
- `study-calm` — минимум отвлекающих событий;
- `battle-focus` — только дальние циклы;
- `projector-attract` — зрелищно и заметно издалека;
- `reduced-motion` — статичные состояния + редкие дискретные изменения.

## 10. Техническая реализация без runtime-генерации изображений

Использовать:

- sprite sheets;
- CSS transforms;
- SVG/Canvas для простых фигур и атмосферных слоёв;
- небольшие tile layers;
- palette swaps;
- shader/gradient overlays при необходимости;
- state machine для времени суток.

Не использовать один огромный prerendered background как единственный источник сцены.

## 11. Свет и время суток

Вместо пяти отдельных фонов предпочтительно иметь общую архитектуру + набор lighting overlays:

- sky palette;
- sun/moon sprite;
- ambient tint;
- window-light mask;
- lamp mask;
- shadow tint;
- star layer;
- fog/rain/snow layer.

Это позволяет сохранять одинаковую геометрию и дешёво менять атмосферу.

## 12. Rare ambient events

Низкая вероятность появления:

- очень большая стая птиц;
- необычный аэростат;
- редкий самолёт;
- северное сияние в сезонном event-profile;
- праздничное оформление центра;
- белка на редком маршруте;
- кот в неожиданном окне;
- «ночная смена» с почти пустым кампусом.

Редкость нужна не для FOMO, а для ощущения, что мир живёт самостоятельно.

## 13. Звук

Опциональный ambient слой:

- город вдали;
- ветер;
- птицы;
- дождь;
- щелчки аппаратуры;
- приглушённые голоса в холле;
- редкий звон/сигнал станции.

Звук отключаемый и не нужен для понимания задания.

## 14. Acceptance criteria

Living world считается реализованным для MVP+, если:

- [ ] есть минимум 4 временных состояния;
- [ ] освещение не требует отдельного полного bitmap на каждое состояние;
- [ ] минимум 6 независимых ambient loops;
- [ ] минимум 5 кликабельных фоновых объектов;
- [ ] есть минимум 3 вида животных/птиц;
- [ ] работает reduced-motion;
- [ ] battle screen может приглушить фон;
- [ ] фоновые события не перекрывают учебный интерфейс;
- [ ] world state переживает navigation/reconnect без резких скачков.

# R07: освещение и дождь на территории станции

**Версия:** кандидат 0.5.2, 13 ноября 2026 года. **Статус:** реализовано; браузерная и итоговая художественная приёмка ожидают CI и просмотра снимков.

## Свет по времени станции

Главная сцена использует дату и `scene.world_location` из [реестра рабочего контура R01](../../packages/world-engine/src/assets/hub/r01-approval.json). Постоянное предзакатное освещение выключено. Фазу определяет существующий `HubTimeOfDay`; расчёт положения Солнца и его предметные границы описаны в [методике освещения](../meteorology/HUB_SOLAR_PHASE_METHOD.md).

| Фаза | Оформление |
| --- | --- |
| День — `day` | Нейтральное небо и естественные цвета территории |
| Рассвет — `dawn` | Мягкий утренний оттенок, умеренный свет окон |
| Предзакатный период — `golden_hour` | Существующий фон заката, если выбран ясный фон |
| Сумерки — `twilight` | Более холодная и тёмная территория, освещённые окна |
| Ночь — `night` | Тёмное небо, читаемые здания и выраженный свет окон и фонарей |
| Белые ночи — `white_nights` | Светлое ночное небо и спокойное освещение территории |

Для всех состояний, кроме ясного `golden_hour`, используется один нейтральный фон SpriteCook без нарисованного солнечного диска. При дожде он применяется и в предзакатный период. Оттенки задаются отдельным изображениям сцены; цвета учебных схем и обычного интерфейса не меняются.

Свет окон кодового поста, архива и фонаря выделен в три прозрачные маски из существующих исходников. Маски сохраняют геометрию этих элементов и рисуются поверх затемнённых зданий. Отдельные изображения каждого здания для шести фаз не создаются.

## Дождь, пауза и возврат

Существующий выбор «Дождь», «Без дождя» или «Иногда дождь» определяет оформление и звуковой слой на станции и в читальне. `WorldCanvas` передаёт абсолютный снимок `ui:weather` с полями `mode` и `animate`; тот же снимок хранится в реестре игры как `ui.weather`. Второго погодного цикла нет.

Поле дождя содержит до **72 штрихов** и обновляется с частотой **12 Гц**. Уменьшенное движение, экономия ресурсов, скрытие вкладки и потеря графического контекста убирают штрихи. Выбранный дождливый фон сохраняется; звуком управляют собственные настройки громкости и общий жизненный цикл вкладки.

После возвращения во вкладку `HubTimeOfDay.refresh()` синхронно сверяет фазу с текущей датой. Ожидать очередной 30-секундной проверки не требуется. Позднее событие готовности сцены в скрытой вкладке оставляет анимацию выключенной. Кадровые события в React не отправляются; фактические фаза, погода и число штрихов публикуются дискретно через `world:environment_mode`.

На низком горизонтальном экране масштаб камеры учитывает высоту нижней панели и зазор над ней. Входы переднего ряда сохраняют доступную область нажатия. Браузерный сценарий отдельно проверяет центр и четыре края каждого входа после изменения размера окна.

## Подготовленные проверки

Используется закреплённый в CI Node.js 22.23.4. Перед браузерной проверкой требуются зависимости и сборка приложения:

```bash
python tools/assets/build_hub_r01.py --check
python tools/assets/build_hub_lighting_r07.py --check
node --experimental-strip-types --test packages/world-engine/src/scenes/hub/HubTimeOfDay.test.ts
node --experimental-strip-types --test packages/world-engine/src/scenes/hub/r01Environment.test.ts
node tools/test_avatar_world_boundary.cjs
pnpm typecheck
pnpm build
node tools/test_station_environment_browser.cjs
```

Браузерный сценарий запускает собранное приложение с отдельным настоящим сервером. Подготовлены Chromium и Firefox, шесть фиксированных дат, размеры 1366×768 и 390×844, изменение размера до 844×390 при DPR 2, настройки дождя и движения, переход через читальню, мышь и клавиатура. Настоящее скрытие вкладки проверяется в Chromium без эмуляции видимости; соответствующий пропуск Firefox отмечается в отчёте.

Переменные `STATION_BROWSER`, `STATION_PLAYWRIGHT_MODULES`, `CHROMIUM_PATH` и `STATION_ENV_EVIDENCE` задают браузер, расположение Playwright и каталог доказательств. `STATION_ENV_BASELINE=1` запускает измерения исходной версии. В [workflow экранов станции](../../.github/workflows/station-screens.yml) выделен отдельный этап: ясная сцена сравнивается в одинаковой фазе, новый дождь измеряется отдельно. После прогрева сохраняются три выборки интервалов RAF по пять секунд, параметры графического контекста, снимки canvas и контрольные суммы. Настроенный предел частоты кадров не считается измеренной производительностью.

## Граница изменения и приёмка

Оформление станции не является источником метеорологических наблюдений. Выбор дождя и цветовая фаза не изменяют телеграммы, учебные ответы, прогресс или оценку. Это техническая граница; дополнительных оговорок в игровом интерфейсе она не вводит.

Подготовленный сценарий сам по себе не подтверждает прохождение браузерной проверки. Итоговые выводы фиксируются после CI в [независимой проверке выпуска](../testing/2026-11-13-station-r07-release-review.md) и [художественном заключении](../art/reviews/2026-11-13-station-r07-review.md). Работа на физических учебных компьютерах и мобильных GPU требует отдельного измерения.

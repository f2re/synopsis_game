# Главное меню, библиотека и справка станции

Срез: `STATION-SCREENS-R01`, 12 ноября 2026 года. База — `main` на `64b19ac`; несвязанный кандидат движения R03 из PR #126 в эту работу не включён.

## Найденные пробелы

Компонент TitleScreen не был подключён: корневой маршрут сразу показывал кампус. Два разных экрана настроек сохраняли несовместимые наборы параметров. Архив открывал помещение, но не давал читать понятия. Справка существовала как короткое модальное описание управления. Выход закрывал профиль без отдельного подтверждения и экрана завершения; при этом поздний ответ входа мог восстановить сеанс.

## Реализованная навигация

`/` — отдельное главное меню с большим знаком 26063, одной основной кнопкой входа в кампус, доступом к смене, библиотеке, помощи, настройкам и выходу. Слева навигация, справа компактный многослойный читальный уголок. Phaser загружается при посещении кампуса; главному меню он не нужен.

`/campus` сохраняет существующий живой мир. Знак станции и меню профиля возвращают к главному экрану. Нижняя панель открывает библиотеку. В карточке Архива можно отдельно открыть библиотеку или посетить помещение; внутри читального зала есть видимая кнопка чтения. Отдельные будущие учебные модули сохраняют честную маркировку готовности.

`/library` — 30 статей с поиском по понятиям, обозначениям и пояснениям, категориями, локальными закладками, связанными понятиями, источниками и областью применения. Поиск нормализует ё/е, дефисы и разделители кодов; короткие обозначения T/Td и АТ/ОТ не ищутся как произвольная часть слога. На узком экране каталог сменяется страницей чтения. Параметр `?q=` задаёт начальный запрос. Библиотека не отправляет запросы к модели или внешнему API при поиске.

`/codebook` — существующие таблицы КН-01, приведённые к нативному диалогу с фокусом, Escape и поиском. Уточнены источники и различия национального КН-01 и международного FM 12. Исправления ограничены справочником: серверные эталоны текущих учебных заданий не менялись. Исторические противоречия опубликованного учебного профиля перечислены в отчёте библиотеки; это не скрытая смена правильных ответов.

`/help` — пошаговое первое дежурство, реальное управление клавиатурой и мышью, восемь ответов на вопросы, ссылки на библиотеку и настройки. Тексты различают принятые сервером результаты, неотправленный ответ, локальные закладки и настройки браузера.

`/settings` — единый экран параметров; контракт описан в [STATION_ATMOSPHERE.md](STATION_ATMOSPHERE.md). `/shift` требует входа и сохраняет существующую логику учебной смены.

`/exit` — завершение сеанса с подтверждением. Музыка и фоновые звуки остановлены, Phaser размонтирован. Игра не обещает закрыть произвольную вкладку программно. Профиль и результаты на сервере не удаляются; настройки и закладки сохраняются.

## Сеанс и отказоустойчивость

- Публичные экраны доступны, пока идёт проверка сохранённого входа. Ошибка сети не уничтожает токен как будто он недействителен; 401/403 закрывают недействительный вход.
- Проверка сессии и серверный выход имеют ограничение ожидания 8 секунд. При неудаче выхода локальный вход закрывается, а экран честно сообщает об отсутствии подтверждения сервера.
- Закрытие формы входа, навигация и выход отменяют поколение ожидаемых входов. Запоздавший ответ не восстанавливает профиль; созданная им серверная сессия отзывается отдельным запросом.
- Запрос выхода фиксирует старый токен до его немедленного локального удаления. Позднее завершение отзыва не удаляет новый вход.
- При запрете sessionStorage работает память текущей вкладки; недоступность хранилища не ломает публичное меню и выход.
- Позднее обновление внешности/кода не применяется к другому сеансу.
- Возврат со вспомогательных страниц использует историю навигации и ограниченный список внутренних адресов. Неизвестный адрес показывает понятную страницу возврата.

## Графика и происхождение

Принятые иконки и элементы интерфейса используются повторно. Для читального уголка выполнена одна генерация SpriteCook Nano Banana 2.1, 12 кредитов. Исходный ответ провайдера сохранён; отдельный воспроизводимый художественный шаг убирает псевдоподпись и объединяет только практически одинаковые цвета без принудительной целевой палитры. Двухслойный Aseprite остаётся редактируемым источником.

`ui.station-room-r01.json` фиксирует исходник, происхождение, геометрию стекла, контрольные суммы и независимую приёмку. `build_station_room_r01.py` создаёт внешний вид окна, передний интерьерный слой и бинарную маску стекла; дождь не накладывается на книгу, лампу или раму. В библиотеке сцена переиспользуется компактно в каталоге; на телефоне она скрыта, оставляя место чтению.

## Бюджеты текущего изменения

| Область | Ограничение |
| --- | --- |
| Комната | 512×288; три PNG; суммарно менее 300 KiB |
| Декоративный дождь | Не более 12 элементов, CSS transform, без кадровых React-обновлений |
| Уменьшенное движение / экономия / скрытая вкладка | Движущихся капель нет |
| Музыка | Один общий AudioContext; один таймер 250 мс; максимум 10 голосов |
| Начальная загрузка | Без создания игрового canvas; Phaser загружается отдельно |
| Кампус | Существующий лимит 60 кадров/с, экономичный профиль 30 кадров/с |
| Интерактивные элементы новых экранов | Основные кнопки не менее 44 CSS px по высоте |

Числа кадров в профиле — установленные ограничения, не измеренная производительность пользовательского устройства. Браузерная проверка сохраняет фактическую геометрию, время кадров и потребление памяти отдельно. Длительная работа на проекторе и физический мобильный GPU не подтверждаются проверкой Chromium в CI.

## Проверки и независимое владение

- `library`: библиотека, предметные источники и Codebook. Независимая методика — `sprite_art` в роли meteo-verifier.
- `settings_audio`: настройки, музыка и существующий звуковой жизненный цикл. Независимая проверка — `library` в ролях web-performance/security.
- `sprite_art`: исходник читального уголка и сборка. Независимые pixel-art-quality-reviewer, затем art-director — `settings_audio`.
- `root`: маршруты, главный экран, помощь, выход и интеграция кампуса. Независимая проверка сеанса — `settings_audio`; итоговая интеграционная приёмка выполняется другим агентом после браузерных результатов.

Команды:

```bash
node tools/test_library.cjs
node tools/test_station_atmosphere.cjs
node tools/test_world_audio_controls.cjs
node tools/test_session_navigation.cjs
python tools/assets/build_station_room_r01.py --check --require-approved
pnpm typecheck
pnpm build
node tools/test_station_screens.cjs
```

Последняя проверка запускает Chromium, настоящий сервер с изолированным тестовым списком пользователей и рабочую сборку веб-приложения. API и графика не подменяются. Размеры: 1440×1000, 390×844 и 844×390. Проверяются поиск, чтение, закладки после перезагрузки, настройки, архив, диалоги, фокус, вход, отзыв серверной сессии и реальные звуковые узлы. Снимки и JSON сохраняет workflow «Экраны станции — браузерная проверка»; сами наличие теста или сборка не обозначают его прохождение.

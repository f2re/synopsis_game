# Станция: настройки, музыка и погода за окном

Дата реализации: 2026-11-12. Владелец: `audio-ambient-designer` / `settings_audio`.

## Единые настройки

`apps/web/src/features/settings/settingsStore.ts` хранит типизированные настройки под прежним ключом `synopsis_26063_settings`. При первом чтении подхватываются `soundEnabled`, `reducedMotion`, `lowPower` из старых настроек кампуса. Неверный JSON, массивы, строки вместо чисел, бесконечные значения и посторонние поля не попадают в состояние. Громкости ограничены диапазоном 0–100.

`useSettings()` возвращает текущий снимок, `updateSettings(patch)` применяет изменение сразу и возвращает результат записи. При запрете localStorage настройки действуют до перезагрузки; интерфейс сообщает об этом. `hubPreferences.ts` — адаптер этого же состояния, а не второе независимое хранилище. Изменения синхронизируются между вкладками событием `storage`.

Системное уменьшение движения учитывается поверх сохранённого выбора пользователя. Оно не записывается как постоянный выбор. Настройки не меняют учётную запись, ответы, прогресс или исходные наблюдения.

## Владение звуком

Один `AtmosphereProvider` установлен над маршрутами приложения. Интерьерные фоны принадлежат ему, фон кампуса — существующему `WorldCanvas`. Оба используют единственный `WorldAudioManager`, его буферы, шины и ограничитель уровня. Новый пакет не создан: `@synopsis/world-engine/audio` открывает существующий модуль без загрузки Phaser на главном экране.

| Поверхность | Музыка | Фоновое окружение | Игровые сигналы |
| --- | --- | --- | --- |
| `home`, `library`, `help`, `settings` | По настройке | Комната; дождь по декоративному циклу | По настройке |
| `campus` | По настройке | Управляется `WorldCanvas`; звуковой слой дождя следует выбранному режиму | По настройке |
| `study` | Остановлена | Остановлено | По настройке |
| `silent` | Остановлена | Остановлено | Выключены |
| Скрытая вкладка | Остановлена | Остановлено | Выключены |

Звук по умолчанию выключен. Даже сохранённое разрешение не запускает звук до первого доверенного действия пользователя в текущей вкладке. Синтетическое DOM-событие не снимает этот запрет. Фоновая музыка не является сигналом правильности ответа; всё существенное доступно без звука.

## Музыка

`StationMusic.ts` содержит исходную партитуру из 64 долей (68 ударов/мин) и синтез мягких синусных тонов. Партитура создана для проекта; чужие записи и мелодии не импортированы. Длительность полного круга — около 56,5 с. Мелодические фразы разделены паузами, бас вступает раз в восемь долей. В экономичном режиме дополнительный тон сопровождения не запускается.

Используется новая шина `music` внутри существующего Web Audio-графа: она проходит через общий регулятор громкости и существующий ограничитель. Отдельный аудиоконтекст не создаётся. Изменения громкости сглаживаются существующим методом шины, окончание музыки затухает за 120 мс.

Бюджет: один таймер планирования раз в 250 мс, максимум десять активных голосов, включая затухающие после выключения. Нет `requestAnimationFrame` для музыки. Длинная задержка таймера пропускает прошедшие ноты, а не воспроизводит их одновременно. При остановке планировщик удаляется, узлы отключаются по окончании затухания. При отсутствии Web Audio музыка молчит, остальные функции остаются доступны.

## Декоративная погода

`ambientWeatherAt()` определяет только оформление: в авторском 12-минутном цикле дождь идёт с восьмой по одиннадцатую минуту. Есть явные режимы «Без дождя» и «Дождь». Это не прогноз, не текущие наблюдения и не геолокация пользователя. Учебные данные от этого выбора не зависят. Проверка фазы происходит раз в 15 секунд; в скрытой вкладке таймер не работает.

В помещении повторно используется принятый `audio.ambient.archive-room`; дождь добавляется через уже имеющийся `audio.ambient.rain-soft` с уменьшенным уровнем. Происхождение этих файлов закреплено в `assets/manifests/audio.collection.json`. Новые сторонние звуковые файлы не добавлены.

Видимый дождь этого этапа существует в `StationRoomArt` за маской окна. Phaser-сцена кампуса не получила нового визуального дождя; для неё подключён только существующий звуковой слой. Это не заявляется как полная визуальная система погоды кампуса.

## Проверка

```bash
node tools/test_station_atmosphere.cjs
node tools/test_world_audio_controls.cjs
```

Первый тест проверяет разбор и миграцию настроек, отказ хранения, системный режим доступности, запрет автозапуска, правила скрытой вкладки/выхода/смены, календарь декоративного дождя и исполнение настоящего музыкального планировщика на управляемом Web Audio-стенде. 500 секунд звукового времени проверены без ускоренного «нагона» нот; наблюдаемый максимум — четыре голоса при бюджете десять. Повторные включения учитывают затухающие голоса. Второй тест проверяет имеющиеся фоновые слои, отключение звука, позднюю загрузку и отмену ненужных кадровых циклов.

Это автоматические проверки логики, не подтверждение прослушивания и не измерение устройства пользователя. Финальная визуальная, слуховая и браузерная приёмка выполняется независимо от автора.

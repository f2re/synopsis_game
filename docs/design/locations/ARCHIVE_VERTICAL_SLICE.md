# Архив — первый вертикальный срез локации

**Статус:** принято к реализации

Архив — первая полностью оформляемая локация. Он нужен как эталон того, как в дальнейшем строятся все помещения: внешний объект в мире → состояние доступности → вход → внутренний экран → заблокированные разделы → возврат в центр.

## 1. Роль Архива

Архив должен выглядеть менее формально, чем главное здание: компактный тёплый корпус/домик с книжными полками в окнах, деревянными деталями, растениями и читаемым входом.

Визуальный образ:

- 1–1,5 этажа;
- тёплая черепичная или тёмная простая крыша;
- кремовая/каменная основа + дерево;
- большое окно с видимыми полками;
- маленький навес или крыльцо;
- один книжный знак/пиктограмма без большой вывески;
- 1–2 ящика/коробки у входа;
- лавка или небольшая клумба рядом;
- допустима белка как редкое событие рядом с архивом.

## 2. Состояния внешней локации

### `available`

Архив доступен с первого рабочего среза.

- тёплое окно;
- вход подсвечен;
- табличка `Архив`;
- вторичная строка `Метеоданные и отчёты`;
- при наведении появляется тонкая золотая рамка;
- нажатие открывает интерьер Архива.

### `active`

Используется, если внутри появилась новая архивная ситуация.

- маленькая точка/маркер события;
- локальная мягкая подсветка таблички;
- без мерцания.

### `locked`

Для самого Архива в первом срезе не используется, но компонент должен поддерживать это состояние для других зданий.

## 3. Остальные локации первого мира

Пока их экраны не реализованы, они обязаны выглядеть заблокированными и объяснять условие:

| Локация | Состояние | Текст |
|---|---|---|
| Картографический класс | locked | `Откроется на ур. 2` |
| Аэрологическая лаборатория | locked | `Откроется на ур. 3` |
| Радарный комплекс | locked | `Откроется на ур. 4` |
| Обсерватория | locked | `Откроется на ур. 5` |
| Турнирный зал | locked | `Откроется позже` |

Нажатие на такую локацию открывает небольшое спокойное сообщение, а не пустой экран.

## 4. Интерьер Архива

Композиция 480×270:

```text
┌────────────────────────────────────────────────────────┐
│ верхняя полоса: Архив                     [Назад]      │
│                                                        │
│  ┌──────────┐     ┌──────────────┐     ┌──────────┐   │
│  │ шкафы    │     │ стол/лампа   │     │ шкафы    │   │
│  │ коробки  │     │ папка/лупа   │     │ каталоги │   │
│  └──────────┘     └──────────────┘     └──────────┘   │
│                                                        │
│  Архивные ситуации     Старые карты      Коллекции     │
│  [заблокировано]       [заблокировано]   [позже]       │
│                                                        │
│                [ Вернуться в центр ]                   │
└────────────────────────────────────────────────────────┘
```

Интерьер не должен напоминать меню поверх пустого фона. Полки, стол и коробки образуют реальное помещение, а интерфейсные карточки лежат поверх него только там, где нужны действия.

## 5. Первый набор пиксельных объектов

Минимальный набор, с которого начинается производство:

1. `archive.facade.base` — фасад Архива;
2. `archive.door.closed` / `archive.door.open`;
3. `archive.window.dark` / `archive.window.warm`;
4. `archive.bookshelf.tall`;
5. `archive.bookshelf.low`;
6. `archive.box.closed`;
7. `archive.box.open`;
8. `archive.catalog.cabinet`;
9. `archive.table`;
10. `archive.lamp.off` / `archive.lamp.on`;
11. `archive.folder.stack`;
12. `archive.magnifier`;
13. `archive.wall.mapframe` — пустая рамка без профессиональных метеосимволов;
14. `archive.sign.book` — простая книжная пиктограмма;
15. `ui.location.lock` — замок для заблокированных зданий.

Для первого технического среза разрешены процедурные пиксельные прототипы в Phaser. Они являются временной геометрией и должны заменяться на `.aseprite`-источники через обычный asset pipeline без изменения семантических ID.

## 6. Кнопки Архива

### `Вернуться в центр`

- тип `secondary`;
- всегда доступна;
- клавиатура: Enter/Space;
- возвращает в Hub.

### `Архивные ситуации`

На текущем этапе:

- тип `locked`;
- подпись `Появятся после подключения пакетов ситуаций`;
- при нажатии показывает объяснение.

### `Старые карты`

На текущем этапе:

- тип `locked`;
- подпись `Откроется после первой завершённой смены`.

### `Коллекции`

На текущем этапе:

- тип `disabled`;
- подпись `В разработке`.

## 7. Нижняя навигация главного мира

До появления соответствующих экранов:

- `Профиль` — disabled, `В разработке`;
- `Инвентарь` — disabled, `В разработке`;
- `Начать смену` — визуально главная кнопка, но при нажатии показывает `Экран смены ещё не подключён`;
- `Лига` — disabled, `В разработке`;
- `Архив` — доступна и открывает Архив.

Нельзя делать визуально активную кнопку, которая ничего не делает.

## 8. Первые анимации

Для этого среза достаточно:

- тёплое окно: 2 кадра/состояния, очень редкое изменение;
- лампа: включено/выключено;
- дверь Архива: 3 кадра, без интерполяции;
- 1 облако в Hub: плавное перемещение объекта при статичных пиксельных кадрах;
- 1 птица или белка как редкий декоративный цикл;
- hover/focus кнопки: изменение рамки, без масштабирования с фильтрацией.

## 9. Критерии готовности среза

- [ ] Hub запускается в 480×270;
- [ ] Архив визуально выделен как доступная локация;
- [ ] пять остальных локаций имеют состояние `locked` и конкретный текст условия;
- [ ] Архив открывается и возвращается обратно;
- [ ] внутри Архива видны как минимум шкаф, стол, лампа, коробки и каталог;
- [ ] все ещё не реализованные действия объясняют состояние;
- [ ] primary/secondary/locked/disabled/focus состояния кнопок различимы;
- [ ] пиксельное сглаживание отключено;
- [ ] reduced-motion не ломает навигацию;
- [ ] семантические ID не зависят от координат будущего атласа.

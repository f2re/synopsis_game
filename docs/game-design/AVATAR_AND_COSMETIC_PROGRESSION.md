# Avatar & Cosmetic Progression — персонализация синоптика

**Статус:** accepted-concept

## 1. Роль персонажа

Персонаж — постоянная визуальная идентичность игрока в мире «Синоптического центра».

Он виден:

- в хабе;
- в инвентаре;
- на экране профиля;
- в лобби;
- в турнирной сетке;
- в spectator mode;
- в post-match;
- в карьерной прогрессии.

Во время сложной учебной задачи персонаж остаётся вторичным относительно карты и данных.

## 2. Базовая кастомизация

Доступна сразу и не требует наград:

- тон кожи;
- форма лица в пределах стилизованного pixel-art набора;
- причёска;
- цвет волос;
- базовый головной убор;
- стартовая одежда;
- базовый рюкзак;
- базовая обувь.

## 3. Стартовые стилевые направления

Игрок выбирает не «класс персонажа», а визуальное направление.

### Спортивный

- худи;
- лёгкая куртка;
- кроссовки;
- городской рюкзак.

### Строгий

- рубашка/свитер;
- аккуратная куртка;
- классические брюки;
- портфель/папка карт.

### Полевой / походный

- ветровка;
- карго;
- ботинки;
- большой рюкзак;
- полевой блокнот.

### Туристический

- яркая куртка;
- кепка;
- небольшой рюкзак;
- термокружка/бинокль как косметика.

### Учебный / лабораторный

- жилет/куртка центра;
- планшет;
- бейдж;
- папка с картами.

Все направления равны по игровым возможностям.

## 5. Синоптическая атрибутика

Коллекционные предметы должны быть тематическими и узнаваемыми:

- красно-синий фронтальный карандаш;
- чёрный изобарный карандаш;
- набор цветных карандашей для подъёма карты;
- картографическая линейка;
- циркуль/измеритель;
- папка синоптических карт;
- архивный блокнот;
- планшет;
- лупа;
- метеорологический значок;
- значок аэрологии;
- радарный жетон;
- мини-метеозонд;
- термокружка;
- настольный барометр как декор;
- нашивки турниров.

## 6. Прогрессия карандашей

Карандаш — один из визуальных символов игры.

Параметры коллекционного вида:

- длина;
- толщина корпуса;
- форма торца;
- заточка;
- мягкость визуального грифеля;
- патина/износ;
- футляр;
- гравировка;
- сезонный скин;
- анимация вращения/заточки.

Пример уровней коллекции:

1. ученический;
2. полевой;
3. профессиональный;
4. комплект ведущего синоптика;
5. памятный/турнирный;
6. архивная серия.

Уровень предмета не влияет на правильность ответа или Ranked score.

## 7. Как зарабатываются предметы

Основной принцип: предметы **зарабатываются игрой**, а не покупаются ради преимущества.

Источники:

- первая победа дня;
- серия Blitz;
- победа в Duel;
- участие/победа в турнире;
- mastery milestone;
- квалификационный допуск;
- прохождение архивного босса;
- достижение;
- сезонный путь;
- редкое World Discovery;
- командное достижение.

## 8. Reward contract

Каждая награда должна иметь понятное происхождение:

```json
{
  "reward_id": "pencil_front_04",
  "source": "achievement",
  "source_id": "frontology_100_correct",
  "cosmetic_only": true,
  "rarity": "rare"
}
```

## 9. Редкость

Допустимые уровни:

- common;
- uncommon;
- rare;
- epic;
- commemorative.

Редкость показывает сложность/редкость получения, а не силу.

## 10. Companions

Косметические спутники:

- синичка;
- чайка;
- баклан;
- снегирь;
- воробей;
- белка как редкий наземный companion;
- кот/собака центра как event-unlock.

Companion может:

- сидеть рядом;
- реагировать на победу;
- появляться в профиле;
- иметь idle-анимации;
- сопровождать игрока в хабе.

В Ranked companion не даёт бонусов.

## 11. Эмоции и реакции

Игрок может открыть emotes:

- «есть фронт!»;
- «нашёл ошибку»;
- спокойная уверенность;
- удивление;
- победный жест;
- задумался над картой;
- реакция на редкое явление.

Emote не должен закрывать карту или мешать сопернику.

## 12. Персонализация рабочего места

Помимо персонажа игрок открывает:

- лампы;
- постеры;
- глобусы;
- модели самолётов/зондов;
- растения;
- кружки;
- рамки карт;
- коллекционные значки;
- декор стола;
- фон профиля.

Это создаёт долгосрочную коллекционную петлю без pay-to-win.

## 13. Связь с достижениями

Лучшие предметы должны рассказывать историю игрока.

Примеры:

- карандаш «100 фронтов»;
- нашивка «КН-01 без ошибок ×50»;
- куртка победителя сезона;
- значок «Южный циклон»;
- рамка «Ведущий синоптик»;
- companion «Синичка» за серию ежедневных смен;
- редкая «Чайка» за World Discoveries.

## 14. Не допускается

- stat boost в Ranked;
- скрытый правильный ответ;
- увеличение времени ответа за косметику;
- снижение штрафа;
- эксклюзивный доступ к обязательному учебному материалу;
- monetized power.

## 15. Acceptance criteria

- [ ] базовый avatar setup доступен сразу;
- [ ] минимум 5 стартовых стилевых направлений;
- [ ] все соревновательные предметы cosmetic-only;
- [ ] предмет имеет provenance награды;
- [ ] companion не влияет на матч;
- [ ] avatar виден в spectator/tournament;
- [ ] cosmetics можно получать в Quiz/Blitz/PvP/mastery;
- [ ] есть preview анимации предмета;
- [ ] inventory и profile используют один avatar schema;
- [ ] внешний вид не влияет на профессиональные символы карты.

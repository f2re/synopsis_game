# Каталог игровых механик

**Статус:** постоянно обновляемый документ

Файл предназначен для независимого развития механик. Каждая механика получает идентификатор, учебную цель, игровой эффект, ограничения и статус.

## Формат карточки

```text
Идентификатор:
Название:
Статус: идея | прототип | принято | реализовано | устарело
Учебная цель:
Игровой цикл:
Входные данные:
Результат:
Соревновательный эффект:
Риски:
Зависимости:
Критерии приёмки:
```

Машинные статусы и поля могут храниться по-английски в данных, но человекочитаемый текст оформляется по-русски.

## M-001 — Быстрое дешифрирование КН-01

- **Статус:** принято.
- **Учебная цель:** автоматизация чтения коротких групп.
- **Цикл:** код → ответ за 5–10 с → мгновенный результат.
- **Соревновательный эффект:** быстрое действие, небольшой эффект, +1 к оперативному ресурсу.
- **Риск:** скорость не должна перевешивать точность.

## M-002 — Собери станцию

- **Статус:** принято.
- **Учебная цель:** схема нанесения метеорологических данных вокруг кружка станции.
- **Цикл:** исходные величины → размещение элементов → покомпонентная проверка.
- **Соревновательный эффект:** защитный щит или восстановление устойчивости.

## M-003 — Критика наблюдений / парирование

- **Статус:** принято.
- **Учебная цель:** поиск подозрительного или ошибочного наблюдения.
- **Цикл:** 5–7 станций → выбор → указание причины.
- **Соревновательный эффект:** парирование, при быстром точном ответе — контратака.
- **Ограничение:** различать «подозрительно», «ошибочно» и «данных недостаточно»; машинные коды могут оставаться `suspect`, `wrong`, `insufficient_data`.

## M-004 — Следующий шаг

- **Статус:** принято.
- **Учебная цель:** процедурная память.
- **Цикл:** текущее состояние анализа → выбор следующей операции.
- **Соревновательный эффект:** поддержание связанной серии.

## M-005 — Алгоритмический конструктор

- **Статус:** принято.
- **Учебная цель:** порядок первичной обработки, фронтологического анализа, ПЭСМ и других процедур.
- **Усложнение:** порядок → лишние шаги → частичный порядок → свободное воспроизведение.
- **Соревновательный эффект:** сложное действие или усиление серии.

## M-006 — Проведи изобару

- **Статус:** предложено.
- **Учебная цель:** анализ барического поля.
- **Цикл:** поле станций → проведение линии → геометрическая и топологическая проверка.
- **Соревновательный эффект:** действие средней сложности.
- **Технически:** используется допустимый коридор и топологические правила, а не точное совпадение пикселей.

## M-007 — Фронт по комплексу признаков

- **Статус:** принято.
- **Учебная цель:** исключить привычку определять фронт по одному признаку.
- **Цикл:** история процесса → АТ/ОТ → приземные признаки → линия фронта.
- **Соревновательный эффект:** сложное действие.

## M-008 — Вертикальное согласование

- **Статус:** предложено.
- **Учебная цель:** связать приземный анализ с АТ-850/700/500 и ОТ.
- **Соревновательный эффект:** усиление командного действия или временная блокировка сложного действия соперника.

## M-009 — Подъём карты

- **Статус:** принято.
- **Учебная цель:** корректное выделение осадков, туманов и явлений цветом и условными знаками.
- **Соревновательный эффект:** поддержка серии; не используется как самостоятельный фантазийный эффект.

## M-010 — История процесса

- **Статус:** принято.
- **Учебная цель:** анализ последовательных сроков.
- **Цикл:** переключение −3/−12/−24 ч → оценка траектории и эволюции.
- **Соревновательный эффект:** предварительная информация о следующем этапе или бонус к сложному анализу.

## M-011 — Цепочка ПЭСМ

- **Статус:** предложено.
- **Учебная цель:** комплексный прогноз через Перемещение → Эволюцию → Суточный ход → Местные факторы.
- **Соревновательный эффект:** итоговое действие только после успешных подготовительных операций.

## M-012 — Эквивалентные соревновательные задания

- **Статус:** принято.
- **Учебная цель:** честное соревнование без обязательного совпадения исходных данных.
- **Технически:** одинаковая структура и близкая эмпирическая сложность при разных данных.

## M-013 — Раунд с одинаковым заданием

- **Статус:** предложено.
- **Назначение:** демонстрационные финалы и занятие с проектором.
- **Особенность:** у обоих игроков один экземпляр задания; правильный ответ скрыт до закрытия раунда.

## M-014 — Командное вертикальное согласование 2×2

- **Статус:** предложено.
- **Роли:** приземный анализ + высотный анализ.
- **Условие:** выводы игроков должны быть согласованы.
- **Результат:** командный бонус только за содержательно совместимое решение.

## M-015 — Оперативная смена 3×3

- **Статус:** предложено.
- **Роли:** наблюдения и коды, приземный анализ и фронтология, аэрология.
- **Финал:** общая прогностическая задача использует результаты трёх ролей.

## M-016 — Совместный архивный синоптический процесс

- **Статус:** идея.
- **Учебная цель:** коллективный разбор реального случая.
- **Этапы:** данные → критика → карта → АТ/ОТ → фронтология → прогноз.
- **Интерфейс:** вместо условного «здоровья босса» показывается неопределённость ситуации или степень завершения анализа.

## M-017 — Ошибка как отдельный объект обучения

- **Статус:** принято.
- **Механика:** ошибка получает код причины и возвращается в интервальное повторение.
- **Примеры:** знак, код, порядок, вертикальная несогласованность, использование одного признака вместо комплекса.

## M-018 — Допуск

- **Статус:** принято.
- **Механика:** крупный блок открывается не только общим опытом, но и квалификационной проверкой.
- **Важно:** пороги задаются курсом или профилем, а не клиентом.

## M-019 — Сезонный сценарий

- **Статус:** идея.
- **Назначение:** регулярное обновление игрового материала без давления на покупки.
- **Структура:** сценарий недели + награды + рейтинговая лига + архив.

## M-020 — Задание преподавателя

- **Статус:** идея.
- **Механика:** преподаватель собирает 5–10 задач в короткое групповое испытание, запускает вход по QR-коду и получает мгновенную аналитику группы.

## Правила принятия новой механики

Механика принимается только если:

1. у неё есть конкретная учебная цель;
2. игровой эффект не искажает метеорологический термин;
3. её можно проверить независимо;
4. она не создаёт преимущества за покупку или бессмысленное накопление;
5. для рейтингового режима возможно обеспечить равенство условий;
6. её можно выключить без поломки предметного содержания.

Основной принцип:

> **Погода постоянно меняется, а наблюдение за ней не прерывается.**

## Приоритет канона

При конфликте применяется порядок:

1. метеорологическая и физическая достоверность;
2. методический профиль и источники;
3. канон мира;
4. вайб-контракт;
5. локальное декоративное решение.

Лор не может подменять реальную метеорологическую терминологию или оправдывать физически неверную механику.

## Для новых ассетов и сцен

Новый материал должен строиться в последовательности:

`профессиональная функция → человеческая обжитость → локальный северо-западный характер → погодное состояние → пиксельный стиль`

У каждой обитаемой сцены должно быть не менее трёх следов человеческого присутствия и не менее одного небольшого сюжетного крючка.

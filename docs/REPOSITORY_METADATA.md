# Рекомендуемые метаданные репозитория GitHub

Эти значения предназначены для полей описания репозитория, тематических меток и будущей страницы проекта.

## Описание

Рекомендуемый русский вариант:

> Учебная соревновательная игра по синоптической метеорологии: российская синоптическая школа, актуальные КН-01, анализ карт, АТ/ОТ, фронтология, автономные турниры и живой мир.

Короткий вариант:

> «Синоптический центр» — учебная игра по российской синоптической метеорологии с реальными данными и сетевыми состязаниями.

Если GitHub или внешний каталог требует отдельное англоязычное описание для международного поиска, оно может храниться как вторичная локализация, но не должно заменять русский основной текст проекта.

## Тематические метки GitHub

Темы GitHub являются техническими поисковыми тегами и поэтому сохраняются в общепринятом латинском написании:

```text
meteorology
synoptic-meteorology
weather
education
game-based-learning
serious-game
realtime
pvp
websocket
weather-map
synop
kn-01
frontology
atmospheric-science
russian-meteorology
student-project
```

При необходимости можно дополнительно использовать русские метки, если платформа начинает полноценно поддерживать их для поиска.

## Главная страница проекта

До появления работающей демонстрационной версии поле домашней страницы лучше оставить пустым. После публикации указывать адрес приложения, а не документации.

## Изображение для представления репозитория

Рекомендуемая будущая композиция:

- современная сцена «Синоптического центра» в утверждённой пиксельной графике;
- крупная синоптическая карта;
- холодный и тёплый фронты, изобары;
- название «Синоптический центр»;
- короткая русская подпись, например «Изучай · Анализируй · Соревнуйся»;
- без перегруженной информационной панели.

## Лицензия

Лицензию необходимо выбрать отдельно для:

1. исходного кода;
2. авторского учебного содержания;
3. внешних архивных карт, изображений, звуков и данных.

До выбора лицензии в README используется обычная русская строка состояния, а не англоязычный статусный бейдж.

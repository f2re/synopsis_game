## Description

> Competitive educational game for synoptic meteorology based on the Russian meteorological school: realtime PvP, map analysis, KN-01, AT/OT, frontology, replay and classroom tournaments.

Короткий русский вариант:

> Учебная соревновательная игра по синоптической метеорологии: российская школа, realtime PvP, карты, КН-01, АТ/ОТ, фронтология и турниры.

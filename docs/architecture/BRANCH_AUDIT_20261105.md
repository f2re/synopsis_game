## Режим очистки

1. Список точных ссылок, оснований и SHA: `tools/maintenance/branch_cleanup_20261105.json`.
2. Проверка безопасности без удаления: `mode=dry_run` и `tools/maintenance/prune_branches.py`. В CI подтверждаются отсутствие открытых PR на удаляемых ветках, отсутствие branch protection, SHA и интеграция через merged-PR либо предка main/живого release candidate.
3. Удаление только после PASS dry-run, сменой `mode=apply` в **том же** манифесте. Job ещё раз проверяет каждую ссылку перед запросом DELETE и сохраняет JSON-протокол с исходными SHA для возможного восстановления.
4. При ошибке данных или новом PR скрипт останавливается. Никакой wildcard-очистки или force-push.
5. Рабочие ветки незавершённых PR и пять веток с уникальной работой сохраняются до отдельного решения.

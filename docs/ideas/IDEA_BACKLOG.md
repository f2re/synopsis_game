# Реестр идей

**Статус:** постоянно обновляемый документ

Здесь хранятся идеи, которые ещё не являются обязательствами плана реализации. Идея переносится в план только после оценки учебной ценности, стоимости и рисков.

## Формат идеи

```text
IDEA-XXX — название
Статус: сырая идея | исследуется | подтверждена | отклонена | перенесена в план
Проблема:
Гипотеза:
Учебная ценность:
Игровая ценность:
Стоимость: малая | средняя | большая | очень большая
Риски:
Как проверить:
Следующий шаг:
```

В данных машинные статусы могут оставаться `raw`, `exploring`, `validated`, `rejected`, `promoted`.

## IDEA-001 — Режим комментирования матча преподавателем

- **Статус:** исследуется.
- Преподаватель отмечает ключевые моменты, а после завершения получает автоматический список эпизодов для разбора.
- **Стоимость:** средняя.
- **Проверка:** пилот на группе 15–25 студентов.

## IDEA-002 — «Синоптический кубок» между учебными группами

- **Статус:** исследуется.
- Сезон из массовых отборочных туров, финалов 1×1 и командной смены.
- Нужна нормализация по численности групп.

## IDEA-003 — Матч против записанного прохождения

- **Статус:** сырая идея.
- Игрок соревнуется не с текущим соперником, а с журналом событий предыдущего сильного прохождения.
- Полезно при малом числе одновременно играющих пользователей.

## IDEA-004 — Реальная ситуация дня

- **Статус:** сырая идея.
- Один короткий архивный или актуальный случай дня с общей таблицей лидеров.
- Требует строгого подтверждения происхождения и прав на данные.

## IDEA-005 — «Ошибка дня»

- **Статус:** исследуется.
- Система выбирает типичную ошибку группы и даёт всем короткое корректирующее упражнение.
- Высокая учебная ценность и небольшая стоимость реализации.

## IDEA-006 — Выбор тематических инструментов перед дуэлью

- **Статус:** сырая идея.
- Игрок выбирает 4–6 тематических инструментов из разрешённого набора; сервер строит матч из соответствующих типов задач.
- Механика не должна превращаться в подбор темы против слабого места конкретного соперника.

## IDEA-007 — Постепенное открытие слоёв карты

- **Статус:** сырая идея.
- Игрок последовательно открывает слои, выбирая порядок анализа.
- Смысл — обучать последовательности работы, а не скрывать данные ради искусственной сложности.

## IDEA-008 — Совместное проведение фронта 2×2

- **Статус:** сырая идея.
- Один игрок намечает фронт по приземной карте, второй подтверждает или корректирует его по высотным данным.
- Итог оценивается как согласованное командное решение.

## IDEA-009 — «Архив ошибок» как коллекция

- **Статус:** исследуется.
- Вместо абстрактных коллекционных карточек игрок собирает типы ошибок, которые уже научился уверенно распознавать.
- Визуальная коллекция не влияет на рейтинговый режим.

## IDEA-010 — Метеорологические достижения без бессмысленного повторения

- **Статус:** исследуется.
- Награды за качество: 20 схем станций без ошибки, 10 корректных парирований, комплексная ситуация без подсказок.

## IDEA-011 — Методический конструктор преподавателя

- **Статус:** сырая идея.
- Преподаватель создаёт собственный пакет заданий через форму, задаёт допустимые перестановки, источники и критерии.
- Публикация в рейтинговом режиме запрещена без методической проверки.

## IDEA-012 — Региональные кампании

- **Статус:** сырая идея.
- ЕТР, Арктика, Сибирь, Дальний Восток, горные районы.
- Каждая кампания опирается на реальные региональные синоптические особенности и источники.

## IDEA-013 — «Ныряющий циклон» как совместная архивная ситуация

- **Статус:** сырая идея.
- Команда разбирает процесс по срокам; ошибки увеличивают неопределённость ситуации.

## IDEA-014 — «Южный циклон» как совместная архивная ситуация

- **Статус:** сырая идея.
- Упор на историю процесса, ВФЗ, осадки и сложную эволюцию.

## IDEA-015 — Турнирный слой большого экрана

- **Статус:** сырая идея.
- Отдельный минималистичный вид для проектора: игроки, Надёжность, текущая категория, серия, карта и результат закрытого задания.

## IDEA-016 — Адаптивная сложность по фактической статистике

- **Статус:** исследуется.
- Сложность задания корректируется не только по мнению автора, но и по фактической точности и медианному времени решения после пилота.

## IDEA-017 — Пакеты для работы без постоянной сети

- **Статус:** сырая идея.
- PWA кэширует выбранные темы для аудитории с нестабильным интернетом.

## IDEA-018 — Ветвящийся разбор повтора

- **Статус:** сырая идея.
- При разборе студент останавливает воспроизведение перед ошибкой и выбирает альтернативное действие.

## IDEA-019 — «Синоптический стол»

- **Статус:** сырая идея.
- Один большой экран или проектор, команды отвечают со смартфонов, карта общая для всех.

## IDEA-020 — Контроль качества учебного содержания

- **Статус:** исследуется.
- Для автора показываются: доля неоднозначных ответов, качество ложных вариантов, состояние источников, необходимость отзыва или замены задания.

## Правила работы с идеями

Идеи не удаляются без следа. При отказе меняется статус на `rejected` и кратко фиксируется причина. Это предотвращает повторное обсуждение уже проверенной гипотезы.

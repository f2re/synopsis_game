# Синоптический центр

**Синоптический центр** — проект короткосессионной учебной игры для студентов-метеорологов, в которой профессиональные операции синоптика являются непосредственно игровыми действиями: дешифрирование КН-01, нанесение данных вокруг кружка станции, критика наблюдений, первичный анализ карт, подъём карты, анализ барического поля, фронтологический анализ, работа с АТ/ОТ, аэрологическими материалами, МРЛ/ИСЗ и составление прогноза.

Проект ориентирован на российскую синоптическую школу и должен явно различать:

1. классическую учебную методику (А. С. Зверев, С. П. Хромов, практикумы отечественных гидрометеорологических вузов);
2. кафедральные варианты последовательности учебных операций;
3. действующие нормативные и методические документы Росгидромета/Гидрометцентра России.

Главный принцип игры: **знание не проверяется перед игровым действием — знание и есть игровое действие**.

## Ключевые принципы

- **Game-first UI:** основную площадь экрана занимает текущая карта, ситуация или задача; рейтинги и дашборды вторичны.
- **Короткие сессии:** микрозадания 5–30 секунд, блиц 60–120 секунд, дуэли 3–6 минут, комплексные смены и «боссы» — длиннее.
- **Профессиональная корректность:** терминология, символы, последовательности и объяснения имеют источник и версию методики.
- **Российские обозначения:** на учебных картах используются принятые отечественные обозначения (например, В/Н, П/Р), если профиль методики не задаёт иное.
- **Историчность и трёхмерность:** анализ текущей карты связан с предыдущими сроками и высотными полями; фронт нельзя определять по одному признаку.
- **Контент управляется данными:** новые задания и методические варианты добавляются через JSON/редактор контента без изменения движка.
- **Честный PvP:** в рейтинговых матчах игровые характеристики нормализованы; преимущество даёт знание, а не гринд или покупка усилений.
- **Серверная проверка:** правильные ответы, таймеры, рейтинг и боевые эффекты рассчитываются на сервере.
- **Наблюдаемость:** матчи имеют spectator/instructor mode и event-log replay без обязательной видеотрансляции.
- **Реальные ситуации:** комплексные сценарии по возможности строятся на архивных реальных картах и наблюдениях; синтетические данные допустимы для изолированных тренажёров кодов/символов и явно маркируются.

## Целевой MVP

Первая версия должна доказать четыре вещи:

1. короткие профессиональные задания действительно удобно решать в браузере и на смартфоне;
2. 90-секундный блиц и 1v1-дуэль дают соревновательный интерес без ущерба методике;
3. преподаватель может запустить турнир группы и наблюдать его на общем экране;
4. преподаватель/методист может добавить новый пакет заданий без изменения клиентского кода.

Минимальный набор MVP: КН-01, схема нанесения станции, условные обозначения явлений, В/Н и П/Р, критика наблюдений, простые задачи по изобарам, базовая фронтология, блиц, 1v1, таблица группы, spectator/instructor view и replay по журналу событий.

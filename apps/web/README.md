# Браузерный прототип

Первое запускаемое приложение проекта. React отвечает за оболочку страницы, Phaser 4 — за живой пиксельный мир.

До исправления отдельного художественного конвейера веб-прототип устанавливается изолированно от остальных рабочих пакетов:

```bash
corepack enable
pnpm bootstrap:web
pnpm dev
```

Проверки:

```bash
pnpm typecheck
pnpm build
```

Текущий срез: главный кампус → Архив → возврат в главный кампус. Остальные локации показывают условия открытия.

`tools/assets` остаётся отдельным рабочим контуром. Его зависимость `sprite-tools` не должна блокировать запуск браузерного прототипа; воспроизводимый способ установки художественного CLI отслеживается в `ASSET-007`.

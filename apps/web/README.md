# apps/web

Канонический браузерный клиент Foundation/MVP: React + TypeScript, Phaser 4 для живого пиксельного мира и SVG/Canvas для профессиональной синоптической геометрии.

`Arena TV` остаётся маршрутом `/arena-tv` этого приложения и использует только безопасные публичные данные.

## Текущие маршруты

- `/` — живой Hub после входа;
- `/profile/avatar` — редактор внешности персонажа;
- `/admin` — управление закрытым списком пользователей, только роль `admin`;
- `/arena-tv` — публичный зрительский маршрут без приватных данных.

## Запуск

Сначала в отдельном терминале запустите `apps/server`, затем:

```bash
corepack enable
pnpm -C apps/web install --ignore-workspace --no-frozen-lockfile
pnpm -C apps/web dev
```

Vite проксирует `/api` на `http://127.0.0.1:8787`.

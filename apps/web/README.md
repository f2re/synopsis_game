# Браузерный прототип

Первое запускаемое приложение проекта. React отвечает за оболочку страницы, Phaser 4 — за живой пиксельный мир.

Запуск из корня репозитория:

```bash
corepack enable
pnpm install
pnpm dev
```

Проверки:

```bash
pnpm typecheck
pnpm build
```

Текущий срез: главный кампус → Архив → возврат в главный кампус. Остальные локации показывают условия открытия.

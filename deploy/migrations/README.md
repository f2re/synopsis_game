# Миграции
Файлы миграций именуются `NNNN_name.sql`, `.py` или `.sh`. `migrate.py` выполняет их по порядку и сохраняет SHA-256 применённого файла в `/var/lib/synopsis-game/migrations/applied.json`; изменение уже применённой миграции блокируется. SQL выполняется транзакционно через `sqlite3` Python для SQLite или через `psql -v ON_ERROR_STOP=1` для PostgreSQL. Перед миграциями обновлятор останавливает сервис и делает резервную копию.

# Skill — Ambient Audio Production

Use for hub ambience, fauna, indoor equipment, interaction cues, Blitz/Duel feedback and Arena TV transitions.

Read:
- `agents/roles/audio-ambient-designer.md`
- `docs/design/LIVING_WORLD_SYSTEM.md`
- `docs/design/PIXEL_ART_STYLE_GUIDE.md`

Procedure:
1. Define event/scene/time/season → sound mapping.
2. Separate continuous beds, one-shots and gameplay feedback.
3. Set loudness priority: task feedback > meaningful interaction > ambient beds.
4. Prefer authored/procedural sounds or explicitly compatible libraries.
5. For every external asset record URL, author, license, attribution, local path and checksum before use.
6. Test loop seams, mute, reduced-sensory mode and long-running kiosk behavior.
7. Never make sound the sole carrier of required information.

Unknown rights or unclear attribution = reject the asset, do not download/ship it.

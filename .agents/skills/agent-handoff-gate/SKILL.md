# agent-handoff-gate

Read `agents/registry.yaml`, `agents/ROUTING_AND_HANDOFF.md`, and `agents/QUALITY_GATES.md`. Select exactly one internal implementation owner and the required independent reviewers before changing files. Attach optional external experts as advisers, not as competing owners. Scope files, enumerate dependencies, and select a branch/worktree. Handoff records task ID, scope, changed files, exact tests, artifacts, reviewer evidence and unresolved risks. A generated plan or AI assertion is never proof that a remote agent ran. Do not merge a blocked review, change main by force, or bypass meteorology/art/security gates.


Evidence: list tested cases and exact commands, with independent reviewer decisions when required.

# Персонажи площади R08

Лица, одежда и предметы сохранены из собственных исходников R02. Для ходьбы заново собраны восемь поз ног на сетке 16×24. Опорная стопа остаётся на линии земли, опора меняется через половину цикла. Сетка спокойных поз и разговора согласована с ходьбой.

`editable/*-walk.aseprite` содержит редактируемые кадры ходьбы. `walk-poses.json` фиксирует конструкцию опоры, палитры, сетку, шаг и исходное семейство. Источник поз покоя и разговора указан в манифесте R02.

Экспорт использует `python tools/assets/build_r08_walk_actors.py`. Параметр `--check` проверяет воспроизводимость манифеста и полос. Кадры ходьбы 16×24 упакованы в 32×48 без сглаживания и сохраняют опору (16, 46). Кадры Веры сохраняют исходную рамку 40×48 и используют сетку 20×24. Поставляются только слои для R08.

# Растровые кандидаты

Этот каталог содержит рабочие растровые кандидаты, а не окончательные `.aseprite`-источники.

## Базовые правила

- один промпт / один `asset_id` = один отдельный вызов генератора = один отдельный файл;
- разные `asset_id` нельзя объединять в один генерируемый коллаж;
- многовидовой/многокадровый результат допустим в одном файле только когда это прямо определено одним prompt/spec;
- ошибочно унаследованный результат предыдущего промпта получает `REJECTED`;
- контрольные композиты являются только review-артефактами;
- кандидат становится каноническим source только после `art_status: pass` и `technical_status: pass`.

## Классы персонажной графики

`dialogue_portrait`, `profile_portrait` и `world_character` являются разными классами.

- `dialogue_portrait`: канонический мастер 256×320 logical px, минимум 192×240;
- `profile_portrait`: отдельная композиция 160×160;
- `world_character`: маленький игровой спрайт 32×48.

Запрещено автоматически уменьшать диалоговый портрет до мирового спрайта или прогонять диалоговый портрет через крупнопиксельный sprite-normalizer.

## Raw-кандидат не является финальным pixel art

Для `generated_raw` и раннего `candidate` разрешены:

- разрешение выше логического;
- временный нейтральный фон;
- антиалиасинг;
- расширенное число цветов;
- небинарная alpha/mask на промежуточной стадии.

Raw оценивается прежде всего по композиции, силуэту, идентичности, мимике, возрасту, обязательным признакам и соответствию арт-направлению.

## Портретный кандидат

Для ключевого NPC создаётся 6 вариантов. При выборе оцениваются:

- естественные взрослые пропорции;
- индивидуальность лица;
- читаемость глаз, носа и рта;
- микромимика;
- возраст;
- причёска и характерный образ;
- профессиональная убедительность;
- отсутствие chibi/kawaii/toy-like эстетики.

Красивый raw-портрет не должен становиться хуже только ради формального уменьшения количества цветов или размера.

## Нормализация

Нормализатор работает только после выбора художественно пригодного кандидата.

Для портрета запрещены:

- majority downsampling;
- жёсткая квантизация в 16/24 цвета;
- chunky-pixel преобразование лица;
- уничтожение тонкой оправы, глаз, носа, рта и возрастных деталей.

Если `refined` хуже `raw`, результат refinement получает `REFINEMENT_REJECTED`.

## Палитра

Количество цветов — не мера качества.

Текущие ориентиры:

- диалоговый портрет: 48–96, мягкий потолок 128;
- профильный портрет: 36–72, мягкий потолок 96;
- мировой спрайт: 16–32;
- крупная архитектура: 48–96;
- большая сцена: 96–192.

Строгая palette quantization допустима для маленьких спрайтов/иконок, но отключена для высокодетальных диалоговых портретов.

## Прозрачность

`#FF00FF` не является обязательным production background. Предпочтительны нейтральный matte + отдельная mask/segmentation map. Chroma key допускается как fallback конкретного workflow.

## Приёмка

Используются независимые статусы:

```yaml
art_status: pending | pass | fail
technical_status: pending | pass | fail
production_status: candidate | approved | rejected
```

Технический `pass` не означает, что ассет художественно принят.

После художественного и технического `PASS` кандидат переводится в канонический редактируемый source, фиксируются pivot/tags/frames, а производные файлы собираются автоматически.

Связанные контракты:

- `docs/design/LOCAL_AI_ASSET_PIPELINE_V2.md`;
- `docs/design/PORTRAIT_ART_DIRECTION.md`;
- `config/art-generation-profiles.json`;
- `docs/design/sprites/GENERATION_SERIES_CONTRACT.md`;
- `docs/design/sprites/PIXEL_ART_VALIDATION_WORKFLOW.md`.

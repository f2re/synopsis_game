# Растровые кандидаты

Этот каталог содержит проверяемые растровые кандидаты, а не окончательные `.aseprite`-источники.

Правила:

- сохранять логический пиксель без сглаживания;
- не редактировать производный атлас вручную;
- семантический идентификатор задаётся манифестом;
- соблюдать `docs/design/sprites/GENERATION_SERIES_CONTRACT.md`;
- один промпт / один `asset_id` должен давать отдельный вызов генератора и отдельный файл кандидата;
- разные `asset_id` нельзя объединять в один генерируемый коллаж или контактный лист;
- многовидовой или многокадровый результат допустим в одном файле только тогда, когда это прямо определено одним промптом данного ассета;
- ошибочно унаследованный результат от предыдущего несвязанного промпта помечается `REJECTED` / `INVALID` и не считается выполненным элементом серии;
- контрольные композиты допускаются только как производные файлы для проверки и не заменяют отдельные исходные кандидаты;
- после `pixel-art-quality-reviewer: PASS` и `art-director: PASS` кандидат переводится в канонический `.aseprite`;
- контрольные композиты сцен не заменяют модульные слои.

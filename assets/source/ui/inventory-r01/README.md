# Исправленные предметы инвентаря R01

10 ноября 2026 года созданы четыре самостоятельные иконки: шарф, защитные очки, значок метеонаблюдений и значок аэрологии. Они исправляют семантические ошибки прежних изображений; исторические файлы не перезаписываются.

Исполнитель графики: `character_runtime`, отдельная задача подготовки UI-ресурсов. Независимая художественная проверка: `docs/art/reviews/2026-11-10-inventory-icons-review.md`. Исполнитель не принимает собственную работу.

## Исходники и сборка

`provider-sheet.png` — неизменённый оригинал встроенного imagegen (1254×1254 RGBA). Четыре `.aseprite` — редактируемые производственные исходники 128×128 с одним слоем и кадром `idle`. Их пиксели экспортируются без повторной генерации или перерисовки.

Однократная подготовка исходников использовала отдельные квадранты, отсечение альфа-канала по128, обрезку по видимому предмету и вписывание ближайшим соседом в112×112 внутри рамки128×128. Исходная мягкая прозрачность сохранена в оригинальном листе. Палитра не квантизировалась. Эти подробные пиксельные UI-иконки относятся к отдельному классу; их не следует выдавать за малую модульную мировую графику.

```bash
python tools/assets/build_inventory_icons_r01.py --check
python tools/assets/build_inventory_icons_r01.py
```

Обычная сборка читает `.aseprite`, создаёт PNG в `assets/generated/ui/inventory-r01` и копии в `apps/web/public/assets/items`. Параметр `--import-source` нужен только для создания отсутствующих редактируемых исходников из сохранённого листа и не перезаписывает существующие источники.

Контракт, точные прямоугольники извлечения, контрольные суммы и идентификаторы находятся в `assets/manifests/ui.inventory-r01.json`. Контактный лист для визуальной проверки: `docs/testing/evidence/inventory-icons-20261110/contact-sheet.png`.

## Генерация и происхождение

Использован встроенный `image_gen`, одна генерация общего листа с `transparent_background=true`. Платные генерация, удаление фона и анимация SpriteCook не запускались. Четыре готовых PNG импортированы через защищённый загрузочный мост в выбранные проект/коллекцию SpriteCook. Баланс до и после импорта —720 кредитов. В манифесте сохранены только стабильные идентификаторы и хеши; токены и временные ссылки не сохранены.

Промпт генерации приведён полностью в `prompt.txt`. Значки являются декоративными игровыми предметами, не наградами реальных организаций и не учебными эталонами метеорологических символов.

# Тихая читальня станции

`station-room.aseprite` — редактируемый источник двух согласованных слоёв размером 512×288. Это компактная иллюстрация для главного меню, справки и библиотеки; она не заменяет сцену кампуса Phaser.

- `window-view`: наружный вид только в стеклянных проёмах.
- `room-front`: мебель, книги, приборы, лампа, оконные рамы и остальной интерьер.
- Маска дождя выводится из alpha слоя `window-view`. Лампа и предметы на подоконнике исключены из маски.

`candidates/provider-room.png` сохраняет неизменный результат одной генерации SpriteCook NB2.1. `canonical-room.png` — уточнённый источник: псевдоподпись на декоративной карте заменена соседней бумагой в прямоугольнике 18×7; близкие RGB-цвета объединены только при расстоянии не более 3 из 255. Новая палитра не имеет целевого ограничения, жёсткая квантизация и изменение размеров не применяются. Сохранены материалы, свет и контуры. Оба слоя без потерь восстанавливают канонический PNG.

Рецепт доработки записан в `refinement` манифеста; `--refine-source` воспроизводит канонический PNG и слои Aseprite из неизменного provider. После независимой приёмки эта операция блокируется, пока статус явно не возвращён в проверку. Сравнения A/B (слева provider, справа canonical) находятся в `docs/testing/evidence/cozy-screens-r01/room-refinement-ab-native.png` и `room-refinement-ab-2x.png`.

Происхождение, геометрия выделения стекла, контрольные суммы, бюджет и сведения о независимой приёмке находятся в [манифесте](../../../manifests/ui.station-room-r01.json).

## Сборка

```bash
python tools/assets/build_station_room_r01.py
python tools/assets/build_station_room_r01.py --check
python tools/assets/build_station_room_r01.py --check --require-approved
```

Первая команда экспортирует Aseprite в `assets/generated` и публичные пути приложения. Вторая проверяет байтовую воспроизводимость рецепта доработки, прозрачность, комплементарность слоёв, точное совпадение с каноническими пикселями и бюджет. Третья дополнительно требует записанной независимой художественной приёмки. Обычная техническая проверка не является художественным одобрением.

`--import-source` предназначен только для однократного создания Aseprite по исходной генерации и маске; существующий исходник не перезаписывается.

## Встраивание

`StationRoomArt({ rain, reducedMotion, className? })` выводит сцену 16:9 без обрезки. Текст и действия остаются обычными доступными элементами React. Дождь декоративный, не отражает реальные метеоданные. Используются 12 коротких штрихов CSS под маской и передним слоем; в скрытой вкладке, при уменьшенной анимации и пониженной нагрузке движения нет.

Состояние погоды не запекается в новые копии комнаты. Тихий статичный вариант сохраняет всю композицию. Иллюстрация не содержит учебного эталона: карта на стене и бумага на столе — элементы окружения.

# H3D-038 — Сведение 2.5D-веток и проверка пространственной модели

**Источник истины:** PR #80 + #87 + #89 + #90; этот этап — отдельный дочерний PR. 
**Не меняет:** основной рендерер `legacy2d`, координаты утверждённого Geometry Lock v1, серверные правила игры.
**Статус:** реализация тестов и аудита; арт-/GPU-приёмка отдельно.

## Выполненный технический вклад

- `runtime/logicalViewportMath.ts`: чистое integer масштабирование; Phaser-адаптер `fitLogicalViewport.ts` только реэкспортирует и применяет его.
- `HubWorldDefinition.ts` теперь импортирует pure viewport constants, что позволяет проверять данные без браузера.
- Контрактные тесты: 640×360/480×270, кадрирование, WebGL2 fallback, восемь входов в здания, единые semantic IDs и текущая Geometry Lock.
- `HubStructureGeometry.ts`: единые параметры размеров процедурных построек, теперь реальный renderer и аналитика используют их совместно (предотвращение дрейфа).
- `HubSpatialAudit.ts`: read-only проверка пересечений осей дорожек с прямоугольниками оснований реальных procedural meshes.
- `spatialAuditCli.ts`: JSON-снимок конфликтов прикладывается к визуальным тестам в Actions. **Не** автоматически превращает эти контуры в признанные коллизии.
- Тесты фиксируют известные конфликты #91: operations/spine, codepost/spine, cartography/west, archive/east, hall/east; реальные исправления должны пройти художественную приёмку.

## Делегирование и приёмка

### Исполнитель 1: `game-runtime-webgl-engineer` (Codex / Claude Code)
- Поддерживать один `ThreeHubRenderer`, одну `HubProjection` и один `PixelPostPipeline`.
- Закрепить `HubStructureGeometry` как единственный источник размеров body/roof, не менять Geometry Lock через shader/camera.
- После review переносить ценную функциональность #86 только как тесты/модули без альтернативного runtime.
- Доказательства: TS + Node tests + CI, отсутствие дублированного renderer.

### Исполнитель 2: `living-world-engineer` (Codex / Gemini)
- **Issue #91**: на основе `spatial-audit.json` согласовать план прохождения дорожек вокруг настоящих footprints.
- Подготовить версионированный новый geometry layout с доступом ко всем восьми входам, с безопасными коннекторами и метеоплощадкой.
- Перемещение зданий и дорожек без согласованного Geometry Lock/арт-подтверждения запрещено.
- После утверждения убрать известные конфликты; заменить тест-фиксацию конфликтов тестом их **отсутствия**.

### Исполнитель 3: `art-director` (Gemini / Claude Code)
- Принять или отклонить spatial-audit наложение; проверить силуэт главного корпуса, дорожек, декора, навигационных входов.
- Предоставить скриншоты 640×360 день/ночь/снег/туман, применить независимую пиксельную приёмку.
- Не принимать новую планировку без сравнения с `hub.geometry.lock_v1`.

### Независимая проверка: `web-performance-engineer`, `integration-release-engineer`
- Скриншоты, p50/p95 render ms, actual GPU vs SwiftShader; context-loss/recovery.
- Проверить `pnpm world:test`, `pnpm world:typecheck`, `pnpm build`.
- Не переключать default mode до закрытия #85; не самопринимать.
